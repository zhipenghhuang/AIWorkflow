# 用例设计（技能 · 随包生效）

> 字段/红线以 `规则/模板/20-测试用例/测试用例模板.md` 为准；本技能=技法与手感。  
> 计划驱动：按 `测试/测试计划.md` §3 类型/轨道与 §12 探索章程设计；功能用例与探索章程分开，不混用覆盖口径。

## 1. 技法速用手册

- **等价类**：有效/无效各取代表；同类代表不重复测。
- **边界值**：取点口诀 `min-1 / min / min+1 / 典型 / max-1 / max / max+1`——数字、长度、时间、分页、金额都适用。
- **判定表**：条件组合互斥时列规则表，一格一用例（同结果列可合并）。
- **状态迁移**：画状态 × 事件矩阵；每个**非法跃迁**一条负向。
- **场景法**：用户故事串「入口 → 动作 → 观测点」；主路径 + 每条分支变体。
- **组合/配对**：多输入选项用 pairwise 思路裁剪（不做全排列）。
- **错误推测**：按历史缺陷谱系补（见 §4）。

## 2. 设计顺序（顺手套七维）

主路径 → 状态与规则 → 负向与非法跃迁 → 边界 → 权限/数据域 → 异常与脏数据 → **视觉/体验**（布局/遮挡/截断/文案/文案减法/空态/加载/错误提示/按钮状态；七维自查见 testcase-agent 完稿自检）。

### 2.1 覆盖全面性（不能只看主流程）

- 每个受影响模块至少覆盖：主路径、状态/规则、负向/边界、权限/数据域、异常/恢复、UI/体验。
- 复杂配置/筛选用组合/配对；状态对象画状态 × 事件；写操作必含失败/回查/清理。
- 文档未写死数值 → 仍出行为用例，执行先读现网口径；禁整段不测。
- 用例之外发现（UI/布局/显示/console/network）在执行期记录，不替代用例覆盖。

### 2.2 深度档（不可让 · 完整≠条数）

> **单一出处**：本表。映射无空行只证明「点有人认领」，**不证明深度够**。工作流三闸②引用本表；§4 须落「深度档自检」。  
> **禁止**：仅按方案场景 1:1 落条、无技法展开却宣称「已全覆盖」；无风险依据的字段穷举/全排列（等价取代表 + pairwise）。

| 设计点特征 | 最低厚度（可多点共用一条，映射须能指到） |
| --- | --- |
| P0-Smoke / 阻断主链 / GATE | ≥1 主路径成功 + ≥1 关键失败/阻断（可同条可判定分支） |
| 有状态对象/流程 | 合法迁移抽样 + **≥1 非法跃迁**负向 |
| 有数值/长度/时间/金额/分页输入 | ≥1 边界或无效等价 |
| 跨角色 / 租户 / 数据域 | ≥1 权限或越权（文档未声明 → 角色冒烟或用户接受不测） |
| 写操作 | 失败或写后回查 + 清理（可并入主条） |
| 受影响 UI 页 | 视觉基础：独立条 **或** 并入相邻用例预期（执行截图必检，见工作流 §2.1.0） |

- 收尾对照：每个 P0/高风险设计点在映射说明或 §4 深度档自检标明已满足上表哪几行；缺行且无「不适用+依据」→ 覆盖缺口，不得开跑宣称完整。
- 分片超时/直做降级：**同一深度档**，禁用「场景映射齐」替代。

### 2.3 AI / 非确定性 / 可访问性附加

- **AI 功能**：oracle 用规则/引用/rubric/人工评审；覆盖拒答、无依据、越权、提示注入、格式破坏、成本/延迟；重复 N 次按阈值判定（方法见 `技能/ai-feature-testing/SKILL.md`）。
- **非确定性**：同一输入多次运行；记录通过率与方差；不把一次通过写成稳定。
- **可访问性**：键盘全流程、焦点顺序/可见、对比度、语义/标签、错误提示、缩放 200%、减少动态；按 WCAG 2.2 AA 适用条款。
- **国际化**：长文案/换行、日期/时区、金额/币种/小数、复数、RTL；不把中文写死在断言里。
- **隐私**：用例数据不含真实 PII；证据脱敏；导出/日志用例覆盖敏感字段。

### 2.4 迭代方案/设计文档覆盖点（生成前必抽）

> 目标：不是“按模块标题生成”，而是“按迭代方案/设计文档的可验收单元生成”。覆盖单元优先级：**GATE/AC/TP > F/R > §章节 > 页面/接口**。

1. **抽全**：从主读抽 `GATE-*`、`AC-*`、`TP-*`、`F-*`、`R-*`、设计文档 §/节点，列成一张“覆盖单元表”；每行写来源、优先级、是否本期范围。**只读当前迭代/近两版；旧版归档不读**（除非用户点名），避免过期口径与 token 浪费。
2. **映射**：每个 P0/GATE/AC 必须落到用例（或「不适用+依据+接受人」）；**只写 DP/模块名不算**。P0/GATE 未映射=覆盖缺口，不得宣称完整。
3. **范围外**：方案明确不做的 F/§ 要标「不适用+依据」，不要静默消失；P2/P3 候选同理。
4. **数据链路/可观测性**（真实缺陷高发区，按项目裁剪）：
   - 幂等键是否**落库/回显/重放**（不是只重复点一次）；
   - 统计窗口/跨日/时区**守恒**（同一产量只归一个窗口）；
   - 跨模块联动**关键字段/关联表/重试**（来源对象、mrbNo、linkageNo、retry_count）；
   - 诊断能否落到**点位/对象级**（不是只给通道级失败）；
   - 最新值是否有**来源/时间/质量**，历史/趋势是否可查；
   - 审计事件能否按**对象类型+ID**检索；敏感字段是否掩码/加密；
   - **验收基线对象是否存在且可查**；受控场景包是否有固定输入/期望事件/清理边界；
   - `待实现` 功能交付后是否**复测**；上一版失败/缺陷是否进入本版回归。
5. **oracle 纪律**：预期只来自方案/AC/契约/用户裁决；**不得因为现网只显示“—”就把“待补配置”改成通过**。现网实现是现状，不是预期；冲突记失败/待确认。
6. **充分性**：每条 P0/GATE 至少 1 条主路径 + 1 条失败/阻断；有状态对象至少 1 条非法跃迁；有数值/时间/分页至少 1 条边界；跨角色/租户至少 1 条越权。

## 3. 断言写法

- 每条预期必须**可观测**：值/文案/状态列/字段=值（杜绝「正常/正确」）。
- 灰盒判定优先写业务信号（列表刷新/状态列/接口字段）。

## 4. 常见漏测谱系（生成时对照补）

金额与精度｜时间与时区｜分页边界与排序｜重复提交/幂等｜空态与首屏｜超长与 Emoji｜导入导出（模板/编码）｜权限域与越权｜并发同键｜缓存刷新｜浏览器返回/刷新态｜网络慢与失败重试｜**UI 布局/遮挡/截断/文案/冗余标语与标签**｜按钮/禁用/加载态｜错误提示与恢复｜AI 拒答/引用/注入/重复运行｜键盘/焦点/对比度｜多语言/长文案/RTL｜成本/超时/降级。

## 5. 与文档的关系

- **用例文档结构（模块内索引 + 结构化，不改目录）**：§1 模块总览表（ID/标题/场景/优先级/类型/关联需求AC/设计点/前置摘要/步骤数/脚本/最近结果/缺陷）→ §2 结构化详情；总览与详情同文件，不拆文件夹、不建全局索引。
- **单条结构**：元数据 → 一句话场景/业务价值 → 前置（账号/数据/入口/环境/构建/依赖）→ 测试数据表 → 步骤表（#/位置/操作/数据/中间预期）→ 预期表（判定面/失败判定）→ 清理 → 证据要求 → 执行提示 → 追溯 → 变更记录。
- **步骤定位**：每一步都写清页面/区域/Tab/弹层/控件/行定位；列表→详情写「按 {列名} 定位行」；按钮用界面可见文案；禁「相关/适当按钮」。
- **步骤详细度**：P0 必达「第二人可不猜页面/字段/数据地跟做」；差→好模式与禁照抄示意见 `规则/模板/30-执行与台账/缺陷文案模板.md` §5.0.4「详细度基线」（用例步骤同构：入口→对象全码→字段=值→操作→断言）。
- **场景载体**：GEN/TP「前置与操作」点名的动作须写入入口/步骤；禁只挂 G-xx、步骤用「执行批量/按场景数据/本步结果可在页面核对」等空话；字段名可「口径待探查」，动作不可空。
- 口径变更 = 改断言 + 同轮同步脚本（`规则/专项/脚本执行.md` §4）；口径待探查先写「以本构建实现值」（仅钉本载体字段）。
- **章节回执**：完稿前对主读逐章过一遍——每章要么「设计点→映射」，要么明确「无设计点」；缺章禁落盘。
- **生成后评审**：本技能只负责生成期自检；**独立评审**走 `技能/testcase-review` + step `review-cases`（T1+ 功能强制；生成写手不得自放行）。
- **引用抽验**：收尾前抽 2～3 条『设计来源』打开被引文件核对（不实即改）——错误尽量拦在生成期，评审再抽验加固。
- **质量评分卡**：场景/前置/步骤/预期/负面边界/独立清理/追溯/可读/数据/版本十项，0～2 分；缺入口/步骤/预期/追溯为阻断；≥18/20 且无阻断才可交评审。  
  三维体验为横向门：UX（执行者能照做）、DX（脚本/维护成本）、AX（结构化/可追溯）任一净退化 → 需修，不计分。

### 5.1 常见合理化与反驳

| 合理化 | 现实 |
| --- | --- |
| “方案场景都覆盖了” | 场景 1:1 不等于技法展开；看深度档与边界/负向。 |
| “字段太多，全排列” | 等价类 + pairwise 取代表；全排列是浪费不是严谨。 |
| “预期写正常/正确就行” | 不可观测=不可判定；必须值/状态/字段。 |
| “AI 输出没法测” | 用规则/引用/rubric/人工 + 重复阈值；不是不测。 |
| “UI 看看就行” | 视觉基础条要进断言或相邻用例预期，截图同帧检。 |
