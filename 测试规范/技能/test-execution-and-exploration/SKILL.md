# 执行与探索（技能 · 随包生效）

> 用于：execute（功能/探索式/计划驱动跨轨）。**计划驱动时，测试计划 §9.2 是编排真值；每阶段按对应轨契约执行。**  
> **执行前核对**：需求模型/分析短表/oracle/TP 与用例追溯；预期来自需求/AC/契约/用户裁决，不按现网实现改预期；实现与需求不一致 → 记失败/缺陷。无来源先问或标「文档未声明」。

## 1. 计划驱动执行（跨轨）

- **按阶段推进**：P0 准备 → P1 冒烟 → P2 功能 → P3 接口 → P4 探索式 → P5 非功能 → P6 回归 → P7 UAT → P8 发布前/灰度 → P9 报告；每阶段入口/出口检查，不跳阶段。
- **阶段取轨**：功能/探索式走多Agent四档；接口单 Agent；发布前按轨契约；只读当前阶段轨契约，不跨轨通读。
- **并行**：仅计划标注且账号/数据/浏览器 profile/写域隔离；同条用例禁并行；写冲突串行。
- **状态**：更新 `测试/测试计划.md` §0（阶段/门/下一动作）与 §16.1 执行日志；正式对照落报告 §2。
- **停止**：P0-Smoke 未过/环境不可用/数据合规/计划实质偏差 → 按计划 §6 暂停或回计划门。

## 2. 执行经济（省时优先）

- **数据先行**：开跑前集中备齐本批前置（缺 → 一次造齐，优先 API/脚本）→ 再进冒烟；别边跑边造。
- **先侦察后动作**：导航 → 等载入 → 快照/截图定位 → 再连续动作；同页多用例=一次侦察多次操作，DOM 变更后再刷新快照；批次结果一次汇总。
- 冒烟先过再全量（`规则/专项/多Agent与输出.md` §1.1.1）；已脚本化走脚本档。
- **工具黑盒调用**：执行器/工具大件不读源码进上下文（先 `--help`/README）；**MCP 全量快照单次数千 token 且逐轮累积**——重复/回归路径沉淀脚本（0 token），MCP 留给首查、口径探查与失败复核。

## 3. 回归闭环（过程中并行）

- **修复即回归**：每个缺陷修复后立即跑 原单 + 冒烟子集 + 影响面组；不等批末。
- **影响面组**：由开发回写【改动范围/影响面】+ 变更点生成（3～8 条建议）；用户点头才扩。
- **升级**：高风险（跨模块/契约/数据/权限/资金/并发）或同模块短窗口 ≥2 单 → 提示模块局部全量/扩大邻接回归。
- **记录**：结果就地覆盖台账与证据，只留最新；报告 §5.2 汇总回归轮次/通过率/遗留。
- 已脚本化优先脚本档；脚本失败按 `规则/专项/脚本执行.md` §3 有界复核后再定性。

## 4. 探索式测试（SBTM）

- **章程**：Explore [目标] with [资源/约束] to discover [风险]；范围/时间盒/数据/oracle 写清（计划 §12）。
- **路线轮换**：数据漫游（替换数据/极端值）｜操作漫游（乱序/连点/回退）｜状态漫游（跳态/终态重入）｜干扰漫游（并发/断网/重复提交）｜业务漫游（主链路抽样）。
- **启发式**：FEW HICCUPPS（oracle：历史/镜像/可比产品/宣称/用户期望/产品/目的/标准）；SFDIPOT（结构/功能/数据/接口/平台/操作/时间）。
- **记录**：session 笔记（发现/覆盖/疑问/耗时）；发现即记，不追完美复现（概率性记频率）。
- **Debrief**：章程完成/覆盖/缺口/新风险；分流——产品缺陷→缺陷+回归；覆盖缺口→补用例/补章程；误报→记录。
- 探索式不脚本化；证据按会话留；收尾禁空泛「探索通过」。

## 5. 现场观察手感

- 看细节：提示语/占位/空态/加载/禁用态/焦点/滚动/截断。
- 边界输入即时试（超长/emoji/空格/大小写/全角）。
- **用例之外发现**：布局错位/遮挡、文案错/截断、冗余标语/说明/次要标签、显示不一致、按钮状态、console 报错、Network 异常、交互反馈缺失——记录位置/现象/证据/影响；能复现进缺陷/观察项，不能复现记频率；不静默忽略。
- 失败当场留证（截图钉断言面）、最小复现、环境快照（URL/账号角色/时间）；归因先复现后定性。

## 6. 数据卫生

- 造数遵循基线 §10/§11；用后清理或标注；写操作前查冲突登记（§15）。
- 回归数据用 `REG-`/runStamp 幂等；跨轮复用先核对状态。
