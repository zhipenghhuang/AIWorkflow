# 测试落地产物评审（技能 · 随包生效）

> 覆盖：**测试计划**、**需求模型/分析短表**、**功能/专项用例**、**接口资产**、**探索章程/用例**、**发布前专项资产**。  
> 用例细规仍见 `技能/testcase-review`（本技能=范围总览 + 计划/分析量规 + **选 B 时 AI 自主深析**）。  
> 门：`select_review_mode` → A 自行｜B AI；未选不得进生成全量 / 执行 P2 / 宣称计划已确认可驱动。

> **增量诚实**：计划/用例评审核对 §3.7 装填与命中域增量是否诚实；一遍过=命中范围，不要求也不倡导全仓重生。

## 1. 强制问 A/B 是否合理（设计原则）

| 问 | 理由 |
| --- | --- |
| 要问 | 将**约束执行与准出**的产物；AI 生成物有流畅≠正确风险（NIST/ETIS） |
| 不必每份都机检 | 选 A=人责放行；选 B=AI 深析+留痕；避免「多层审批」疲劳 |
| AI 自主空间 | 选 B 时**不止过清单**：主动找漏测、矛盾、不可测、风险错配、策略缺口 |

## 2. 强制 / 建议 适用表

| 产物 | 何时必问 A/B | 选 B 时 AI 主攻 |
| --- | --- | --- |
| **测试计划**（T1+ 首版/换代/范围·准出·缺陷策略实质变） | **强制** | 范围/反范围、类型与轨道是否匹配风险、P0～P9 编排可行性、常青/依赖 Smoke、准出是否可判定、GAP 是否被偷偷写成确定范围 |
| **需求模型 / 分析短表**（T2/T3 或歧义≥2） | **强制**；T0/T1 建议 | 九类歧义是否扫全、oracle 来源、跨文档矛盾、TP 种子空洞、把现网当预期 |
| **功能全量/专项用例** | **强制**（T1+） | 见 `testcase-review` A1–A6/S1–S6 + 漏测谱系主动补洞建议 |
| **接口测试资产**（计划驱动或独立生成且进准出） | **强制**（有契约/改接口时） | 接口×维度覆盖空洞、负向/幂等/鉴权、与契约漂移 |
| **探索式章程/用例**（计划 §12 纳入时） | **建议**；T3 强制 | 章程是否可 session、风险启发是否对准、会否冒充全量 |
| **发布前**（性能/安全/兼容/迁移资产） | **建议**；T3/点名强制 | 指标/达标线/环境是否可测、与发布风险对齐 |
| 随机业务流程 | **不强制**（计划外） | 用户点名才审 |
| 执行台账/报告 | **不走本门** | 走 execute/report 机检门 |

## 3. 必须先停问

```text
【评审方式】产物={计划|分析|功能用例|接口|探索|发布前…}｜级别={T0～T3}
A. 自行评审通过 — 你过目；AI 附「自主分析摘要」（仍可拒绝）
B. AI 独立评审 — 另起评审身份深析；留痕；功能轨可选 -Mode review
请回复 A 或 B（可写「B，并重点看权限/支付」等自定义焦点）
```

- 用户可加**自定义焦点**（选 B 时 AI 必须优先分析这些面）→ 发挥自主分析。  
- 同产物同会话只问一次。

## 4. 选 B：AI 自主深析协议（不可只当清单机器人）

在跑量规之前，必须先输出 **【自主分析】**（≤40 行）：

1. **策略是否配得上风险**：级别 T× 与类型/轨道/深度是否匹配；该加的专项有没有漏。  
2. **漏测假设**：基于漏测谱系 + 本需求特有风险，列 3～8 条「最可能漏」并指向应补设计点/用例。  
3. **矛盾与不可测**：文档内/跨文档/原型/计划 冲突；AC 不可判定项。  
4. **过度/不足**：过测（低价值重复）与欠测（P0/权限/资金面）各至少审视一句。  
5. **建议取舍**：保留/合并/降级/升级测试类型；供人拍板。

然后再跑对应量规；缺口表须能追溯到上述分析条目。

## 5. 计划量规（摘）

| 轴 | PASS | FAIL |
| --- | --- | --- |
| 范围边界 | 做/不做清晰；常青/依赖 Smoke 有安排 | 仅新功能、反范围空 |
| 风险驱动 | 类型/轨道/P0 与 T 级、业务风险对齐 | 高风险无专项/无 HighRisk |
| 编排可执行 | §9 依赖/并行/账号隔离说得通 | 纸面阶段无法落地 |
| 准出可判定 | §5 与 P0/缺口规则一致 | 「差不多就过」 |
| 追溯 | 引用分析短表/AC/TP | 计划与分析脱节 |

## 6. 与 testcase-review / 报告门

- 功能/接口/探索/发布前的**用例级**细轴 → 调用或内联 `testcase-review` / 各轨契约。  
- 报告/台账对账 → **不**用本技能；用 `-Mode report/execute`。  
- 选 A 时：仍须产出简短【自主分析摘要】（可压缩为 8～12 行），帮助人审，但放行权在人。

## 7. DoD

- 范围/依据/版本清楚；逐项量规有证据，不空写“符合”。
- 独立分析指出风险/缺口/矛盾，不是复述清单。
- 结论 verdict + 阻断项/待补项/责任人；选 A/B 方式已记录。
