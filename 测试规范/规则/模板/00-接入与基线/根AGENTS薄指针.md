# 项目根 AGENTS.md（引导样例）

> 接入时把下方引导语句补入**项目根** `AGENTS.md`：已有则追加（不覆盖原文），没有则新建；勿放进 `测试规范/`。  
> 与项目根原有内容冲突时以原文为准；本会话只启用一包。  
> **多包同项目**：根 `AGENTS.md` 只做路由，不要逐包追加“本会话只启用本包”。已有多包时保留原文，在“已启用包”列表按实际包目录补齐（本包及同项目其它包各一行）：`- 测试规范：按 测试规范/AGENTS.md 执行；口令见其 AGENTS。` 三包会自动探测并共享 `项目资料/` / `activeContext.md`，无需额外协作目录或合同文件。

```markdown
# AGENTS.md

本项目启用 **测试规范** AI 工作流包。

1. 先完整阅读 `测试规范/AGENTS.md`，再按其口令 → `workflows/*.yaml` 执行。
2. 本会话只启用测试规范（落地通常只装本包）。
3. 与本文冲突时以本文为准；细则以 `测试规范/AGENTS.md` 为准。
```
