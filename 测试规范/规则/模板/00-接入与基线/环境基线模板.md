## 3. 常用接口与真值（Network 实测，禁止猜测）

> **页面路由 ≠ 本表**：本节为 **API** 真值；前端页面路由须单独记录（菜单 navigate 实测）。**禁止**由 `{API}/{资源}/list` 类推页面路由。  
> **读写分轨**：同一业务常拆「监控/列表（只读）」与「配置/管理（写操作）」；**写操作/启停**须登记在写操作页捕获行，并在「废弃/勿用」列标注误测 path（如 `…/channels/toggle-status`）。  
> **query 真值必填**：列表/看板/图表/预警类须记录**实际页面 Network 捕获的完整 query**（默认枚举、日期范围、状态域、`onlyMine` 等）；**禁止**仅写裸 `{/list?page=1&pageSize=20}` 充当终态真值。  
> **POST body 真值必填**（写操作/造数）：generate/save/submit 等须记录 **UI 成功同操作捕获的请求体键名**（非文档臆测）；400 字段报错时先对齐本表或本轮 capture。  
> **规则**：详情/子资源优先 `{模块}/{id}` REST 风格；`detail?xxxId=` 若 500 而 REST 200，以 REST 为准，**不得记功能失败**。每轮探索式测试前 `list_network_requests` 校准；变更同步本表。  
> **实例化**：示例行为**格式示例**，复制后删除，按 MCP 探查逐行追加；**勿**将某产品 path 写入本模板目录。

## 9. AI 会话注入

登录类用例优先路径（AI-API / AI-Hybrid）：

1. `POST {/api/auth/login}`（captcha 见 §1）取得 token
2. 浏览器 MCP 注入：`localStorage.setItem('{tokenStorageKey}', …)` 后访问 `{/home}`
   - 常见键名：`{app}-auth`、`token`、`accessToken`（以 Local Storage 实测为准）
3. 校验：`GET {/api/auth/userinfo}` code=200
4. token 脱敏存批次证据，禁止写入仓库明文；被测系统账号密码可按项目授权明文记录

### 9.1 实例化字段清单（执行效率 · 阶段一必填）

> **阶段一探查必填**（执行注入杠杆）：供执行阶段**会话注入 1 次/批次**直接复用；空壳项写「不适用 + 原因」。

| 项 | 值（实例化） |
| --- | --- |
| captchaApi | `{/api/auth/captcha}` |
| loginApi | `{/api/auth/login}` |
| userinfoApi | `{/api/auth/userinfo}` |
| loginBody 字段 | `{username}` / `{password}` / `{captchaId}` / `{captchaCode}` |
| token 响应路径 | `{data.token}` 等 |
| Cookie 名与格式 | `{Authorization: Bearer <TOKEN>}` |
| localStorage 键与 JSON | `{完整 persist 结构，<TOKEN> 占位}` |
| homeUrl | `{/home}` |
| 固定验证码（若有） | `{写在 §1}` |

> **会话形态按实测填写**：localStorage / sessionStorage 脚本注入、Cookie（脚本可写）、**HttpOnly Cookie（仅 UI 登录或等价接口，不支持脚本注入）**、Header Token 等任一形态；以本节实测为准，不适用项写「不适用 + 原因」。

## 12. 同步规则

1. 账号增删/停用 → 更新 **§1 / §4**；台账与用例中的编号保持一致
2. 路由/接口变更 → 同步 **§3**；新入口/404 映射 → 增补 **§3.2**
3. 执行中新发现 API 路径 → 回写 **§3**；新样本 → 增补 **§5～§7 / §14**；新造数链路 → 增补 **§11**；新冲突/停用形态 → 增补 **§15**；缺陷协作 → 增补 **§13**
4. 口令/凭据策略变更 → 更新 **§1**（§4 同步）
5. 浏览器能力变更 → 更新 **`测试/能力/`**，§8 只改索引指针；未启用时停问用户，禁止静默换实现
6. **回写纪律**：仅**新可复用**信息才增补（顺序/选择器/成功信号优先）；无新信息禁改基线
7. 脚本档启用/变更（executor、config、登录策略、已脚本化模块）→ 更新 **§16**；凭据只记环境变量名
8. 工具可用性变化 → 更新 **`测试/能力/00-能力清单.md`**（§17 仅索引；契约见 `测试规范/能力/00-能力契约.md`）。
