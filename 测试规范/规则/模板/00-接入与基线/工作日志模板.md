# 测试工作日志

> **落点**：`测试/工作日志.md`（测试包维护）。  
> **用途**：本岗**里程碑侧记**；最新在前。  
> **不是**：根 `CHANGELOG.md`（项目发版史，仅开发维护；本包禁写/禁建）、测试报告正文、计划 §16.1 执行日志。  
> **禁止**：创建/修改/补链根 `CHANGELOG.md`；用例清单/证据目录粘贴、密钥/PII。  
> **只记里程碑**（见事件类型）；琐碎进计划执行日志/台账。  
> **关账**：版本关闭/准出 ≠ 根发版史；可供开发发版核对，不写入根。  
> **年归档**：过长或跨年 → 用户确认后移 `测试/_归档/工作日志/`；不随业务版本整文件搬迁。

## 事件类型（选型）

| 类型 | 何时写一条 |
| --- | --- |
| 接入/治理 | 规范接入、基线/文档树落定 |
| 计划确认 | 测试计划门通过 |
| 轮次/准出 | 阶段准出或有条件准出 |
| 报告完成 | 测试报告门 PASS/CONDITIONAL |
| 重大 CR | C2/C3 或计划实质变更吸收 |
| 版本关闭 | 版本/迭代测试关闭归档（≠ 写根 CHANGELOG） |
