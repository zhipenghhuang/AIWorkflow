# 测试工作日志

> **落点**：`测试/工作日志.md`（测试包维护）。  
> **用途**：岗位**里程碑侧记**，人类可扫、可复查；最新在前。  
> **不是**：项目根 `CHANGELOG.md`（给人看的项目发版史，仅开发维护）、测试报告正文、测试计划 §16.1 执行日志（细粒度过程追加）。  
> **禁止**：创建或修改项目根 `CHANGELOG.md`；把用例清单/证据目录粘贴进本文件；密钥/PII。  
> **只记里程碑级事件**（见下方事件类型）；日常琐碎进计划执行日志/台账。  
> **年归档**：过长（约 >200 行）或跨年 → 列候选并**用户确认**后移入 `测试/_归档/工作日志/工作日志-{year}.md`，本文件留索引；**不随业务版本整文件搬迁**。

## 事件类型（选型）

| 类型 | 何时写一条 |
| --- | --- |
| 计划确认 | 测试计划门通过 |
| 轮次/准出 | 阶段准出或有条件准出 |
| 报告完成 | 测试报告门 PASS/CONDITIONAL |
| 重大 CR | C2/C3 或计划实质变更吸收 |
| 版本关闭 | 版本/迭代测试关闭归档 |
