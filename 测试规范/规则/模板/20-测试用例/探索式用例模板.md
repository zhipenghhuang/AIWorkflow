# 探索式测试用例（{主题短名} · {yyyyMMdd-HHmm}）

> **定位**：日常（无迭代窗口）持续测试 + 计划驱动探索式穿插——**补功能测试测不到/不便测的点**（组合/时序/异常/脏数据等）＋**细节与用户体验**；不替代迭代全量（功能全量为准出主轨）。  
> **详细度（适当加厚）**：章程可对账 + 前置三件套 + **步骤四列** + **同号判定/失败面** + oracle 来源 + 清理 + 执行提示 + 章程目标映射；比功能轨轻（无深度档全表/无模块常青评分卡），但须第二人可跟做。  
> **探索自由**：可多写细案；每条仍须可执行、可判定；禁臆造未见于主读/§0/现网的步骤。  
> **命名**：见 `规则/轨契约/探索式.md`「命名」节（同戳成对）。
