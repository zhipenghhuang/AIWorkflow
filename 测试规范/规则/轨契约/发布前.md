# 轨契约 · 发布前（边界轨 · 性能/安全/兼容）

> 口令生成/执行性能|安全|兼容时默读本文。  
> **计划驱动**：按 `测试/测试计划.md` §3.1 类型选择 + §3.2 专项资产 + §9.2 P5 生成/执行；本契约定专项执行细节，计划定范围/顺序/门禁。  
> **边界轨**：本包定风险分级、最小集、工具矩阵与判定纪律；具体场景库/脚本由项目自备；禁假装本包有完整菜谱。  
> **专项独立**：性能、安全、兼容各自独立目录、独立方案、独立报告、独立证据；**禁止一个方案里混写三项**。

## 风险分级（按变更/影响选最小集 · 选否写理由）

| 级别 | 适用 | 最小集 |
| --- | --- | --- |
| **基础级** | 小改/低风险 | 依赖与密钥扫描；关键接口 smoke；1 条核心性能基线；1 个代表浏览器/分辨率 |
| **标准级** | 版本级/多模块 | 基础级 + 性能 3 场景×3 次；SAST/SCA + 越权/IDOR + DAST（对外）；2 浏览器 + 移动端代表；迁移/回滚演练 |
| **高风险级** | 资金/权限/数据/公共 API/大促 | 标准级 + 全链路压测/长稳；全量安全；兼容矩阵；混沌/故障注入；回滚实战 |

## 工具矩阵（能力名 · 不绑品牌）

| 专项 | 主选能力 | 备选/降级 | 最小判定 |
| --- | --- | --- | --- |
| 性能/容量/长稳 | `perf-test`（k6/JMeter/Locust 任一） | 项目自备工具 | p95/p99、吞吐、错误率、资源；对照目标值 |

## 输入 / 输出

| 项 | 内容 |
| --- | --- |
| **输入** | SLA/目标值与来源；架构/关键链路；数据量级与分布；环境与生产差异；安全等级/合规；兼容矩阵；迁移/回滚方案；监控/APM |
| **输出** | 专项方案；原始数据/日志；指标对照表（目标 vs 实测）；瓶颈与根因线索；阻塞项；回滚证据；结论建议（准予发布/修复后复测） |

## 最小执行纪律

- **性能**：预热后计；≥3 次取中位/偏保守值；记录 p95/p99、吞吐、错误率、CPU/IO/慢查询；环境不可比须标限制，禁拿测试机冒充生产。
- **安全**：先过 SAST/SCA/密钥扫描；再验越权/IDOR、注入、上传、敏感数据；对外服务加 DAST；工具产物须人工复核，禁直接当结论。
- **兼容**：代表矩阵（最新/上一主版本、桌面/移动、2 分辨率）；重点端与退化端各 1；a11y 对外页面至少自动扫描一次。
- **迁移/回滚**：先 dry-run；核对行数/校验和/关键字段；回滚演练记录耗时与数据影响；不可回滚须显式风险接受。
- **成本**：基础级不跑全量压测/全量 DAST；标准级/高风险级按风险升级；工具运行与人工判读分离，AI 不替代测量工具。


## 脚本化通道（可选 · 发布前提速）

> 发布前轨中「可写死断言的子集」可用脚本档 0 token 回放；**测量类与需读报文语义的探查维持项目工具/AI**（本包不提供菜谱，见文首边界）。
> 纪律复用 `规则/专项/脚本执行.md`（判定/失败升级/口径单一）；脚本放 `测试/发布前测试/{性能|安全|兼容}/脚本/{NN}-{名称}.script.mjs`。

| 子集 | 通道 | 说明 |
| --- | --- | --- |
| 安全负向 smoke（无 token / 越权 / 参数边界 → 4xx 且无脏写） | `executor --mode=api` | 断言 `expectStatus`/`expectMessage`；造数走 `api` |
| 兼容/可用性 UI 断言（入口可打开、关键元素可见、无报错） | executor UI 模式 | 断言 `assert`/`wait`；失败自动截图 |
| 性能/容量/负载测量 | 项目自备工具或按 `能力/00-能力注册表.md` 选装（perf-test；本包不绑定） | 不可用=按项目方法执行；方案/报告字段照本轨契约 |
| 一次性的口径探测、判读型结论 | AI 直跑 | 不脚本化 |

- 结果：执行时以 `--draftDir=测试/发布前测试/{性能|安全|兼容}/.draft --evidenceDir=测试/发布前测试/{性能|安全|兼容}/证据` 指定本专项落点（jsonl 同格式）；报告「指标对照表」/结论仍由 AI 按本轨字段汇总。
- 失败升级：同 `规则/专项/脚本执行.md` §3（有界复核，一次为限）。

## 红线

- 停用（已废弃）资产被点名执行时先提醒一次；其余照常执行。  
- 通过准则须可判定（数值/清单/观察项）；禁空泛「测试完成即通过」；指标须写明目标值与来源。  
- **硬映射无空行**（未跑须标缺口+接受人）方可称「本风险级最小集已完成」。  
- **阻断项**：安全 critical/high 未闭环、性能未达目标且用户未接受、兼容/迁移阻断项未解决、发版准出时最小集未完成 → 不得判发布通过。  
- **环境/数据可比**：记录测试环境与生产差异、数据量级；不可比须标限制，禁拿测试机结论冒充生产。  
- 「已执行/通过/达标」结论须绑定可复核产物路径（报告/数据/日志），缺产物不得声称。
- 能力按 `能力/00-能力注册表.md` 选装（perf-test / sec-scan / a11y / visual-reg）；不可用禁假称已测。  
- 工具与脚本可自选或现写；结论写入方案/报告；拟提交走门3（YAML）。  
- 【任务收尾】第 1 点「汇报」：结论说明体一整段（导语加粗；测了什么/对照达标线/问题/建议写入正文），供人审与发布决策；骨架见 `../AGENTS.md` §5。  
- 不与功能全量 DraftPath 接力；证据落本专项目录。  
- **中断续跑**：按已落盘阶段产物核对完成度，从首个未完成阶段接续；不重跑已完成阶段。  
- 项目无方案/场景时：一问补资产或接受缺口，**禁编造指标后宣称已测**。
