# 轨契约 · 随机业务流程测试

> 口令命中「随机业务流程 / 业务随机」生成或执行时默读本文。主链 step 仍用 `testing.yaml`。  
> **定位**：对本版「该有的本事」做有结构随机体检（主读影响面 + 常青抽样）；**适当**带功能用例未覆盖的坑。  
> **计划外**：**不进** `测试/测试计划.md`、不占 P0～P9、不参与准出对照；「按计划执行」**不**调度本轨。准出与常青保证仍由计划内功能/冒烟/前序/回归承担。

## 主读与版本窗

- **主读**：与功能/探索同构——用户点名或门1 确认；其它文档仅**有界参考**，禁把参考版扩成主读范围。
- **版本窗**：**当前最新**，或**最多落后一个版本（N-1）**；更旧主读默认拒绝（须用户明示例外并写入本轮 §0）。
- **范围构成**（生成与门2 摘要必带）：
  - **主读影响面**：本期增量/变更相关核心能力与邻接走法；
  - **常青不变点**：跨版本仍应可用的主路径能力（抽样，非全量用例搬运）；
  - **未入库坑（辅）**：功能资产未覆盖的发现点。
- **比例**：本事体检（影响面 + 常青随机）**≥约 70%**；未入库坑 **≤约 30%**。辅项超限须收尾说明或拆到探索式口令。

## 命名（含时间 · 不可让）

> 轮次可并列；**文件名必须带本轮时间戳**。戳取落盘时本机本地时间。

| 产物 | 命名 | 例 |
| --- | --- | --- |
| 用例 | `测试/随机业务流程测试/{主题短名}-{yyyyMMdd-HHmm}-用例.md` | `…/方案评价体检-20261027-1200-用例.md` |
| 台账 | `测试/随机业务流程测试/{主题短名}-{yyyyMMdd-HHmm}-执行台账.md` | 同戳 |
| 证据 | `测试/随机业务流程测试/证据/{主题短名}-{yyyyMMdd-HHmm}/` | 叶名含 caseId |
| 会话记录（可选） | `测试/随机业务流程测试/.draft/{主题}-{yyyyMMdd-HHmm}-session.md` | — |

- **同戳成对**：用例与台账（及证据子目录）共用同一戳；禁错配。
- **新开一轮**：新戳、新文件对；旧轮默认保留并列。
- **续跑**（「继续」同会话）：沿用本轮已落盘戳，不另开戳。
- **归档**：用户点名或版本关闭时旧轮整对移入 `测试/随机业务流程测试/_归档/{yyyyMMdd}/`；**禁**进根 `测试/_归档/`。

## 红线

- 用例 ID：`RND-{NN}`（台账合并按此识别）；禁纯数字/下划线。
- **生成必对照随机模板**：步骤四列；预期含失败判定；§3 清单覆盖与占比自检必填；超占比须说明或拆探索式口令。
- 禁臆造未见于主读/现网的业务步骤；禁把参考文档当主读扩范围；建议读分析表 §0 对齐差量。
- 禁替代 P0-Smoke / 功能全量 / 计划内常青准出；禁「按计划执行」静默跑本轨。
- 不脚本化（同探索式）；先 UI 再 Network；证据落本轨目录；禁抬高通过率。
- 收尾禁空泛「随机通过」；须写主读/版本窗、影响面与常青覆盖、占比、缺口、建议补功能用例、发现分流。
- 缺陷测试类型用 **`随机`**；修复后回归走计划内回归策略（原单 + 冒烟 + 影响面），不以本轨轮次冒充回归闭环。
