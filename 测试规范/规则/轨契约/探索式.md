# 轨契约 · 探索式测试

> 口令命中「探索式 / 探索测试」生成或执行时默读本文。主链 step 仍用 `testing.yaml`。  
> **定位**：补功能测试测不到/不便测的点 + 细节体验；**不替代迭代全量**（功能全量为准出主轨）。  
> **计划驱动**：按 `测试/测试计划.md` §12 探索章程穿插执行；独立口令可即兴探索（不要求计划）。  
> **互斥**：本版「该有的本事」主内容随机体检（影响面+常青）→ **计划外** `轨契约/随机业务流程.md`，不塞进本轨。

## 边界

| 项 | 约定 |
| --- | --- |
| 正式产物 | `测试/探索式测试/`（正式目录；命名见下） |
| 过程 | `测试/探索式测试/.draft/` |
| 执行门 | 独立口令：无 00 索引强制；门1（主读未点名）/门2（范围）仍按 YAML；**不触发计划步/计划门**（随时可跑）。计划驱动：按计划 §12 章程 + §9.2 P4 排期。 |
| 覆盖 | **软**：主读场景点/章程目标有对应用例或显式不测原因；【生成/执行收尾】写章程完成/覆盖/缺口 |
| 侧重 | **补功能测试测不到/不便测的点**：组合边界、非常规路径与状态、时序/并发、异常与脏数据、跨模块组合、重复/长时操作；**细节与用户体验**：文案准确性、操作反馈、易用性、空态与异常提示、基本视觉、**展开/下钻后邻接布局是否别扭（有见则记，不硬判设计对错）**——日常无迭代窗口时多写细案；不替代迭代全量 |
| 骨架 | AI 自拟、**轻量字段齐**（章程 ID／前置三件套／同号步骤·预期／清理／执行提示；模板 `规则/模板/20-测试用例/探索式用例模板.md`）；禁臆造未见于主读/现网的业务步骤 |

## 章程（计划驱动）

- 计划 §12 给 3～6 条**按风险排序**的章程：主题｜目标/风险｜范围/路线｜时间盒｜数据/账号｜触发/排期｜输出。
- 每场按 SBTM 节奏：mission → 范围/路线 → 时间盒 → 记录（发现/覆盖/疑问）→ debrief。
- 发现分流：产品缺陷 → 缺陷 + 回归；覆盖缺口 → 补用例/补章程；误报 → 记录。
- 独立口令可即兴探索；计划驱动按章程穿插，不替代功能全量。

## 命名（含时间 · 不可让）

> 探索轮次多、可并列；**文件名必须带本轮时间戳**，便于区分与对照。戳取落盘时本机本地时间。

| 产物 | 命名 | 例 |
| --- | --- | --- |
| 用例 | `测试/探索式测试/{主题短名}-{yyyyMMdd-HHmm}-用例.md` | `…/登录越权-20261015-1430-用例.md` |
| 台账 | `测试/探索式测试/{主题短名}-{yyyyMMdd-HHmm}-执行台账.md` | `…/登录越权-20261015-1430-执行台账.md` |
| 证据 | `测试/探索式测试/证据/{主题短名}-{yyyyMMdd-HHmm}/` | 叶名仍含 caseId |
| 会话记录（可选） | `测试/探索式测试/.draft/{章程ID}-{yyyyMMdd-HHmm}-session.md` | `…/{章程ID}-{yyyyMMdd-HHmm}-session.md` |

- **同戳成对**：同轮用例与台账（及证据子目录）共用同一 `{yyyyMMdd-HHmm}`；禁用例新戳、台账旧戳错配。  
- **新开一轮**（「生成/重写探索式」）：新戳、新文件对；旧轮默认保留并列。  
- **续跑**（「继续」同会话）：沿用本轮已落盘戳与台账，**不另开戳**。  
- **归档**：用户点名或版本关闭时旧轮整对移入 `测试/探索式测试/_归档/{yyyyMMdd}/`；**禁**进根 `测试/_归档/`（过程清理见 `../工作流.md` §1.3）。  

## 红线

- 用例 ID 用 `{前缀}-{NN}`（首字符为字母、连字符分段，如 `EXP-01`；台账合并计数按此识别）；禁纯数字/下划线。  
- 禁臆造未见于主读/现网的业务步骤。  
- 探索辅助（可选）：装配 vision-ui（`能力/00-能力注册表.md`）时可用自然语言＋截图断言辅助判定；结论仍须可对照主读/现网。  
- 执行与落账细则见 `规则/专项/多Agent与输出.md`（jsonl/台账六态与功能轨一致）；计划驱动跨轨见 §4。  
- 证据落本节命名目录，禁抬高通过率。  
- 结果难标准化属预期；收尾须写清章程完成/探索范围与缺口，禁空泛「探索通过」。  
- 探索式不脚本化（`规则/专项/脚本执行.md` §6）；session 记录/debrief 必做，发现须分流。
