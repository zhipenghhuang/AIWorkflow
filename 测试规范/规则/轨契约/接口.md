# 轨契约 · 接口（正式轨）

> 口令「生成接口测试资产」/「执行接口测试」时默读本文。  
> **计划驱动**：按 `测试/测试计划.md` §3.2 接口资产 + §9.2 P3 生成/执行；本契约定接口执行细节，计划定范围/顺序/门禁。

## 边界

| 项 | 约定 |
| --- | --- |
| 正式产物 | `测试/接口测试/`（契约表 + 用例清单 + 台账 + `脚本/`）；P0 接口冒烟登记 `测试/00-稳定冒烟清单.md`（其余脚本在 `测试/接口测试/脚本/` + tags） |
| 过程 | `测试/接口测试/.draft/` |
| 执行门 | 门1（主读未点名）/门2（确认接口范围与环境）/门3（独立生成且有拟入库，`generate` 步条件触发） |
| 执行形态 | **脚本优先**：确定性接口用例默认 `executor --mode=api`；AI 单 Agent 只做契约探查、语义判定、失败复核、脚本生成/维护；**不必** Worker/Reviewer；**不默认** browser-mcp |
| 覆盖 | **对照可全维、执行分层**：契约表内每个必测接口 → 各适用维度填 用例ID 或「不适用+依据」（**覆盖对照禁空**）；**默认可执行/可脚本=高风险维**；`depth=full` 或发版/点名才补齐其余维脚本。已有资产先打开命中域增量更新，不重写未受影响项；无域文件才按域首生 |
| 依据 | 主读 + 现网 Network；**禁猜**未见 path/字段 |

## 产物最低字段

| 产物 | 最低字段 |
| --- | --- |
| 契约表 | 模块 ｜ 接口名 ｜ 方法+path ｜ 关键参数 ｜ 响应码/关键字段 ｜ 来源（基线 §3 已登记 或 本轮实测） |
| 覆盖对照 | 每个必测接口一节：维度 → 用例ID 或「不适用+依据」（对应「覆盖维度」表；**禁空**） |
| 用例条 | ID ｜ 场景 ｜ 接口（方法 path）｜ 前置（账号域/数据）｜ 请求要点 ｜ 期望（码+关键字段）｜ 负向类标签 ｜ 依据 |
| 脚本 | `测试/接口测试/脚本/{NN}-{模块}.script.mjs`：caseId ｜ `api` 动作 ｜ 断言 ｜ `tags`/`suites` ｜ 契约版本 |
| 台账行 | caseId ｜ 接口 ｜ 预期 ｜ 实际（码+关键字段）｜ 判定 ｜ 证据 ｜ 备注 |

## 覆盖维度（**每个必测接口逐适用维 ≥1 条**；不适用须声明「不适用+依据」）

| 维度 | 最低 |
| --- | --- |
| 成功契约 | 每个必测写/关键读：成功码 + ≥2 关键字段 |
| 无 token / 失效 | 写接口 ≥1：401/未授权且无脏写 |
| 越权 | 有平行/低权账号 ≥1：拒绝且无脏写；无账号声明跳过 |
| 参数边界 | 写接口 ≥1：空/非法/停用引用 → 拒落库 |
| 超长 / Emoji 写入 | 写接口 ≥1：超长字段 / emoji 正确受理或明确拦截，无截断/乱码 |
| 非法状态与假成功 | 适用写 ≥1：终态重入等被拒；**2xx 但未落库/状态不变 = 失败** |
| 幂等与并发 | 高风险写（create/assign/confirm/close 等）各 ≥1：无双写/双成功 |
| 查询特殊字符 | 关键词检索 ≥1：`%`/`_` 不得扩大命中 |
| 不存在资源 | ≥1：明确 4xx；**200 空壳（data=null 等）= 失败** |
| 分页边界 | 列表 ≥1：page/pageSize 非法值须明确拦截或受控回落 |
| 错误 METHOD | 代表接口 ≥1：4xx |
| 排序 | 有 orderBy/sort 时 ≥1 |

## 判定与执行纪律

- **判定三要素**：状态码 + 业务码/业务信号 + 关键字段值；**仅 2xx 不得记通过**。
- 写条**写后回查**（列表/详情复核）；**假成功 = 失败**。
- 无 token/越权条用**隔离上下文**（不带登录态），防已登录会话导致假 401/假通过。
- 失败要点：方法+path+关键参数+码/消息（无密钥）；复核后仍失败才落终态。  
- **中断续跑**：以台账已有终态为准，从首个未完成条继续；已判定条不重跑（用户点名重测除外）。  

## 脚本优先（默认 · 接口轨提速）

> 接口用例天然可脚本化（HTTP + 断言）；**确定性用例默认脚本**，回归 0 token、无浏览器。纪律见 `规则/专项/脚本执行.md`。

- 执行器：`测试/脚本/executor.mjs --mode=api --draftDir=测试/接口测试/.draft --evidenceDir=测试/接口测试/证据`；接口脚本放 `测试/接口测试/脚本/{NN}-{模块}.script.mjs`。  
- **生成即脚本**：可脚本化=是 → 用例与脚本同轮产出；不可脚本化须写理由（语义判定/一次性/依赖未定），禁默认只出用例。  
- 登录钩子：`config.apiLogin`（返回鉴权头对象）；步骤动作限 `api`（`expectStatus`/`expectMessage`/`expectFields`/`save`）与 `note`；无 token/越权用隔离上下文。  
- **域常青 + suite**：脚本按模块/契约维护；跨版本保留主档；只更新受影响 endpoint。回归选型：`--suite=core|module|full`（或 tags）；**P0 接口冒烟**→`测试/00-稳定冒烟清单.md`；默认跑高风险维，full 维发版加跑。轨内 `_归档/` 仅下线域/重生快照/点名旧轮；**禁**关账整轨搬走现行；**禁**进根 `测试/_归档/`。  
- **契约漂移**：breaking change 必须新增/更新用例与脚本；禁因换代重写全套；半残合并≥2 次 → 有界重生该接口域。  
- 落账：jsonl → `merge-ledger.mjs` 合并接口台账；失败升级同 `规则/专项/脚本执行.md` §3（有界复核）。  
- AI 只做：契约探查、语义/业务规则判定、脚本生成/维护、失败复核；**不逐步点击 UI 替代接口调用**。  

## 能力（可选 · 见 `能力/00-能力注册表.md`）

| 能力名 | 用途 | 降级（未安装） |
| --- | --- | --- |
| api-client | 契约初稿导入/集合回放（Postman 集合、OpenAPI；或 hurl/bruno 文本化脚本） | 现行「主读 + 现网 Network」 |
| api-fuzz | 对 OpenAPI/契约自动生成属性与负向候选（并入「接口 × 维度」对照的负向候选） | AI 按维度表现场设计 |
| contract-test | 消费方契约验证（pact / specmatic） | 按「成功契约」维度抽样 |
| mock-server | 依赖未交付/异常注入/前置构造 | 基线 §11 造数索引 |

- api-fuzz 产物只作**候选**：仍须按覆盖对照逐条判定，**禁**自动判通过或直接落账。
- 经 mock 取得的结论不得冒充真实链路结果；真实链路不可用时按阻塞口径处理。

## 红线

- path/方法/关键字段以实测或主读原文为准；文档与现网冲突须标明以何为准。  
- 用例 ID 用 `{前缀}-{NN}`（首字符为字母、连字符分段，如 `API-01`；台账合并按此计数）。  
- **覆盖对照禁空**：必测接口 × 适用维度既无用例 ID 也无「不适用+依据」＝未完成，禁称已覆盖。  
- **脚本默认**：可脚本化接口用例未产出脚本且无理由 = 未完成；回归优先脚本档，禁 AI 逐步点击替代接口调用。  
- **域常青**：接口用例/脚本跨版本保留；只更新受影响 endpoint；**禁**因换代删除现行后整包重生成；`_归档/` 仅下线/重生快照/点名旧轮。对照维可全、执行维默认可少于对照（须在台账/计划声明 depth）。  
- 契约初稿可援引项目已有接口文档/工具导出（OpenAPI、Apifox、Postman 等），**入库前以实测或主读校正**；禁未验证导入直接判通过（api-client 见「能力」节）。  
- 与功能 UI 结论分轨：本轨不冒充页面通论。  
- 需要浏览器仅当契约明确依赖页面触发的请求；否则用 HTTP/客户端按契约测。
