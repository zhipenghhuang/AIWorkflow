# 验证与准出（测试轨）

> **单一出处**：报告↔台账↔证据↔P0 的对账规则、完成状态与报告措辞。`AGENTS.md` 只留指针；`验证/README.md` 是操作入口。
> **读取时机**：`review-cases`、`execute` 批末、`report`、`handoff`/交平台前。维护读 `规则/核心/规则治理.md`。

## 1. 不变量（带 ID）

| ID | 不变量 |
| --- | --- |
| TEST-VER-01 | 报告数字必须来自台账**本轮装填**计数；台账 §1.1 与结果表本轮行一致，禁止手改通过率；`未本轮验证` 不得计入通过率。 |
| TEST-VER-02 | P0 未通过不得判整体通过；“有条件通过”仅限 P0 全过、缺口非 P0 且用户接受。 |
| TEST-VER-03 | 失败/阻塞/待实现（实现缺陷）必须有证据或已尝试/恢复条件；证据路径必须可打开。 |
| TEST-VER-04 | 未测项、覆盖缺口、口径待探查、环境缺口、**未本轮验证规模**必须显式列出，不以“已执行/库内曾通过”替代“本构建已覆盖”。 |
| TEST-VER-05 | 报告先写中文回执结论（可准出/有条件准出/不准出/阻塞），并与门 JSON 一致；非“可准出/有条件准出”禁用“全部通过/可发布”。 |

| TEST-VER-08 | 门读现有计划/台账/报告/评审记录，不无中生有；解析不了不猜，不得给 PASS（按 FAIL/BLOCKED）。 |

## 2. 完成状态

| 状态 | 条件 | 报告措辞 |
| --- | --- | --- |
| `PASS` | P0 全过；**本轮装填**未执行=0；本轮台账/报告一致；准出评估=PASS；证据可打开；无未接受缺口 | 通过/可准出 |
| `CONDITIONAL` | P0 全过；缺口非 P0；准出评估=CONDITIONAL 且用户书面接受 | 有条件通过；列遗留 |
| `FAIL` | 任一 P0 失败；准出评估=PASS 但有失败/本轮未执行；关键证据缺失；数字不一致 | 不通过；列失败 |
| `BLOCKED` | 环境/输入/回执缺失；无法对账 | 阻塞/未验证 |

> 中文回执映射：可准出=PASS｜有条件准出=CONDITIONAL｜不准出=FAIL｜阻塞=BLOCKED｜未验证=NOT_VERIFIED。报告/收尾写中文，机器对账仍读 JSON 英文值。

## 3. 对账规则

- 台账 §1.1 本轮装填 ↔ §2 结果表中非 `未本轮验证` 行：总数/通过/失败/阻塞/未执行/待实现/不适用逐项一致；只统计当前台账，`_归档`/`.draft`/`资料` 不参与对账。
- `未本轮验证` 只进 §1.2；**不**进报告 §4 通过率分母/分子。
- `待实现`=实现缺陷，计入缺陷合计/交平台；不得当未测；范围外→不适用。
- 报告 §4 统计 ↔ 各台账 **本轮装填**汇总；不一致先修报告/台账，不得直接写准出。
- `writeback` 模式只核回执（单号/备注/状态/附件），不要求计划/台账存在。
- 报告 §1 准出评估 ↔ P0/缺口：P0 未过不得写“通过”；有条件通过必须有接受人/遗留项；须声明本轮 runId/构建与 suite/depth。
- 覆盖：功能全量/专项 §3 映射无空行；P0 点有用例或“不适用+依据”；§4 须有深度档自检与视觉基础摘要（机器核存在性；语义深度由评审/AI 量规）。
- 阻塞：摘要含已尝试≥2/恢复条件；缺数据/缺样本先造/换，不写阻塞；方案/AC 范围内未实现（菜单无入口且无接口）→待实现（实现缺陷），入口存在但 404/500/空壳→失败；均不写阻塞。
- 回写：单号/备注/状态/附件回执；备注与状态同轮；`writeback` 模式只核回执。
- 回执归属：report 读 `.gate/测试规范/report.json`、execute 读 `execute.json`、writeback 读 `writeback.json`；核对 `package=测试规范` 与本轮 `gate_id`/`timestamp`。writeback 不得覆盖 report；不符=未验证。
- P0 计划覆盖：计划 §3.7/§9.2 与 `00-稳定冒烟清单` 中的 P0 用例必须在台账中存在且为**本轮终态**（不得为未执行/未本轮验证）；缺失 = FAIL。

## 4. 成本纪律

- **步后门**：域批末 `execute -Scope {域路径片段}`（只对 Scope 内台账本轮行）；缺 Scope 且无法推断 → BLOCKED。
- **准出门**：版本级 `report`——聚合各现行台账的**本轮装填**计数（忽略 `未本轮验证`）；仍扫描各轨现行台账文件，但计数口径=本轮。
- execute 的 `coverage-map`/`p0-missing` = soft；report 硬。禁把无 Scope 全仓 FAIL 写成「本批不准出」。
- 证据失败/阻塞必看；不要求每条通过截图；不每补丁全量回归；不新增测试文档。
