# 文档治理（资料 + 工作文档）

> 单一出处：外部资料收取/分类/对照/归档 + 工作文档生命周期/归档/清理。旧 `资料治理.md`、`文档生命周期.md` 仅保留指针。
> 铁律：**先扫描分类 → 输出候选 → 用户确认 → 才改名/移动/标记失效/归档/清理**；未确认前只读。
> 安全：证据、当前计划/报告、源文件、用户文件、密钥、`.git` 永不自动删除；拿不准 → 待确认或移 `_归档/_待清理/`。

## 1. 两个区，三种模式

| 区 | 放什么 | 不放什么 |
| --- | --- | --- |
| `测试/资料/` | 外部输入、只读证据（扁平，按类型前缀命名） | 测试计划/用例/台账/报告/脚本/证据等本包工作产物 |
| `测试/功能测试/` 等轨目录 | 本包工作产物 | 外部原件（放 `测试/资料/`） |

- **单包资料根**：`测试/资料/`；**多包**：共享根 `项目资料/`，本包 `资料/` 只放专属/历史资料。
- **资料模式**：`keep` 原位只读；`mix` 原位只读 + 新文件引用/摘要（默认）；`replace` 可改名/移动，列清单确认后执行。
- **单一主副本**：一份文件只保留一个主副本；跨包只引用，不复制多份。

- 无法判断 → 保持原名，状态=`待确认`，问一次；不先移动。

## 3. 资料收取

1. **识别**：扫描本包资料根 + 既有资料目录（keep/mix）+ 项目根（replace/用户投放）的未登记/变化文件、索引断链、内容哈希变化。
2. **读取**：先读标题/目录/开头与显式变更段，需要时再读关键段，不整篇读；提取标题、版本/日期、范围（模块/页面/接口/AC/专项）、显式「替代/废止/全量更新」。
3. **分类**：按 §2 定主类型；不确定 → `待确认`。
4. **对照**：找同类型 + 同主题旧文件，比较覆盖范围；不要只看版本号。
5. **输出【资料收取与归档候选】**：分类、归属、采纳建议（引用/摘要/复制/迁移）、对照关系、建议归档/保留/待确认；**此时不改索引、不改名、不移动、不标记失效**。
6. **确认后**：改名/登记 → 旧文件标 `失效`（仅确认归档时）→ 移 `测试/_归档/{yyyyMMdd}-{版本或批次}/资料/` → 写 `归档清单` → 更新索引/计划/报告/activeContext。

**覆盖关系**：全量替代（旧版可归档）｜全量覆盖（旧版可归档）｜部分覆盖（保留旧版）｜增量补充（保留）｜仅新增（保留）｜重复（可归档）｜冲突（停下问，不归档）。

**失效依据**：S1 全量替代；S2 全量覆盖；S3 重复；S4 需求删除/版本取消；S5 用户明确失效。禁止按时间年龄归档。

## 4. 工作文档四类

| 类型 | 判定 | 动作 |
| --- | --- | --- |
| 长期/固定 | 跨版本稳定真值/规范/主档 | 就地更新，不随迭代归档 |
| 版本/迭代绑定 | 只服务某版本/主题 | 关闭时快照/归档；当前版本保留 |
| 失效/替代 | 被新版本全量替代、需求删除、版本关闭 | 旧版归档；部分覆盖保留 |
| 过程/临时 | `.draft/`、草稿、缓存、失败产物、重复文件 | 清理候选；确认后删除或移 `_待清理/` |

本包清单：

| 文档/目录 | 类型 | 处理 |
| --- | --- | --- |
| `环境基线.md`、`activeContext.md`、`测试/测试计划.md`、`测试/测试报告.md` | 长期/当前版本 | 就地更新；版本关闭时计划/报告快照到 `_归档`，当前档不移动 |
| 根 `CHANGELOG.md` | 长期 | 版本/迭代关闭、报告完成更新；不随版本归档 |
| `测试/00-稳定冒烟清单.md`、可复用脚本、基线 | 长期 | 保留/更新，不随换代整包归档 |
| `测试/功能测试/`（用例/台账/评审/证据/分析短表） | 版本/迭代绑定 | 版本关闭归档；当前版本保留 |
| `测试/接口测试/`、`测试/探索式测试/`、`测试/发布前测试/` | 版本/迭代绑定 | 版本关闭归档；当前版本保留 |
| `测试/变更/CR-*` | 版本绑定 | 版本关闭归档 |
| `测试/资料/` | 外部输入 | 按 §3 收取/对照/归档 |
| `**/.draft/`、失败导出、未引用截图、重复文件 | 过程/临时 | 清理候选；确认后删除或移 `_待清理/` |

## 5. 更新还是归档

| 情况 | 动作 |
| --- | --- |
| 长期真值/主档变化 | 就地更新；变更前后写 CR/变更记录，不归档主档 |
| 当前版本用例/台账局部变化 | 就地更新受影响条目；旧结论覆盖，只留最新 |
| 新版本计划全量替代旧计划 | 新版=现行；旧版=失效，确认后快照/归档 |
| 新版本只改一个模块 | 旧计划保留并更新未覆盖部分；不归档 |
| 版本/迭代关闭，文档只服务该期 | 整个版本绑定目录归档；主档/基线/稳定冒烟不动 |
| 需求删除/版本取消 | 相关文档标失效；确认后归档 |
| 过期但仍有参考价值 | 保留为参考，不归档 |
| 重复/空文件/无引用 | 清理候选；确认后删除或移 `_待清理/` |

判定原则：版本号新 ≠ 全量替代；以覆盖范围为准；正式资产只写现行有效；报告滚动更新只留最新口径。

## 6. 版本/迭代关闭

1. 更新测试计划 §0/§16.1/§16.2、测试报告、activeContext、根 `CHANGELOG.md`。
2. 版本关闭：计划/报告/CR/关键证据快照到 `测试/_归档/{yyyyMMdd}-{版本}/`；当前 `测试/测试计划.md` 不移动。
3. 版本绑定用例/台账/证据/CR 整体归档；只归档已确认项。
4. 按 §5 扫描：全量替代/关闭版本/需求取消 → 归档候选；部分覆盖 → 保留并更新。
5. 写 `归档清单`（原路径/归档路径/类型/依据/替代/校验/日期）。
6. 清理过程/临时文件：按 §7 出候选，确认后执行。
7. 更新资料索引/计划/报告/activeContext；跑引用检查。

## 7. 过程/临时文件清理

- 扫描 `测试/` 与项目根顶层；跳过 `.git/`、代码依赖/构建产物/模板目录。
- 候选：`.draft/`（未被计划/报告/评审引用）、`*.tmp/*.temp/*.bak/*.log`、`~$*/ .DS_Store / Thumbs.db / desktop.ini`、`* (1).*/*副本*/0 字节未引用`、未引用导出/下载/截图/临时 JSON。
- 永不自动删除：正式资产、当前计划/报告、证据、源文件、模板、`.git`、`.env`/密钥、拿不准的文件。
- 执行：列【清理候选】（路径/类型/原因/大小/引用/动作）；确认后已知临时文件可删，不确定移 `_归档/_待清理/{yyyyMMdd}/`；写清理清单；更新 activeContext。
- 禁止业务任务中途顺手删除；只在关闭/巡检/点名「清理」时执行。

## 9. 触发

| 时点 | 动作 |
| --- | --- |
| 接入/重新接入 | 扫描资料/工作文档；建索引；旧结构列迁移/归档/清理候选 |
| 新版本/新迭代替换旧文档 | 按 §5 判定更新/归档；不全量替代不归档 |
| 版本/迭代关闭 | 按 §6 快照/归档/清理 |
| 用户点名「资料整理/文档整理/巡检/清理」 | 扫描 → 候选 → 确认 → 执行 |
| 季度/月度（可选） | 只扫描出候选，不移动 |
