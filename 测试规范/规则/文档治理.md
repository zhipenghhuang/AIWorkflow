# 文档治理（资料 + 工作文档）

> 单一出处：外部资料收取/分类/对照/归档 + 工作文档生命周期/归档/清理。
> 铁律：**先扫描分类 → 输出候选 → 用户确认 → 才改名/移动/标记失效/归档/清理**；未确认前只读。
> 安全：证据、当前计划/报告、源文件、用户文件、密钥、`.git` 永不自动删除；拿不准 → 待确认或移 `测试/_归档/_待清理/`（仅跨轨临时/不确定清理，不含各类测试资产与资料）。

## 1. 两个区，三种模式

| 区 | 放什么 | 不放什么 |
| --- | --- | --- |
| `测试/资料/` | 外部输入、只读证据（**版本/主题子目录**，见 §2） | 测试计划/用例/台账/报告/脚本/证据等本包工作产物 |
| `测试/功能测试/` 等轨目录 | 本包工作产物 | 外部原件（放 `测试/资料/`） |

- **单包资料根**：`测试/资料/`；**多包**：共享根 `项目资料/`，本包 `资料/` 只放专属/历史资料。
- **资料模式**：`keep` 原位只读；`mix` 原位只读 + 新文件引用/摘要（默认）；`replace` 可改名/移动，列清单确认后执行。
- **单一主副本**：一份文件只保留一个主副本；跨包只引用，不复制多份。

## 2. 资料目录与命名（版本/主题子目录 · 非扁平）

```text
测试/资料/
├─ 资料索引.md
├─ 项目文档/                         # 设计输入主区（默认）
│  ├─ README.md / 业务流程.md / …    # 跨版本通用：平铺在 项目文档/ 根
│  ├─ V1.5/                          # 版本或主题子目录
│  ├─ V2.0/
│  ├─ APS-2.2.0/ … APS-2.5.0/
│  ├─ IoT-2.6.0/
│  └─ V2.7.0/
├─ 测试数据/                         # 样本/造数说明/账号配方
├─ 交接/{HO-ID}/                     # 收到的外部交接包（只读）
└─ _归档/{yyyyMMdd}-{版本或批次}/    # 仅失效资料（确认后）
```

- **默认结构**：`测试/资料/项目文档/{版本或主题}/`；通用文档平铺在 `项目文档/` 根下；**禁止**把资料强制压成类型前缀扁平单层。
- 子目录名用版本/主题（如 `V2.7.0`、`APS-2.2.0`），文件名保持原文档名（或项目既有命名）；索引登记类型/主题/版本/状态。
- 测试计划/用例/台账/报告/脚本/证据不进资料区。
- 无法判断归属 → 保持原名与原目录，状态=`待确认`，问一次；不先移动。
- **旧扁平残留**：若实例仍有 `测试/资料/PRD-*.md` 等平铺文件，可保留并在基线 §2.1/`资料索引` 登记；新资料默认进 `项目文档/{版本或主题}/`，不要求回迁扁平。

## 3. 资料收取

1. **识别**：扫描本包资料根 + 既有资料目录（keep/mix）+ 项目根（replace/用户投放）的未登记/变化文件、索引断链、内容哈希变化。
2. **读取**：先读标题/目录/开头与显式变更段，需要时再读关键段，不整篇读；提取标题、版本/日期、范围（模块/页面/接口/AC/专项）、显式「替代/废止/全量更新」。
3. **分类**：定归属子目录（版本/主题）与资料类型（PRD/迭代/原型/设计…，写索引，不靠强制改文件名）；不确定 → `待确认`。
4. **对照**：找同主题/同版本旧文件，比较覆盖范围；不要只看版本号。
5. **输出【资料收取与归档候选】**：分类、归属、采纳建议（引用/摘要/复制/迁移）、对照关系、建议归档/保留/待确认；**此时不改索引、不改名、不移动、不标记失效**。
6. **确认后**：登记/按需改名落位 → 旧文件标 `失效`（仅确认归档时）→ 移 `测试/资料/_归档/{yyyyMMdd}-{版本或批次}/` → 写同批 `归档清单` → 更新索引/计划/报告/activeContext。

**覆盖关系**：全量替代（旧版可归档）｜全量覆盖（旧版可归档）｜部分覆盖（保留旧版）｜增量补充（保留）｜仅新增（保留）｜重复（可归档）｜冲突（停下问，不归档）。

**失效依据**：S1 全量替代；S2 全量覆盖；S3 重复；S4 需求删除/版本取消；S5 用户明确失效。禁止按时间年龄归档。

## 4. 工作文档四类

| 类型 | 判定 | 动作 |
| --- | --- | --- |
| 长期/固定 | 跨版本稳定真值/规范/主档 | 就地更新，不随迭代归档 |
| 版本/迭代绑定 | 只服务某版本/主题 | 关闭时快照/归档；当前版本保留 |
| 失效/替代 | 被新版本全量替代、需求删除、版本关闭 | 旧版归档；部分覆盖保留 |
| 过程/临时 | `.draft/`、草稿、缓存、失败产物、重复文件 | 清理候选；确认后删除或移 `_待清理/` |

本包清单：

| 文档/目录 | 类型 | 处理 |
| --- | --- | --- |
| `环境基线.md`、`activeContext.md`、`测试/测试计划.md`、`测试/测试报告.md` | 长期/当前版本 | 就地更新；版本关闭时计划/报告快照到 `测试/_归档/{yyyyMMdd}-{版本}/`（仅跨轨主档），当前档不移动 |
| 根 `CHANGELOG.md` | 长期 | 版本/迭代关闭、报告完成更新；不随版本归档 |
| `测试/00-稳定冒烟清单.md`、可复用脚本、基线 | 长期 | 保留/更新，不随换代整包归档 |
| `测试/功能测试/` | 版本/迭代绑定 | 版本关闭：用例/台账/评审/证据 → `测试/功能测试/_归档/{yyyyMMdd}-{版本}/`；现行目录保留/重置 |
| `测试/接口测试/` | 版本/迭代绑定 | 版本关闭或用户点名旧轮 → `测试/接口测试/_归档/{yyyyMMdd}-{版本或批次}/`；现行就地更新，禁删后整包重生成 |
| `测试/探索式测试/` | 版本/迭代绑定 | 用户点名旧轮 → `测试/探索式测试/_归档/{yyyyMMdd}/` |
| `测试/发布前测试/{专项}/` | 版本/迭代绑定 | 版本关闭或用户点名 → `测试/发布前测试/{专项}/_归档/{yyyyMMdd}-{版本}/` |
| `测试/变更/CR-*` | 版本绑定 | 版本关闭 → 随同批写入 `测试/_归档/{yyyyMMdd}-{版本}/变更/` |
| `测试/交接/{HO-ID}/` | 版本绑定/快照 | 生成后不可改；关闭/版本结束 → `测试/_归档/{yyyyMMdd}-{版本}/交接/`；`交接台账.md` 常青就地更新 |
| `测试/资料/交接/{HO-ID}/` | 外部输入/只读 | 接收包只读；不修改；失效时按资料规则进 `测试/资料/_归档/` |
| `测试/资料/` | 外部输入 | 按 §3 收取/对照；失效资料只进 `测试/资料/_归档/` |
| `**/.draft/`、失败导出、未引用截图、重复文件 | 过程/临时 | 清理候选；确认后删除或移 `测试/_归档/_待清理/{yyyyMMdd}/` |

## 5. 更新还是归档

| 情况 | 动作 |
| --- | --- |
| 长期真值/主档变化 | 就地更新；变更前后写 CR/变更记录，不归档主档 |
| 当前版本用例/台账局部变化 | 就地更新受影响条目；旧结论覆盖，只留最新 |
| 新版本计划全量替代旧计划 | 新版=现行；旧版=失效，确认后快照到 `测试/_归档/` |
| 新版本只改一个模块 | 旧计划保留并更新未覆盖部分；不归档 |
| 版本/迭代关闭，文档只服务该期 | **各类测试资产进各自轨 `_归档`**；失效资料进 `测试/资料/_归档/`；计划/报告/CR/交接进 `测试/_归档/` |
| 需求删除/版本取消 | 相关文档标失效；确认后按上表落点归档 |
| 过期但仍有参考价值 | 保留为参考，不归档 |
| 重复/空文件/无引用 | 清理候选；确认后删除或移 `_待清理/` |

判定原则：版本号新 ≠ 全量替代；以覆盖范围为准；正式资产只写现行有效；报告滚动更新只留最新口径。

## 6. 版本/迭代关闭

1. 更新测试计划 §0/§16.1/§16.2、测试报告、activeContext、根 `CHANGELOG.md`。
2. **跨轨主档**：计划/报告/CR/已关闭交接包快照到 `测试/_归档/{yyyyMMdd}-{版本}/`；当前 `测试/测试计划.md` / `测试/测试报告.md` 不移动。
3. **分轨资产**（只归档已确认项）：
   - 功能 → `测试/功能测试/_归档/{yyyyMMdd}-{版本}/`
   - 接口 → `测试/接口测试/_归档/{yyyyMMdd}-{版本}/`
   - 探索式 → `测试/探索式测试/_归档/{yyyyMMdd}/`（或带版本后缀）
   - 发布前各专项 → `测试/发布前测试/{专项}/_归档/{yyyyMMdd}-{版本}/`
4. **资料**：按 §3～§5 扫描；只归档用户确认的 `失效` 项到 `测试/资料/_归档/{yyyyMMdd}-{版本}/` + `归档清单`；部分覆盖/增量/参考/待确认不动。
5. 写各批次 `归档清单`（原路径/归档路径/类型/依据/替代/校验/日期）。
6. 清理过程/临时文件：按 §7 出候选，确认后执行。
7. 更新资料索引/计划/报告/activeContext；跑引用检查。

> **禁**：把功能/接口/探索式/发布前用例·台账·证据整包丢进 `测试/_归档/` 根下。根 `_归档` 只收跨轨主档（计划/报告/CR/交接）与 `_待清理`。

## 7. 过程/临时文件清理

- 扫描 `测试/` 与项目根顶层；跳过 `.git/`、代码依赖/构建产物/模板目录。
- 候选：`.draft/`（未被计划/报告/评审引用）、`*.tmp/*.temp/*.bak/*.log`、`~$*/ .DS_Store / Thumbs.db / desktop.ini`、`* (1).*/*副本*/0 字节未引用`、未引用导出/下载/截图/临时 JSON。
- 永不自动删除：正式资产、当前计划/报告、证据、源文件、模板、`.git`、`.env`/密钥、拿不准的文件。
- 执行：列【清理候选】（路径/类型/原因/大小/引用/动作）；确认后已知临时文件可删，不确定移 `测试/_归档/_待清理/{yyyyMMdd}/`；写清理清单；更新 activeContext。
- 禁止业务任务中途顺手删除；只在关闭/巡检/点名「清理」时执行。

## 9. 触发

| 时点 | 动作 |
| --- | --- |
| 接入/重新接入 | 扫描资料/工作文档；建索引；缺 `项目文档/` 则建默认结构；旧扁平/错位归档列迁移候选 |
| 新版本/新迭代替换旧文档 | 按 §5 判定更新/归档；不全量替代不归档 |
| 版本/迭代关闭 | 按 §6 分轨快照/资料归档/清理 |
| 用户点名「资料整理/文档整理/巡检/清理」 | 扫描 → 候选 → 确认 → 执行 |
| 季度/月度（可选） | 只扫描出候选，不移动 |
