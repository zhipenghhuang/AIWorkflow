## 2. 分级

| 级别 | 典型 | 计划 | 生成 |
| --- | --- | --- | --- |
| T0 补丁/热修 | 小改、单模块 | 轻量计划（≤1 页） | 受影响模块用例/脚本 |

## 3. 流程卡

1. **analyze**：主读未点名 → 列候选+建议，一问选定；已点名 → 仍出需求模型/轻量分析短表（需求理解/变更点/影响面/口径待探查/oracle/歧义/风险/建议类型/TP→用例）。禁整步空过；关键歧义未裁决先问，不猜。
2. **plan**：版本级/首版 → 完整计划；小任务 → 轻量计划；有前序/GATE 依赖时 §2.2/§9/§10 写入依赖版 P0-Smoke（禁有界对照替代）；计划门仅在首版/换代或范围·准出·缺陷策略实质变更时停；A/B 期中变更就地更新，C 回计划门。
3. **generate**：按计划 §3.2 资产清单逐项生成/登记；缺计划先轻量补；缺主读先门1。
4. **覆盖三闸**（功能全量/专项）：① 可测承诺抽取（验收/GATE/主路径/状态/权限/异常 + 变更点/影响面/视觉基础；章节回执）；② 设计点→用例映射无空行；③ 缺口三分类（覆盖缺口/口径待探查/环境交付）。P0 覆盖缺口先问用户接受不测。
5. **用例质量**：每条独立可执行、前置三件套齐、步骤↔预期同号、判定面可观测、负面/边界、清理、证据、追溯、评分卡 ≥18/20 且无阻断；UI 体验用例覆盖文案减法/冗余标签。
6. **脚本判定**：P0-Smoke/核心闭环 → 同轮脚本；接口确定性 → 同轮 API 脚本；其余迭代功能默认 AI，不强行脚本化；一次性/低频不脚本。判「否」写一句理由。
7. **收尾**：生成收尾（已生成·未执行，映射 N 点/用例 M 条）；独立生成有拟入库 → 门3；同会话续执行 → 门3 留 report。

## 4. 红线

- 禁臆造路由/接口/按钮；禁空泛「已全覆盖」。
- 每条用例可追溯到 RQ/AC/F/R/TP 或页面/接口来源；预期必须来自需求/AC/契约/用户裁决，不按现网实现反推；无来源先问或标“文档未声明”。
- 主读已点名不免除轻量分析短表；小任务不豁免覆盖闸（功能全量/专项）。
- 探索式/接口/发布前按各自契约，不套功能三闸。
- 大规模生成 ≥3 模块且 ≥40 条才分片；单模块直做；不并行写同一文件。

## 5. 输出

用例/台账/脚本/分析短表/计划；生成收尾按 `规则/模板/90-交接与收尾/收尾骨架.md`。
