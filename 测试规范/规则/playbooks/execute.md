## 2. 执行卡

1. **门2/预授权**：计划 §0=已确认/执行中/待关闭且口令「按计划执行」→ 跳过门2，附【已预授权执行：按计划】；未确认范围 → 一行确认。
2. **数据准备**：功能全量/专项先扫本批前置三件套（账号/入口/数据）；缺者集中一次造齐（优先 API/脚本）；小批 ≤20 或已齐可跳过。
3. **P0 冒烟**：功能全量/专项先跑 P0-Smoke（脚本优先）；全绿 → 全量；失败按 §1.1.1 分流：环境级停轮；产品级拦阻断面；脚本漂移修脚本。
4. **按轨执行**：功能按用例逐条；接口按契约/维度；探索式按章程/timebox；发布前按专项方案。**同条用例禁并行**；写操作前确认账号/数据隔离。
5. **落账**：一条一写台账/jsonl；结果六态 pass/fail/blocked/na/pending/未执行；失败摘要钉断言点；证据叶名含 caseId；不攒批。
6. **失败复核**：脚本 fail 先有界复核（一次为限、同批同因合并、可定性即停）；AI 执行失败先按 `缺陷分类` 判实现/产品；blocked 四问通过才写 blocked。
7. **缺陷**：计划 §11 已授权「发现即提交」→ 查重后直接提交（十段齐+证据）；未授权 → 门3；同因不重复提交。
8. **回归**：修复后跑原单+冒烟子集+影响面组；高风险/连环提示升级；结果就地覆盖，只留最新结论。
9. **收尾**：更新台账/证据/计划 §0/§16.1；需要报告时走 report；直接以 execute 为末步则按 `规则/模板/收尾骨架.md` 输出执行收尾。

## 3. 红线

- 先 UI 再 Network；禁猜未见 API 判失败；仅 list 探活不得判 fail。
- 缺数据/缺样本先造/换样，≠blocked；blocked 四问任一未过不写 blocked。
- 禁抬高通过率；禁改断言/跳测试凑绿；失败必须留证。
- 已脚本化用例回归必须走脚本档，禁 MCP 逐条重跑；脚本通过不采信退出码。
- 不跨轨通读；不静默降范围；计划实质变更回计划门。

## 4. 输出

台账/证据/缺陷/回归记录/计划状态；失败与偏差并入报告。收尾按 `规则/模板/收尾骨架.md`。
