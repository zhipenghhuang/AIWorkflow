## 2. 执行卡

1. **门2/预授权**：计划 §0=已确认/执行中/待关闭且口令「按计划执行」→ 跳过门2，附【已预授权执行：按计划】；未确认范围 → 一行确认。
2. **展示装填行（必做）**：读计划 §0/§3.7 → 出示 `suite=core|module|full` + 命中域 + 已终态/next。**有文件 ≠ 本轮跑**。口令「继续」只续装填，不重做影响分析、不隐式 generate。
3. **数据准备**：对本批装填域扫前置三件套；缺者集中一次造齐；小批 ≤20 或已齐可跳过。
4. **P0 冒烟（suite⊇core）**：先跑 P0-Smoke（脚本优先）；全绿 → 进入 §3.7 装填域（module）；发版/点名才 full；失败按 §1.1.1 分流。
5. **按轨 + 装填执行**：功能只跑装填域逐条；接口按契约/本轮执行维；探索式按章程；随机业务流程计划外；发布前按专项。**同条用例禁并行**。
6. **落账**：一条一写台账/jsonl；结果六态；失败摘要钉断言点；证据叶名含 caseId；不攒批。同步 §0 装填进度。
7. **截图即视觉检**：凡拍目标页截图 → 工作流 §2.1.0 视觉六项；阻断→`fail`；非阻断→额外发现。**已截必检**。
8. **失败复核**：脚本 fail 有界复核；AI 失败按 `缺陷分类`；blocked 四问通过才写 blocked。
9. **缺陷**：提交策略见 `规则/缺陷/缺陷协作.md` §6.1；同因不重复提交。
10. **回归**：原单+冒烟子集+影响面组；高风险/连环提示升级；就地覆盖只留最新结论。
11. **收尾**：本批终态齐后 `Invoke-Gate.ps1 -Mode execute -Scope "{装填域}"`；更新台账/证据/计划 §0/§16.1。**准出门槛**：迭代≥module、发版/完整项目=full；仅 core 不得判可准出（补丁口径除外且须明示）；报告必声明 suite；准出走 report。

## 3. 红线

- 先 UI 再 Network；禁猜未见 API 判失败；仅 list 探活不得判 fail。
- **禁换验收载体**：按用例/方案已点名动作走 UI→同源 Network；难测不得改打「同类」其它批量/写接口；载体入口缺失→待实现/fail，不猜替代 API。
- 台账「执行通道」只许模板枚举（`AI-MCP`｜`脚本档`｜`混合`）；**禁**自造 `AI-API` 等标签。
- 口径待探查=钉本载体字段/实现值，≠换功能点。
- UI 文案减法与视觉六项见工作流 §2.1.0；禁「先功能后视觉、截图不看界面」。
- 缺数据/缺样本先造/换样，≠blocked；方案/AC 范围内未实现→`待实现（实现缺陷）`；blocked 四问任一未过不写 blocked。
- 本批未终态齐（停轮/用户中断除外）禁【执行收尾】与拟提交清单。
- 禁抬高通过率；禁改断言/跳测试凑绿；失败必须留证。
- 已脚本化用例回归必须走脚本档；脚本通过不采信退出码。
- 不跨轨通读；不静默降范围；不把库内未装填条算进本轮通过率；计划实质变更回计划门。
- 安全/P0 不可因「精准选测」静默剔除。

## 4. 输出

台账/证据/缺陷/回归记录/计划状态；失败与偏差并入报告。收尾按 `规则/模板/90-交接与收尾/收尾骨架.md`。
