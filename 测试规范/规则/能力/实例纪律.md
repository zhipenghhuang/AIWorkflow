# 实例能力纪律（测试）

> **读取级别：参考**。装配 / 体检 / 首次触达浏览器或外部工具时读；业务顺跑只读 `测试/能力/00-能力清单.md` 相关行。

## 1. 单一出处

- **真源**：`测试/能力/`（清单必有；`槽位/` · `绑定/` · `装配/` 按需）。
- **禁双写**：环境基线、计划、activeContext、档案式文档**不得**维护完整选型/绑定正文；只写指针（路径或槽名）。
- **包侧**：`能力/00-能力契约.md` = 槽位名与缺失策略；`能力/参考目录.md` = 候选举例。实例选型**不**写回包内。

## 2. 目录与渐进读

| 文件 | 何时读 |
| --- | --- |
| `测试/能力/00-能力清单.md` | 需要外部工具时（Tier1） |
| `测试/能力/槽位/{slot}.md` | 清单 `详情=` 指向或复杂选型（Tier2） |
| `测试/能力/绑定/{slot}.md` | 清单 `绑定=` 指向或执行需端口/server（Tier3） |
| `测试/能力/装配/*` | 装配留痕 / 排障 |

无清单 → 接入不强制填满；**首次命中槽**或「装配能力」→ 确认单后写入。

## 3. 字段与 kind

清单行：`能力名` · `启用` · `kind`（`mcp`｜`skill-cli`｜`builtin`｜`none`）· `impl` · `status`（available｜missing｜degraded｜prompted｜undecided）· `详情` · `绑定` · `verified`。

- `kind=mcp`：按 MCP 稳态（挂载、Restart、禁静默换 server）；绑定见 `绑定/`。  
- `kind=skill-cli`：按该实现手册（如 ego-browser / Playwright CLI+Skills）；不适用 CDP 套件则绑定文件写明。  
- `kind=builtin`：包内脚本执行器等。  
- **禁**未确认改启用集或换 `impl`。

## 4. 口令

| 口令 | 行为 |
| --- | --- |
| 装配能力 | 对照契约+参考目录+现清单 → 安装宿主侧 → **写 `测试/能力/`** |
| 体检能力 | **能力**只改 `测试/能力/`；**技能**可改包内 `技能/`（HITL） |
| 业务适度建议 | 至多 1 条，指向装配/体检 |

## 5. 安全

清单/绑定可入库：无 token/密码；只用环境变量名与宿主配置入口类型。高风险槽（缺陷写回等）装配须显式确认。
