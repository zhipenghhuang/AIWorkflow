# 门（测试轨）

> 单一出处：计划门、门1～3、迁移/资料门、`when`/`gate_when` 词表。步骤顺序以 `../workflows/*.yaml` 为准；**只认步上 `hitl`**，专规不另造门。
> 读取时机：当前步有门时只读对应行；写/改 YAML 时才读全表。

## 1. 门

| 门 | 步上声明 | 动作 |
| --- | --- | --- |
| 门1 | `select_mainread`（when: `mainread_unspecified_for_generate` / `exploratory_mainread_missing`） | 主读未点名 → STOP 一问；已选定 → 跳过，不得重问 |
| 理解门 | `confirm_understanding`（when: `understanding_needs_confirm`） | 出示需求模型摘要/oracle/冲突/九类歧义/GAP/缺口清单/置信度；确认后才写计划/用例/断言 |
| 计划门 | `confirm_plan`（when: `plan_needs_confirm`） | 版本级首版/换代或范围·准出·缺陷提交策略实质变更 → STOP 一行摘要确认；同会话同载体只一次；专项轻量不设门 |
| 门2 | `confirm_scope`（when: `scope_needs_confirm`） | 开跑前一行：主读/计划范围/环境 → 确认；同会话同载体只一次；计划驱动已确认 → 跳过并附【已预授权执行：按计划】 |
| 门3 | `confirm_commit`（when: `standalone_generate_with_pending` / `has_pending_commit_or_platform_ask` / `platform_submit`） | 有拟入库、须问交平台或拟新建缺陷单 → STOP；否则跳过 |
| 迁移/资料门 | `confirm_docs_migration`（when: `docs_migration_needed`） | 资料收取/分类/改名/归档、或旧结构迁移前列清单与目标；确认后执行 |
| 备注门 | `confirm_remark`（when: `remark_writeback`） | 拟关/激/解决/标重复/补充澄清/回归写回 → 先列 id+结论+备注全文；确认后执行 |
| 入库门 | `confirm_gitignore` | 四选一确认资产入库范围并写 `.gitignore`；接入时一次 |
| 覆盖闸 | `gate: coverage-map`（when: `functional_coverage_required`） | 功能全量/专项新生成/补生成：设计点→用例映射无空行；不适用于其它轨 |
| 报告闸 | `gate: report-consistency` | 出报告/准出前运行 `验证/Invoke-Gate.ps1 -Mode report`；台账/报告计数一致、P0、证据、覆盖缺口；未 PASS/CONDITIONAL 不得写整体通过 |
| 回写模式 | `验证/Invoke-Gate.ps1 -Mode writeback` | 交平台/回写前运行；无回执/备注状态不同轮/附件未回查 → BLOCKED |

## 2. `when` / `gate_when` 词表

`mainread_unspecified`｜`mainread_unspecified_for_generate`｜`exploratory_mainread_missing`｜`understanding_needs_confirm`｜`plan_needs_confirm`｜`scope_needs_confirm`｜`standalone_generate_with_pending`｜`has_pending_commit_or_platform_ask`｜`has_pending_commit`｜`remark_writeback`｜`platform_submit`｜`docs_migration_needed`。

`gate_when`：`functional_coverage_required`（不满足 → 跳过该 gate，步骤不跳过）。

`scope_needs_confirm`：非计划驱动、计划状态非「已确认/执行中/待关闭」或范围/环境实质变化时为真；计划驱动且 §0 为已确认/执行中/待关闭时为假。期中变更 A/B 并入后保持已确认→假；C 变更中→真（计划门）。

`understanding_needs_confirm`：输入含 PRD/迭代方案/原型/接口或技术文档、存在 2 个以上实质歧义/冲突、T2/T3，或用户要求计划/用例/准出时真；已有**本轮当前范围**确认的需求理解包/分析短表或纯信息查询/机械低风险操作时假。

同一会话同一确认点只问一次；资料/迁移/清理清单确认后本轮不再重复（`docs_migration_needed` 置假）。

## 3. 门档位（防过度审批）

| 档 | 适用 | 行为 |
| --- | --- | --- |
| autonomous | 只读、列表/巡检、已脚本化回归 | 直接做，收尾记录变化/假设 |
| notify | 同范围生成/执行、A/B 期中变更 | 展示范围/计划/环境后继续，用户可打断 |
| approve | 计划实质变更、首次执行未确认范围、平台建单/回写、提交、资料搬迁/清理 | 停：计划门、门2/门3、备注门、迁移门 |

低风险动作不要升级为 approve；高风险动作不得降为 notify。红线不被“少问/直跑”覆盖。
