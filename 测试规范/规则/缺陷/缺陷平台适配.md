# 缺陷平台适配（通用 · 内置 zentao）

> 只在提交/回写/排障时读；`规则/缺陷/缺陷协作.md` 的 `§4.x` 指针指向本文件。

## 4. 平台适配（通用 · 内置 zentao 见 §4.1）

### 4.0 通用纪律与适配契约

**一律先读 `环境基线.md` §13**：provider、提交方式、备注格式、适配定义。端点/字段/枚举**只认 §13 映射**；未写「内置 zentao」时**禁止**调用 §4.1 路径或禅道字段名。

**最小能力契约**（§13「适配定义」须覆盖；缺任一项且提交方式≠`export` → 一问补齐，补不齐改 `export`）：

| 能力 | 语义（平台无关） | 适配须给出 |
| --- | --- | --- |
| 认证 | 登录/取 Token | 端点、凭据字段、刷新方式 |
| 列表 / 查重 | 按指派/创建者/关键词拉未关闭单 | 过滤参数、分页、标题/路径字段 |
| 详情 | 读单全文 | 状态/指派/严重度/优先级/构建/历史备注/附件字段名 |
| 建单 / 提交 | 新建缺陷 | 标题/正文/严重度/优先级/类型/指派/构建等字段与取值 |
| 备注 | 追加评论（与状态同轮） | 评论端点、正文格式（html/md/text） |
| 状态变更 | 解决 / 关闭 / 激活·重开 / 非修复处置 | 语义→平台 transition 或 status/resolution 取值 |
| 指派 | 改负责人 | 字段与账号标识 |
| 附件 | 上传与回查挂载 | 上传端点/字段名；回查如何断言已挂到本单 |
| 用户查询 | 解析指派对象（可选） | 查询端点；不支持则备注写姓名 |

**语义动作**（对话与确认包用这些词；写平台时换成 §13 取值）：`submit` 建单｜`comment` 备注｜`resolve_fixed` 标已修复待验｜`close` 关闭｜`activate` 激活/重开｜`assign` 指派｜`mark_duplicate` 标重复｜`nonfix` 非修复（设计如此/不修/延期/外部/转需求等，细分取值见映射）。

通用纪律：

- 状态变更与 comment **同轮**；禁删缺陷对象；禁密码/绝对路径/用例路径入备注或 steps。  
- 写平台文本版式按 §13「备注格式」：`html` → 块内行间 `<br>`、块间单个 `<p></p>`，**禁**每行外包 `<p>`、`<br><br>`、`\n\n`；`markdown`/`text` → 行间单换行、块间至多一空行。写入前按 payload 自检。  
- 读单：按 §7.3 语义字段经 §13 映射读取；api 读不全 → `browser`；仍不全 → 请用户补关键备注/附件，禁只看标题分析。  
- 读者过滤：只写事实、证据、请求；用例 ID/路径、台账/计划/报告路径、测试脚本、内部分类/评级理由、内部过程、无关测试数据、未标注猜测、PII/密钥不写入。  
- 回写回查：按 `环境基线.md` §13「详情/附件」端点核对状态·指派·最新备注·附件挂载；记录 `noteId/time`；不一致按 §8.7；失败走 `export`，不声称成功。附件失败重试 ≤1，禁反复重传。

### 4.1 内置 zentao（仅 provider=zentao 且适配定义含「内置」）

- Token：`POST /api.php/v1/tokens`；禁浏览器登录页。  
- 建单 REST v1：`openedBuild=trunk`（禁 `0`/空）；`severity`/`pri` 传字符串 `"1"`…`"4"`；实现缺陷 `type=codeerror`；产品缺陷有 `designdefect` 则用，否则标题或【提交摘要】首行写「产品缺陷」。  
- 附件：`POST /api.php/v2/files`，字段 **`file`** + `objectType=bug` + `objectID`（禁 v1）；非 ASCII 文件名按 UTF-8 原字节写入 multipart `filename`；回查 `GET /api.php/v2/files/{fileId}` 核对 `objectType/objectID`（v1 详情 `files` 可为空，**不得**据此判未挂载）。  
- 读/回查：详情与列表用 v1；写后 `GET /bugs/{id}` 核对 `status/resolution/assignedTo/lastEditedDate` 与最新 action；附件以 v2 元数据或页面附件区为准。  
- resolution 常用取值（写回前仍以 §13 为准）：`fixed` / `notrepro` / `bydesign` / `duplicate` / `external` / `postponed` / `willnotfix` / `tostory`。
