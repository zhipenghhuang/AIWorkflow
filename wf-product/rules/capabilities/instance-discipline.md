# 实例能力纪律（产品）

> **读取级别：参考**。装配 / 体检 / 首次触达外部工具时读；业务顺跑只读 `{workroot}/capabilities/00-能力清单.md` 相关行。

## 1. 单一出处

- **真源**：`{workroot}/capabilities/`（清单必有；`槽位/` · `绑定/` · `装配/` 按需）。
- **禁双写**：`product-profile.md` 等只索引清单；不抄绑定正文。
- **包侧**：`capabilities/00-contract.md` + `capabilities/reference.md`。

## 2. 渐进读与口令

同开发/测试：清单为 Tier1；装配写实例；体检拆开（能力→`{workroot}/capabilities/`，技能→包内 `skills/`）。浏览器若复用测试，写复用指针。

## 3. 安全

无密钥入库；宿主配置仅指针。

## 4. 外部工具/浏览器生命周期

- 默认不预启动；仅有竞品/页面取证或原型实走任务时按需拉起；结束后按实例绑定/清单记录的退程方式关闭。
- 复用测试实例时，生命周期按测试包绑定与实例纪律执行。
- 跨会话默认正常改项目；共享可写状态只一个写会话；同一 MCP 内部并行需独立会话/请求级路由或独占实例，否则串行；共享登录态/页面状态/写状态时串行或隔离。
