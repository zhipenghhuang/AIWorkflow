# 收尾骨架（产品轨）

> **单一出处**：完整【任务收尾】/【今日工作总结】字段下限。专规只填第 1 点正文。  
> **原则（硬）**：通用占位骨架，非剧本。`{…}` 按当前项目事实填；无则「无」。**禁止**照抄他项目路径/数字/短名。低价值叙述可压缩；机读字段与 1～6 标签不可省。未覆盖 → 目标+证据自主判断并 `deviation=`（`execution-contract.md`）。  
> **读取**：`wrap`/点名收尾·总结时；中途 ≤3 行简报。

## 0. 头块（各占一行）

```text
【任务收尾】
【验证回执】结论={可定稿|草稿|阻塞|不适用} | 校验={名（代号/时间）} | 检查={通过}/{总数} | 待确认={n|列表|无}
【遵守自检】route={workflow:step} | mode={execute|analyze|stop} | reads={≤5 或 +n} | gates={id=verdict} | sync={…；triad=aligned|na|deferred:<原因>；facade=aligned|na|deferred:<原因>} | skip={…|无} | deviation={…|无}
```

- 有门产物 → 回执与 `.gate/wf-product/{mode}.json` 一致（`READY/DRAFT/BLOCKED`）；无门 → `结论=不适用` + 自检依据，**不伪造**门回执。  
- 无计划 `triad=na`；未触门面 `facade=na`。心跳不替代遵守自检。  
- `python verify/tools/check_compliance.py --report <本文件>`。

## 0.5 表达（可复制块）

- 代号/门禁缩写每次带中文；禁裸写、禁抄示例短名。  
- `**{短名}**（{结论}）：{正文}`；汇报用 text 围栏；汇报层禁行内反引号与路径。  
- 待你确认只在第 4 点。

## 1. 通用骨架（完整收尾）

```text
【任务收尾】
【验证回执】结论={…} | 校验={…} | 检查={…}/{…} | 待确认={…}
【遵守自检】route={…} | mode={…} | reads={…} | gates={…} | sync={…；triad=…；facade=…} | skip={…} | deviation={…}

汇报（可直接复制）：
**{短名}**（{结论态}，{完成}/{总数}，{说明}）：{覆盖面；目标/验收；未决；未验证不得写「无阻断」}

1. 完成了什么：
   {动作/对象/产出/评审态}
   影响：{下游/阶段/范围；无则「无」}；{业务路径变化或「业务路径无变」}
2. 改了哪些文件：
   文件：{路径|无}
   未提交：{本任务 n / 前序 m / 无关 k}
   建议动作：{…|无}
   待提交摘要：{…|无}
   git：{无仓库|分支+态}
   .gitignore：{合理|拟改待确认|已更新|无仓库}
   文档归档：{一句|无}
3. 如何验证：
   - {评审/抽验/UAT/回写核对 + 结果}
   - {未验证项|无}
4. 假设与未决项（待你确认）：
   假设：{…|无}
   待你确认（需拍板 {N} 项）：
   - {编号 短名}（归属={P|D|S}；可转发产品={是|否}）
     事项：{…}
     选项：{…}
     建议：{…}
     影响/默认：{…}
   默认（不回复即执行）：{可默认项|无}
   回复：{…|无}
   可转发产品：{…|无}
5. 还存在什么问题或风险：
   {…|无}
6. 当前进度与下一步：
   当前：{阶段/门/健康度/阻塞/评审 x/y/下一门}
   下一步：
   1）{动作}（执行：{谁}；产出：{…}；完成标志：{…}）
   优先级：{先→再→后}
   建议：{…}；理由：{…}
   不建议：{…}
   完成标志：{…}

附：运行与沉淀
资料补强：{…|无}
工作记忆：{偏好·洞见·坑或「无」}
运行态：浏览器={已退程|延后·原因|仍在运行|未用}；其它={…|无}
```

### 1.1 填空纪律

- 汇报=对外摘要；第 1 点=明细；不合并。写/改 PRD 时第 3 点含完稿自检要点（技能有则按其 §9.1）。  
- 第 2 点 7 子字段逐行；无 git → 双写「无仓库」。  
- 第 4 点唯一待确认；定价/合同/合规/隐私/对外承诺/C2/C3 不得默认；运行中须关闭/保持。落盘 `{workroot}/00-governance/open-items.md`。  
- 下一步按实际 1～3 条，勿凑数。拟提交/回写门在骨架后确认。

## 2. 工作总结

围栏外：`范围：{from}～{to}`。可复制块：

```text
- **{产品}·{版本} 产品** —— 完成度: {P%}，{进度一句}
  - **{计划短名}**（{确认态}）：{静态简介；禁下一步}
  - 【今日工作总结】{yyyy-MM-dd}｜{产品}·{ver}｜产品

```

## 3. 输出分级

| 场景 | 输出 |
| --- | --- |
| 只读/答疑 | 2～3 行；可展开；不伪造回执 |
| 改文件/过门 | 完整【任务收尾】 |
| 发布/对外/回写 | 完整收尾 + 证据要点 |

## 4. 发出前自检

头块分行 → 汇报独立 → 1～6 齐 → 子字段/附录齐 → 回执与门一致 → `check_compliance` 通过。
