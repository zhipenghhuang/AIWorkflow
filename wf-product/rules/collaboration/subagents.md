# 子代理编排（执行档位 · 扇出读 · 汇聚写）

> **定位**：本包唯一子代理编排口径；`workflows/` 与 `agents/` 只写「按本文取档/派工/回收」，不重复阈值。  
> **原则**：**先工具、再单上下文分节、再只读扇出、最后写分片**；能直做不拆；达阈值默认拆或声明偏差。  
> **净收益**＝上下文卸载＋墙钟加速＋质量增益−（重复读取＋合并核验＋漂移风险）。主收益优先**上下文卫生与独立核验**，其次墙钟。  
> **择优**：用户点名优先；未点名时由 AI 按项目实际、宿主能力、共享资源与净收益选择档位/并行宽度；阈值只作默认触发器。  
> **契约文件**：分片/侦察子代理 → `../agents/worker-agent.yaml`；联动/一致性/UAT/缺陷复核（拆分档核验） → `../agents/verifier-agent.yaml`；PRD 评审 → `../agents/reviewer-agent.yaml`（派工时附带，禁只靠口头角色名）。

**派工前 3 问**（仅**未达**§2 阈值时的可选拆分；**不得**否决已命中阈值）：① 能否校验器/脚本/单上下文分节完成？② 单元是否独立且写集不相交（含生成物/配置/迁移/测试数据/账号/端口/profile；或只读）？③ 合并/核验是否机械、返回能否 ≤30 行？三问皆否 → 直做。

## 0. 实例生命周期（硬）

> 契约 YAML 是**角色模板**，不是常驻单例。宿主 Task：`新开`＝新 Task（不带作者会话）；`resume`＝续同一 Task。下表不可让。

| 动作 | 要求 |
| --- | --- |
| **分片扇出** | 每一单元（单/模块/页/文档/来源）**新开**一个子代理；禁把上一单元会话 `resume` 成下一单元 |
| **拆分档核验** | Writer 完成后 **新开 fresh** `verifier-agent`；**禁** `resume` Writer；核验上下文只给产物＋验收＋证据，不给作者解释/草稿 |
| **串行下一批** | 默认 **新开**；仅派发包标明同一主题/同一 DraftPath 且「继续」未完成时可 `resume` 同 worker |
| **并行同波** | 每路各 **新开**；并发 ≤3 |
| **失败补跑** | 同回合对同任务可重派 ≤1（优先新开）；同方案无效须换路径；禁空转重派同一方案 |

## 1. 执行档位

| 档 | 适用 | 形态 | 落盘 |
| --- | --- | --- | --- |
| **工具档** | `validate_prd.py`、评分卡、统计、grep、链接/证据核对 | 确定性执行，0 token；不派子代理 | 校验结果/摘要 |
| **直做档** | 默认；单条需求、单份 PRD、单页原型、单份文档、需全局判断；「继续」单单元；宿主无子代理 | 本会话直接做 | 正式产物 |
| **分片档** | ≥3 独立单元（单/模块/页/文档/来源）；或 ≥20k token 原始证据 | 一单元一子代理（§0 新开）；读可并行、写按文件集隔离；批末核验→下一批 | `.draft/{主题}/`＋正式产物 |
| **拆分档** | 正式评审/高价值变更/对外材料/需独立核验 | Writer → fresh `verifier-agent`（§0）→ 编排合并 | 草稿＋正式产物 |

**开跑声明（达阈值或用户点名分片时）**：一行 `mode=工具|直做|分片|拆分` + 对照 §2 条款一句。

## 2. 取档阈值（默认触发器；按净收益与共享资源择优）

| 场景 | 阈值 | 取档 |
| --- | --- | --- |
| 缺陷批量分析 | **≥5 单且读单成本高**（多备注/附件/评估单）或合计 ≥20k token | 逐单只读侦察（可并行≤3）；五选一与处置集中 |
| 变更影响评估 | 跨版本/高价值且 ≥3 影响域 | 分域只读（可并行≤3）；受理单/变更单单写手 |
| 联动落地审计 | ≥4 份受影响文档 | 单写手完成后 verifier 审计 |
| PRD 证据侦察 | **≥3 来源文档** | 只读侦察（可并行≤3）；PRD 正文单写手 |
| PRD 评审 | 大 PRD/跨模块 | 维度只读扇出；主 reviewer 去重 |
| 原型高保真 | ≥8 页 | 分页构建（pages 文件不相交可并行≤3）＋一致性/无障碍审计 |
| 展示/用户文档 | ≥3 类文档 | 共享事实表＋按类型分片（不同类型文件可并行） |
| UAT | ≥3 模块 | 分模块只读核验（可并行≤3）；结论集中 |
| 调研/竞品 | ≥4 独立来源 | 按来源只读扇出（可并行≤3）；去重入池 |
| 单条反馈/单份文档/单页/同一 PRD 正文 | — | **禁并行写**，直做 |

达阈值默认拆；若合并成本高于收益、共享资源无法隔离或用户点名直做 → 可直做，记 `deviation=subagent_skipped:<理由>`（`unavailable`/`user` 除外须写清）。
未达阈值但 2 个高价值独立单元净收益为正 → 也可拆，不把「≥3」当上限。

## 3. 并行与隔离

**共享写域** = 同一文件/文件集 + 生成物/锁文件 + 迁移/schema + 全局配置/路由/索引/设计 tokens + 同一 DB/测试数据/账号/端口/profile/下载目录中的可写或会话变更部分 + 同一外部单据/平台记录。任一共享可写 → 串行或隔离。MCP 的会话/当前上下文/登录态/页面状态/浏览器全局状态也按共享可写状态处理。

| 类型 | 可否并行 | 条件 |
| --- | --- | --- |
| 只读扇出（调研/竞品/影响/审计/抽取） | **可** | 并发 ≤3；返回各 ≤30 行 |
| 写分片（不同文件集） | **可** | 并发 ≤3；文件集不相交 |
| 跨会话（独立宿主/会话） | **可** | 默认正常改项目；同文件/共享可写状态并发时串行、分工或按需隔离；MCP 按实际隔离能力与冲突面判断，同一实例无独立会话/请求级路由能力时串行 |
| 同一 PRD/计划/UAT/受理单/变更单/`prototype/index.html` | **否** | 单写手 |
| Writer∥Verifier（拆分档） | **否** | 同回合串行：写完再 fresh 验（§0） |

并行冲突 → 立即串行并记偏差。

> 并发宽度是默认护栏：只读扇出在合并机械、宿主资源允许且无共享写域时可上调；写分片/原型页默认 ≤3，需突破时用隔离套或串行。

## 4. 失败降级（不可让）

任一项 → **同回合降级直做/串行补齐**，禁空转重派同一方案：超时/deadline/无产物/空返回；`rules=violation` 或 `scope=over` 无法收敛；连续 2 批负收益。  
收尾：`deviation=subagent_degraded:<timeout|empty|violation|neg_roi>`。宿主无子代理 → 全程直做 + `subagent=unavailable`。

## 5. 扇出读 · 汇聚写（硬约束）

- 读可扇出：调研、竞品、影响面、逐单缺陷、证据核对、页面审计、文档抽取。  
- 写必须单写手或文件集不相交；同一 PRD/计划/UAT/受理单/变更单/页面文件禁并行写。  
- 判断、定性、优先级、五选一、GO/NO-GO、发布/对外承诺、平台回写留在编排；子代理不得过 `hitl`/`gate`。  
- 子代理不改产品计划/需求池/PRD 正文/门；不 git/不平台/不对外发布。  
- 原型只用既定 tokens/组件；页面分片只写 `原型/pages/{page}.html`（或独立片段），**禁止并行写共享 `prototype/index.html`**；新组件/新 token 须回编排确认；禁止各页自造样式。  
- 产品缺陷必须给 PRD/设计原文＋现网/测试证据＋相符证明；子代理只提供素材，不替产品定性。

## 6. 派工包（7 项，缺一不派）

1. 任务与验收（受理号/主题/模块/页面/文档类型/判定面）。  
2. 边界（允许路径/文件集；共享可写资源/隔离方式；禁改 PRD 正文/计划/需求池/他模块）。  
3. 输入（路径＋节；**不附整本**；不读其它包）。  
4. 规则摘录（只带 3～5 条相关红线＋契约文件路径；禁只靠口头角色名）。  
5. 输出契约（草稿路径/产物格式/字段）。  
6. 返回格式（≤30 行固定字段；禁全文/长引用/推理过程）。  
7. 禁止事项（git/平台/门/对外发布/超范围/同命令重跑）。  

## 7. 回收与合并（编排必做）

- 文件在、字段齐、计数一致、链接/证据可打开、规则回执；失败同回合补跑。  
- 去重与冲突：同一结论只留一条；冲突以 PRD 原文/现网证据/构建为准；不采信口头完成。  
- 联动清单逐项核「已更新/不适用/待补」；待补须有责任人与截止。  
- 规则回执：`rules=ok|violation:<条款>`、`scope=ok|over`、`evidence=…`；违规即回退重派或降级直做。  
- 失败：同回合重测 ≤1；同方案无效 2 次换路径；连续失败停止上报。

## 8. 上下文卫生（防稀释）

- 主上下文只留派工摘要、返回摘要、核验结论；原始inbound/长 PRD/竞品页/截图清单落盘。  
- 子代理只读派发摘录与本批相关节；不通读整本档案/规则/历史；同一文件不重读。  
- 后续步骤 delta-only；批末只重读当前步 must＋当前门，不重读整本。  
- **独立核验**：只给产物＋验收清单＋证据，不给作者解释/草稿（防锚定）；实例须 §0 fresh。  
- 并发默认 ≤3（见 §3 宽度护栏）；共享写域/同一文档/同一页面/同一平台单据一律串行或隔离。  
- 草稿落 `.draft/{主题}/`，不入库；已完结 draft 按 `rules/doc-governance.md` §8（点名/关版本可清；日常收尾不向用户追问）。

## 9. 成本守卫

- **负收益信号**：返回 >30 行、合并/口径冲突、返工、主上下文回读原始资料、超范围。  
- 连续 2 批出现负收益信号 → 回直做（见 §4）。  
- 批末一行：`batch | mode | units | parallel | returns≤30 | conflicts | rework | verdict=keep|direct|degraded`；不写长报告。  
- 质量投资型拆分（独立核验、维度评审、对外材料复核）只在正式评审/高价值/对外场景启用。  
- 不为「多 Agent」而拆；不把确定性校验交给 LLM。
