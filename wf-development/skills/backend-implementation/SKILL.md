# 后端实现（技能 · 随包生效）

> 用于：S4 编码自测中涉及 API/服务/数据访问/任务/消息/外部集成的任务。  
> 产出：可运行服务 + 单测/集成/契约测试 + 日志/指标证据 + 配置/迁移说明。  
> 原则：**输入必校验、权限必自校、写操作想事务、重复调用想幂等、外部调用想超时。**

## 1. 分层与边界

- Controller/接口层：参数校验、鉴权入口、错误映射。
- Service：业务规则、事务边界、幂等、并发控制。
- Repository/DAO：查询、索引、批量、分页；不把业务塞进 SQL。
- 外部集成：超时、重试、熔断、限流、降级。
- 与项目现有结构/命名一致；最小改动。

## 2. 输入、权限与错误

- 必填/类型/范围/枚举/长度/格式；服务端为准；金额/数量精度超限须**拒绝**（禁 ORM/驱动静默 round 当成功）。
- 可空业务字段（日期/金额/期间/归属）进入计算或判定前须显式处理：拒绝、待补态或等价降级；禁裸异常，禁用默认值补造（如缺失到期日按 30 天）。
- 认证/授权/资源级权限/数据域；不假设调用方已鉴权；**未显式配置的动作/范围/额度默认拒绝**（禁空配置归一全开）。
- 错误码稳定、可区分；消息可给用户看；不泄露堆栈/密钥/内部地址/路由清单。
- 唯一/状态/版本冲突 → 冲突类业务响应（稳定码+文案），禁把约束异常或乐观锁失败（Stale*/条件更新行数 0）漏成裸 5xx；未捕获异常若对外仍 5xx，须稳定信封/可读提示。
- **API 前缀**下未匹配路径/方法 → 同构 JSON 信封（契约见 `api-design` §2）；全局 404/405/未捕获须进统一错误层，禁框架调试 HTML。
- 上传：类型以**内容/魔数**为准；扩展名或声明 MIME 与内容不一致 → 拒绝；细则 `threat-modeling` S5。
- 软删+物理唯一占用：分配/查重计入含删集（真源 `cross-layer-consistency` §2.4）。
- 幂等：幂等键/业务键；终态重入拒绝；重复提交可识别。
- **重放不越权**：幂等/重放命中路径同样过鉴权、数据范围与期间校验；禁先回放结果再鉴权、禁以命中幂等键绕过越权判断。

## 3. 数据与事务

- 事务边界：一个业务动作一个事务；避免长事务/大事务。
- 隔离级别/锁/死锁重试；并发更新用版本号/乐观锁/悲观锁；**版本不匹配须映射冲突业务响应**，禁未映射漏 5xx。
- 缓存一致性：失效/双写；先写库还是先写缓存。
- 迁移/回填：幂等、分批、可回滚/前滚；大表看锁与时长。
- 消息/任务：重复消费、顺序、死信、补偿；Outbox/Saga（如适用）。

## 4. 可靠性

- 外部调用超时/重试/退避/熔断；重试只对幂等操作。
- 限流/降级/队列背压；失败可恢复。
- 日志：结构化、含 traceId、无敏感信息。
- 指标：RED/关键业务；告警阈值；探活见 `observability-and-instrumentation`（有运行时服务则须可调用探活或债项）。
- 配置/密钥：环境变量/密钥库；默认值安全；零入库；对外环境禁 DEBUG 技术错误页。

## 5. 测试与证据

- 单测：业务规则/边界/异常/幂等。
- 集成：真实数据库/缓存/消息（可用容器）；契约测试。
- **SQL 契约（硬）**：注解/XML 内 SQL 也要有可执行证据——`UNION` 的 `ORDER BY` 只允许引用第一段输出别名；派生表/聚合/排序按目标数据库方言实跑一次；Mapper 单测 mock 不能替代 SQL 可执行。
- 负面验证：鉴权/越权、参数边界、终态重复、不存在对象、错误码。
- 证据：测试命令+结果、关键日志/指标、迁移/配置变更说明。
- 未验证项明示；不把“编译通过”当“功能通过”。

## 6. 常见坑

- 只做 happy path；鉴权/越权漏测。
- 长事务、锁等待、N+1、无界查询。
- 重试风暴、无超时、异常吞噬。
- 日志打印 token/PII；错误回显内部信息。
- 迁移不可回滚、配置默认值不安全。

## 常见合理化与反驳

| 合理化 | 现实 |
| --- | --- |
| 「主路径通了就算完」 | 权限/幂等/事务/失败路径须有自测证据。 |
| 「空 catch 先顶住」 | 吞异常=静默坏数据；记日志并上抛或明确业务码。 |
| 「并发很少，先不加锁」 | 资金/库存/唯一约束命中面必须硬补。 |
| 「404 用框架默认页」 | API 客户端只认信封；HTML/URLconf 既不可解析又泄露路径。 |
| 「上传看扩展名就够」 | 伪装扩展名绕过；类型以内容为准（S5）。 |
