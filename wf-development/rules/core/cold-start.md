# 开局卡（开发轨）

> **读取级别：常驻**。新会话 / 切包 / 接管任务 **先读本文（≤90 行）**，再按需读 `AGENTS.md` 口令表。  
> **中段**：心跳重锚身份 + 当前步骤包（及所在子机）；禁止通读全书。  
> **冲突**：用户本轮明确指令 > 根 AGENTS > 开局卡/包规则；与门/红线冲突须先说明再等选择。

## 1. 硬约束

1. **每轮先判、再动手**：先判新任务/续跑/只读；新任务或范围变化 → 复述目标/范围/验收并确认；续跑一行确认；只读一句话；首行锚 `route/step/packet` 或 `mode=analyze`；未确认禁写、禁下结论。
2. **澄清追问**：先查可查事实；仍不明确 → 一次只问 1 个关键问题（附候选/推荐），问到能做出可验证方案（关键项 ≥95% 把握）；不把提问当流程。
3. **执行前检查**：错误前提/逻辑跳跃/信息缺失；不迎合；数字/人物/结论核实来源；用户有误直接指出依据与风险；提醒忽略的变量、成本、偏差。
4. **方案择优**：不适配/明显更差 → 依据 + 主推（可附 1 备选），禁静默照做；用户坚持 → 执行并记 `deviation=`。
5. **执行纪律**：给方案先说权衡；跑命令前确认环境与依赖；失败先析因，同方案 2 次无效换路径。
6. **改动纪律**：动手前说明拟改文件；优先直接编辑，批量/重复才写脚本；最小改动；先工具后子代理；改动面超预期先停。
7. **完成只认门**：`-Claim` → `CLAIM: ALLOWED`；无 ALLOWED 禁写完成/通过/可提测。有 UI → 当前包内前端硬门；无 UI 标 `na`。
8. **收尾六点**：任务结束/交付按六点（完成/文件/验证/假设/风险/下一步）；只读或状态回 2～3 行 + 下一步；主动发现 ≤3 条（问题+依据+建议+是否阻塞）。
9. **文档现行**：只写当前有效；删除即移除；不写历史/旧方案/变更原因；不写修改方案。
10. **读链**：本文 → `_chain` → 当前节点包 → §6 技能 → 模板 ≤1；同时只激活一个节点包。
11. **技能闭环**：§6 必开 skill 打开→执行→回包；禁止粘贴代替。
12. **心跳**：切步/出子机/长会话每 3～5 轮一行，带 `packet=`/`role=`/`task=`。
13. **冲突裁决**：用户当轮明确指令 > 包规则；与硬门冲突先说明风险，由用户二选一；不静默拒绝也不盲从。
14. **证据红线**：证据先于结论；禁刷绿；密钥零入库。

## 2. 本步命令

| 场景 | RUN |
| --- | --- |
| 进 workflow | 读 `_chain.md` 一次（顺序、`when`、推进）→ 落到入口 step / 子机 |
| 进长链子区 | 读 `_region-*.md` 一次 → 区内逐步 |
| 执行 step | 开该步骤包 → §6 必开 skill 闭环 → 回包完成门/产出 |
| 中断/续跑 | 读 `activeContext` 进行中 + 当前 `packet=`；从当前步继续，不从头重跑；packet 丢失用 `_chain` 定位；缺口写未验证 |
| 口令/链路未命中 | 按 `routing.md` 五元组选**最小可用入口**；仍不唯一 → 问 1 个 + 推荐；不硬套、不拒做 |
| 声称完成 | `verify/Invoke-Gate.ps1 -Claim` |
| 小步/纯文档 | 预检/前端可 `na`+理由；**必开 skill 与 Claim 不降** |

## 3. 禁做

- 通读整条 workflow 的全部步骤包 / 一次开多个 skill。
- 跳过必开 skill，或把 SKILL 粘贴进步骤包冒充已执行。
- 切步后仍用旧 `packet=`；Claim DENIED 仍写通过。

## 4. 状态机读链（防稀释 · 不降质）

```text
父状态机  rules/packets/<wf>/_chain.md          ← 进 wf 一次
 └─ 子状态机 rules/packets/<wf>/_region-<id>.md ← 进该区一次（长链才有）
      └─ 步骤包   rules/packets/<wf>/<step>.md  ← 当前唯一激活
           └─ 技能闭环 skills/<name>/SKILL.md   ← §6 必开/条件开：打开→执行→回步骤包
                └─ 模板（可选，至多 1）
```

| 层级 | 管什么 | 不管什么 |
| --- | --- | --- |
| `_chain` / `_region` | 路径、入口、区内步骤表 | 方法细节 |
| 步骤包 | 门、产出、完成、编排 | 不粘贴 skill 全文 |
| skill | 专业方法/必做（质量） | 不改门名/Claim |
| `agents/<id>.yaml` | 角色边界（能定什么/何时停/向谁升级）、派工阈值 | **不逐步读**：派子代理或改角色时才读 |

## 5. 回执

```text
route=… | step=… | region=…|na | packet=rules/packets/… | reads=… | skills=name|done|na | claim=… | next=…
```

`packet=` 丢失或必开 skill 未闭环 = 先重锚/补做，再继续。
