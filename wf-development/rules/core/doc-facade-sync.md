# 门面同步（开发）

> **读取级别：参考**（事件触发时读；收尾不再强制 `facade=` 字段）。
> **真源**：档案 / `activeContext` / 计划；根 README 只镜像已核实对外句。

## 1. 目的

把本轮已核实、对外可见的入口/运行/目录变化，轻量同步到根 README（及档案要求的对外句）。

## 2. 触发

| 级别 | 何时 |
| --- | --- |
| 必 | 版本 bump、迭代关闭、发布/上线、对外入口命令实质变化 |
| 按需 | 本轮核实的 README 已断句/过时句 |
| 免 | 纯内部实现、未改对外可见事实 |

## 3. 做法

1. 先改档案/`activeContext`/计划命中行，再改根 README 对应句；禁只改 README。  
2. 只改**本轮已变**相关句；禁止为「保险」通读全文或重排章节。  
3. 无根 README → 写「无门面变化」（接入/点名新建除外）。  
4. 用户确认推迟 → 收尾第 6 点写推迟原因；必触发未做且未推迟 → 不得收尾称同步完成。

## 4. 收尾表述

有门面变化时在收尾第 6 点写一句（已同步 / 无门面变化 / 推迟+原因）。**不另造** `facade=` / `triad=` 字段。
