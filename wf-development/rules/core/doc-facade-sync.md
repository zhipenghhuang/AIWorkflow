# 门面与对外事实同步（开发）

> **定位**：根 `README.md` 与档案中**对外可见句**的事件触发同步。  
> **不替代**：状态「三处同拍」（计划 §0 ↔ INDEX ↔ `activeContext`）仍只认 `execution-contract.md` §4 规则 7；关账/materials 仍认 `doc-governance.md` §7。  
> **禁每轮全扫**：未命中下表触发 → 不打开、不对账根 README；日常身份短读仍只读档案表。  
> **写法**：轻量改已有对应句；结构大动走 `project-readme.md` 偏好确认。实例面禁写工作流包用途/装载/升级（见 `AGENTS.md` 多包·实例面）。

## 1. 本包表面

| 表面 | 本包职责 |
| --- | --- |
| 身份真源 | `project-profile.md` §1/§2 命中行 + `activeContext` 总览 |
| 根 README | **默认由本包维护**（多包同仓时产品/测试只提差异，不并行大改） |
| 根 CHANGELOG | 仅正式发版/点名发版（见 `versioning.md` / 文档治理） |
| materials `{ver}/README` | 关账/发资料时按 §7，非日常门面 |

## 2. 触发矩阵（事件 × 必/可）

| 触发 | 档案/总览 | 根 README | materials README | 根 CHANGELOG | 三处同拍 |
| --- | --- | --- | --- | --- | --- |
| 日常 / 语义未变 | 否* | 否 | 否 | 否 | 可只改进行中 |
| 阶段·门·焦点·下一步语义变 | 否* | 否 | 否 | 否 | **必** |
| 本轮核实的**对外可见事实**变（版本号、怎么跑、入口 URL、文档链、能力一句话等，且 README/档案已有对应句或本应有） | **必**（命中行） | **必**（对应句） | 否 | 否 | 按需 |
| **产品/迭代版本 bump**（对外承诺的版本字段变） | **必** | **必**（若已写版本/跑法/文档链） | 关账时 | 正式发版时 | 阶段变则必 |
| **迭代关闭**（`confirm_iteration_close` 后 §7.1） | **必**（指向下期） | **按需**† | **必** | 跳过除非发版 | **必** |
| **发布 / 上线**（release 记录·部署后） | **必** | **必**（轻量） | 按发版 | **必** | **必** |
| 资料不足升级 | **必** | 有缺口则**必**补已核实句；无缺口=`na` | 否 | 否 | 热层 |
| 点名生成·更新·整理 README | 先真源 | 按偏好 | 否 | 否 | 按需 |

\*纯状态跳变不改档案地图。  
†换迭代未发版：仅当 README 仍写已关闭迭代为「当前」或入口已断 → 必须改；否则可 `facade=na`。正式发版/结项 → 升级为**必**。

**对外可见事实（判定）**：会出现在根 README、对外说明、或新人「怎么跑起来」路径上的现行值；内部任务卡/评审意见/密钥/仅 AI 工作流路径不算。

## 3. 执行顺序与预算

1. 先改身份真源（档案命中行 / 总览），再改根 README 对应句；禁只改 README。  
2. 只读/只改**本轮已变字段**相关句；禁止为「保险」通读全文或重排章节。  
3. 无根 README → `facade=na`（接入/点名新建除外）。  
4. 用户确认推迟 → `facade=deferred:<原因>`；必触发未做且未 defer → 不得收尾称同步完成。

## 4. 收尾 `sync=`

在原有 `triad=` 之外增加（可同字段）：

`facade=aligned` | `facade=na` | `facade=deferred:<原因>`

- 未命中 §2 必/按需触发 → 写 `facade=na`（不必读本文件全文）。  
- 命中且已轻量对齐 → `facade=aligned`。  
- 只读分析 → `facade=na`。
