### 本步动作清单

- 首条回执含 mode=（缺陷批加严，见 subagents）。
- 拉取后读全单：提交信息（标题/steps/数据/环境/附件）＋历史备注/讨论＋产品评估/回复附件。
- **批量侦察**（子代理编排 ）：≥5 单且读单成本高（多备注/附件/评估单）或合计 ≥20k token → 逐单只读扇出（一单/小批一子代理），返回「分类候选/证据缺口/查重键/产品评估要点」≤30 行。
- 达阈值未扇出→deviation=subagent_skipped:<理由>。
- 编排集中读回执并读关键单原文。
- 不可用→deviation=subagent_skipped:unavailable，仍进 triage 出分类表。
- 同号重复修复预检。
- 归组后进入 triage（未 triage 禁改码）。
- 历史预检跳过项：产品缺陷待产品确认 → 跳过标注「待产品」。
- 已修复未再激活 → 跳过标注「已处理」。
- 无法确认被激活 → 重新分类处置。
- 产品已回复/已退回 → 直接进 product_decision。
