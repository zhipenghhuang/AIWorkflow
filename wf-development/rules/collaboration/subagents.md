# 子代理编排（执行档位 · 扇出读 · 汇聚写）

> **定位**：本包唯一子代理编排口径；`workflows/` 与 `agents/` 只写「按本文取档/派工/回收」，不重复阈值。  
> **原则**：**先工具、再单上下文分节、再只读扇出、最后写分片**；能直做不拆；达阈值默认拆或声明偏差。  
> **净收益**＝上下文卸载＋墙钟加速＋质量增益−（重复读取＋合并核验＋漂移风险）。主收益优先**上下文卫生与独立核验**，其次墙钟。  
> **择优**：用户点名优先；未点名时由 AI 按项目实际、宿主能力、共享资源与净收益选择档位/并行宽度；阈值只作默认触发器。  
> **契约文件**：实施/侦察子代理 → `../agents/worker-agent.yaml`；拆分档/波末独立核验 → `../agents/reviewer-agent.yaml`（派工时附带，禁只靠口头角色名）。完成门只读核验可另附 `../agents/verifier-agent.yaml`。

**派工前 3 问**（仅**未达**§2 阈值时的可选拆分；**不得**否决已命中阈值）：① 能否脚本/校验器/单上下文分节完成？② 单元是否独立且写集不相交（含生成物/配置/迁移/测试数据/账号/端口/profile；或只读）？③ 合并/核验是否机械、返回能否 ≤30 行？三问皆否 → 直做。

## 0. 实例生命周期（硬）

> 契约 YAML 是**角色模板**，不是常驻单例。宿主 Task：`新开`＝新 Task（不带作者会话）；`resume`＝续同一 Task。下表不可让。

| 动作 | 要求 |
| --- | --- |
| **分片扇出** | 每一任务/模块/bug **新开**一个子代理；禁把上一单元会话 `resume` 成下一单元 |
| **拆分档 / 波末核验** | Writer 完成后 **新开 fresh** `reviewer-agent`（或完成门场景的 `verifier-agent`）；**禁** `resume` Writer；核验上下文只给产物＋验收＋diff，不给作者解释/自评 |
| **单写手档** | 整波允许 **1 个** writer（本会话或 1 个子代理串行）；波末核验仍须 §0 fresh，不与 writer 同会话 |
| **串行下一批** | 默认 **新开**；仅派发包标明同一任务号/同一 DraftPath 且「继续」未完成时可 `resume` 同 worker |
| **并行同波** | 每路各 **新开**；并发 ≤3 |
| **失败补跑** | 同回合对同任务可重派 ≤1（优先新开）；同方案无效须换路径；禁空转重派同一方案 |

## 1. 执行档位

| 档 | 适用 | 形态 | 落盘 |
| --- | --- | --- | --- |
| **工具档** | 门禁、校验器、grep/统计、脚本、日志过滤 | 确定性执行，0 token；不派子代理 | 日志/摘要 |
| **直做档** | 默认；单文件、小批、单文档、需全局判断；L0；宿主无子代理 | 本会话直接做 | 正式产物 |
| **单写手档** | 同一文件集/同一波次/需全局一致，且不适合多 writer 拆分 | 本会话或 **1 个 writer 子代理**串行完成（§0）；波末独立评审 | 正式产物 |
| **分片档** | 读：≥20k token /≥5 文件；写：**≥3 个可独立任务且文件集不相交**（含清单已标 `[P]`） | 一任务/一模块/一 bug 一子代理（§0 新开）；读可并行；写文件不相交可并行≤3；批末门禁→核验→下一批 | `.draft/{任务}/`＋正式产物 |
| **拆分档** | 高风险/大改/破坏性/需独立核验 | Writer → 同回合 fresh `reviewer-agent`（§0）→ 编排合并 | 草稿＋正式产物 |

**开跑声明（每波/每批实施开工前）**：一行 `mode=工具|直做|单写手|分片|拆分 | reason=...`；直做也写 reason；达阈值未拆记 `deviation=subagent_skipped:<理由>`。  
**缺陷批加严**：进入 `defect-fix` 的 pull/triage/fix 波次，首条有效回执须含 `mode=`（缺则补写再继续）；宿主无子代理 → `mode=直做|单写手` + `deviation=subagent_skipped:unavailable`，**不得省略 triage 分类表**（见 `fix-collaboration.md` §4.0）。同文件集默认 `mode=单写手`。

> **单写手 ≠ 免评审**：同一文件集/整波可由本会话或 1 个 writer 子代理串行完成，但波末仍须 `reviewer-agent` 独立评审；L 任务内部拆，不因单写手合并 L。

## 2. 取档阈值（默认触发器；按净收益与共享资源择优）

| 场景 | 阈值 | 取档 |
| --- | --- | --- |
| 实施/迭代 | **≥3 个可独立任务且文件集不相交**（或清单 `[P]`≥3 组） | 分片；一组一子代理；**文件不相交可并行≤3** |
| L0 微改/单文件 | — | 直做 |
| 缺陷批量 triage | **≥5 单且读单成本高**或合计 ≥20k token | 逐单只读侦察（可并行≤3）；**分类表由编排集中输出**（§4.0）；不可用→直做仍出表 |
| 缺陷修复分片 | ≥3 单且文件不重叠 | 分片；文件不相交可并行≤3；**重叠/同文件集→单写手或合并组串行** |
| 代码评审 | >400 行有效 diff 或 L3 | 拆分/维度扇出（维度只读可并行≤3） |
| 设计 | L3/架构级且 ≥3 领域 | 只读领域侦察（可并行≤3）；方案正文单写手 |
| 发布就绪 | L3/多系统 | 按检查域只读扇出；GO/NO-GO 集中 |
| 文档吸收 | ≥3 份新文档 | 只读抽取扇出（可并行≤3） |
| 代码地图/影响面 | 大仓或改动 ≥5 文件 | 只读 scout（可并行按域） |
| 门禁日志 | 先脚本过滤；多文件语义归因才子代理 | **工具优先** |
| 同一文件/同一清单/同一单据/同一缺陷 | — | **禁并行写**，直做 |

达阈值默认拆；若合并成本高于收益、共享资源无法隔离或用户点名直做 → 可直做，记 `deviation=subagent_skipped:<理由>`（`unavailable`/`user` 除外须写清）。
未达阈值但 2 个高价值独立单元净收益为正 → 也可拆，不把「≥3」当上限。

> **`[P]` 机检**：`validate_tasklist.py` 校验同 `[P]` 文件重叠、相互依赖、并行数 >3；任一 FAIL 先改任务清单，不得带冲突派工。

## 3. 并行与隔离

**共享写域** = 同一文件/文件集 + 生成物/锁文件 + 迁移/schema + 全局配置/路由/索引/设计 tokens + 同一 DB/测试数据/账号/端口/profile/下载目录中的可写或会话变更部分 + 同一外部单据/平台记录。任一共享可写 → 串行或隔离。MCP 的会话/当前上下文/登录态/页面状态/浏览器全局状态也按共享可写状态处理。

| 类型 | 可否并行 | 条件 |
| --- | --- | --- |
| 只读 scout / 文档抽取 / 日志归因 / 评审维度 | **可** | 并发 ≤3；返回各 ≤30 行 |
| 实施/修复写分片 | **可** | 文件集不相交；并发 ≤3；同文件集必须合并为一组串行 |
| 跨会话（独立宿主/会话） | **可** | 默认正常改项目；同文件/共享可写状态并发时串行、分工或按需隔离；MCP 按实际隔离能力与冲突面判断，同一实例无独立会话/请求级路由能力时串行 |
| 单写手（同文件集/整波） | **否（与其它 writer）** | 只允许 1 个 writer；其他 agent 只读；波末独立评审 |
| 同一清单正文/方案正文/报告/发布文档 | **否** | 编排单写手回写 |
| Writer∥Reviewer（拆分档） | **否** | 同回合串行：写完再 fresh 验（§0） |

并行冲突/覆盖风险 → 立即串行并记偏差。

> 并发宽度是默认护栏：只读扇出在合并机械、宿主资源允许且无共享写域时可上调；写分片/UI 默认 ≤3/≤2，需突破时用隔离套或串行。

## 4. 失败降级（不可让）

任一项 → **同回合降级直做/串行补齐**，禁空转重派同一方案：超时/deadline/无产物/空返回；`rules=violation` 或 `scope=over` 无法收敛；连续 2 批负收益。  
收尾：`deviation=subagent_degraded:<timeout|empty|violation|neg_roi>`。宿主无子代理 → 全程直做 + `subagent=unavailable`。

## 5. 扇出读 · 汇聚写（硬约束）

- 读可扇出：代码地图、影响面、日志、文档抽取、逐单分析、领域侦察、证据核对。  
- 写必须单写手或文件集不相交；同一文件/任务清单/方案/报告/发布文档禁并行写。  
- 判断、优先级、终态、门禁、git、平台回写、GO/NO-GO 留在编排；子代理不得过 `hitl`/`gate`。  
- 子代理不改任务清单/开发计划/需求基线/方案正文；完成状态由编排核验后回写。  
- 同文件集多个子代理必须合并成一组串行；禁止并行覆盖。

## 6. 派工包（7 项，缺一不派）

1. 任务与验收（任务号/RP/AC/DoD）。  
2. 边界（允许路径/文件集；共享可写资源/隔离方式；禁改清单外）。  
3. 输入（路径＋节；**不附整本**；不读其它包）。  
4. 规则摘录（只带 3～5 条相关红线＋契约文件路径；禁只靠口头角色名）。  
5. 输出契约（草稿路径/代码范围/返回字段）。  
6. 返回格式（≤30 行固定字段；禁日志全文/推理过程）。  
7. 禁止事项（git/平台/门/超范围/同命令重跑）。  

## 7. 回收与合并（编排必做）

- 文件在、字段齐、计数一致、证据可打开、规则回执；失败同回合补跑。  
- 去重与冲突：同一结论只留一条；冲突以代码/命令输出/证据为准；不采信口头完成。  
- 写分片合并后跑一次定向/全量门禁；单文件不重复写。  
- 规则回执：`rules=ok|violation:<条款>`、`scope=ok|over`、`evidence=…`；违规即回退重派或降级直做。  
- 失败：同回合重测 ≤1；同方案无效 2 次换路径；连续失败停止上报。

## 8. 上下文卫生（防稀释）

- 主上下文只留派工摘要、返回摘要、核验结论；原始日志/大 diff/长文档落盘。  
- 子代理只读派发摘录与本批相关节；不通读整本rules/档案/历史；同一文件不重读。  
- 后续步骤 delta-only；批末只重读当前步 must＋当前门，不重读整本。  
- **独立核验**：只给产物＋验收＋diff，不给作者解释/自评（防锚定）；实例须 §0 fresh。  
- 并发默认 ≤3（见 §3 宽度护栏）；共享写域/同一文件/同一账号/同一发布窗口一律串行或隔离。  
- 草稿落 `.draft/{任务}/`，不入库；已完结 draft 按 `rules/doc-governance.md` §8（点名/关版本可清；日常收尾不向用户追问）。

## 9. 成本守卫

- **负收益信号**：返回 >30 行、合并/口径冲突、返工、主上下文回读原始证据、超范围。  
- 连续 2 批出现负收益信号 → 回直做（见 §4）。  
- 批末一行：`batch | mode | units | parallel | returns≤30 | conflicts | rework | verdict=keep|direct|degraded`；不写长报告。  
- 质量投资型拆分（独立核验、维度评审）只在 L3/高风险/大改启用。  
- 不为「多 Agent」而拆；不把确定性工作交给 LLM。
