# 子代理编排（执行档位 · 扇出读 · 汇聚写）

> **定位**：本包取档/生命周期/派工回收的**短口径**；批流、冒烟闸、准确度红线、MCP/退程、计划驱动详版 → `../special/multi-agent-output.md`（按节读，禁通读）。  
> **原则**：**先脚本/工具、再决策树取档、再只读扇出、最后写分片**；能直跑不拆；达阈值默认拆或声明偏差。  
> **净收益**＝上下文卸载＋墙钟加速＋质量增益−（重复读取＋合并核验＋漂移风险）。主收益优先**上下文卫生与独立核验**，其次墙钟。  
> **择优**：用户点名优先；未点名时默认按决策树，可依项目实际/宿主/共享资源/净收益调整，须在开跑声明写理由。  
> **契约文件**：执行/模块子代理 → `../agents/worker-agent.yaml`；拆分档核验 → `../agents/reviewer-agent.yaml`（派工时附带，禁只靠口头角色名）。

**派工前 3 问**（仅**未达**决策树阈值时的可选拆分；**不得**否决已命中的多模块/拆分档）：① 脚本/校验器能否完成？② 单元独立且写集不相交（含账号/端口/profile/写域；或只读）？③ 合并核验机械且返回 ≤30 行？三问皆否 → 直跑。

## 0. 实例生命周期（硬）

> 契约 YAML 是**角色模板**，不是常驻单例。宿主 Task：`新开`＝新 Task（不带作者会话）；`resume`＝续同一 Task。下表不可让。

| 动作 | 要求 |
| --- | --- |
| **模块 / 生成分片** | 每一模块（或每一生成 draft 域）**新开**一个子代理；禁把上一模块会话 `resume` 成下一模块 |
| **拆分档核验** | Worker 完成后 **新开 fresh** `reviewer-agent`；**禁** `resume` Worker；核验不收 Worker 推理/自评（防锚定） |
| **串行下一模块 / 下一批** | 默认 **新开**；仅「继续」同批未完成且派发包标明同一 `DraftPath`/`B-Vx-xx` 时可 `resume` 同 worker |
| **并行同 PG** | 每路各 **新开**；并发 ≤3（UI 默认 ≤2，见 multi-agent §1.5.3） |
| **失败补跑** | 同回合对同批可重派 ≤1（优先新开）；同方案无效须换路径；禁空转重派同一方案 |
| **浏览器** | 复用浏览器进程 ≠ 复用页面上下文；跨模块须重新 snapshot（详 multi-agent §2.2） |

## 1. 执行档位

| 档 | 适用 | 形态 | 落盘 |
| --- | --- | --- | --- |
| **脚本档** | 已脚本化＋稳定主链/回归/确定性接口 | 执行器回放；失败再 AI 复核；不派子代理 | jsonl＋证据 |
| **直跑档** | 「继续」单模块；单模块小批；探索小章程；宿主无子代理 | 本会话直接执行 | 本模块执行记录＋证据 |
| **模块子代理档** | 同轮 ≥2 装填模块（或计划 §3 明示多模块） | 一模块一子代理（§0 新开）；编排核验后下一模块 | 各模块执行记录＋证据 |
| **拆分档** | 单模块 ≈>20 条 / P0 写密集 / 需隔离核验 / 用户点名 | Worker → fresh Reviewer（§0）→ 编排合并 | jsonl＋执行记录 |

**开跑声明（不可省）**：`exec_mode=脚本|直跑|模块子代理|拆分` + 对照决策树条款一句；并行则 `pg=PG-xx`，否则 `pg=na`（与技能 §2 / 收尾字段同名）。达阈值未拆记 `deviation=subagent_skipped:<理由>`。

> **取档决策树（命中即停）**详版：`multi-agent-output.md` §1.5.1。摘要：脚本 → 用户点名 → 接口单 Agent → 无 Task 直跑 → 「继续」单模块直跑 → ≥2 模块子代理 → 单模块大/长链拆分 → 其余直跑。

### 1.1 执行补取档（仅 execute 缺行/冲突时）

> **计划步勿打开本文。** 计划 §3.1 填表真源=计划模板该节（读链：步骤卡→技能→模板）。  
> 本节只服务执行：计划缺行/冲突时按 §1 档位与决策树摘要补取档；详版并行按需读 `multi-agent-output.md` §1.5.3（禁通读）。  
> **子代理 ≠ 并行**；无互斥隔离 → `pg=na`/串行；宿主无 Task → 直跑 + `subagent=unavailable`。

## 2. 取档阈值（默认触发器）

| 场景 | 阈值 | 取档 |
| --- | --- | --- |
| 执行（超大 draft 分片） | ≥3 模块且（≥40 条或点名分片） | 执行期再拆：一模块一子代理写 `.draft/execute/`；**计划形态仍写「模块子代理」**（不另造第五档）；文件不相交可并行≤3 |
| 平台缺陷回归 / 缺陷批读单 | ≥5 单且读单成本高或 ≥20k token | 逐单只读侦察（可并行≤3）；分拣/复测/回写集中；复测默认串行（同账号/写域/同用例禁并行）；达阈值未扇出记 `deviation=subagent_skipped:<理由>` |
| 执行 | 见 §1 / 计划 §3.1 | 模块子代理 / 直跑 / 拆分 / 脚本 |
| 大范围调查 | ≥20k token 或 ≥5 文件 | 只读扇出（可并行≤3） |
| 同一文件/同一场景/共享写域 | — | **禁并行写** |

未达阈值但 2 个高价值独立单元净收益为正 → 也可拆。计划 §3.1 与决策树冲突时，隔离/写域红线优先，记 `plan_batch_conflict`。  
**平台回归加严**（`defect` 轨 classify/search）：首条有效回执含 `mode=直跑|只读扇出`；宿主无子代理 → `mode=直跑` + `deviation=subagent_skipped:unavailable`；子代理不写平台、不改状态；不把计划执行的 `pg=` 并行套到平台复测。

## 3. 并行与隔离

共享写域定义与并行表 → `multi-agent-output.md` §1.5.3。要点：只读/draft/隔离套可并行≤3；同 MCP 实例需支持独立会话/路由或独占实例；共享 profile/账号/写域串行或隔离；**一次一个 PG**；Worker∥Reviewer 禁并行。

## 4. 失败降级（不可让）

超时/空产物/违规无法收敛/连续 2 批负收益 → **同回合降级直做/串行补齐**，禁空转重派同一方案。  
收尾：`deviation=subagent_degraded:<timeout|empty|violation|neg_roi>`。宿主无子代理 → 全程直跑 + `subagent=unavailable`。

## 5. 扇出读 · 汇聚写（硬约束）

- 读可扇出；写须单写手或文件集不相交；同一场景/模块执行记录/报告/计划/单据禁并行写。  
- 判断、终态、门禁、平台回写、合并结论留在编排；子代理不得过 `hitl`/`gate`、不得 git/交平台/改他模块。  
- 分片生成只写 draft；编排合并后跑意图覆盖/深度检查。

## 6. 派工包（7 项，缺一不派）

1. 任务与验收（含 `B-Vx-xx`/卷/模块）  
2. 边界（允许路径/写域/隔离套/并行组）  
3. 输入节选（**不附整本**）  
4. 规则摘录 3～5 条＋契约路径  
5. 输出契约（执行记录/DraftPath/证据目录）  
6. 返回 ≤30 行固定字段  
7. 禁止事项（git/平台/门/超范围/同命令空重跑）

## 7. 回收与合并（编排必做）

- 文件在、逐条落盘、计数一致、`result` 合法、证据可打开；规则回执；不采信口头完成。  
- 批末核验通过再下一批/下一模块（§0 默认新开）。  
- 失败：同回合重测 ≤1；同方案无效 2 次换路径。

## 8. 上下文卫生 · 成本守卫

- 主上下文只留派工/返回/核验摘要；子代理不通读整本；delta-only。  
- Reviewer 不收 Worker 推理（§0）。  
- 负收益信号：返回 >30 行、合并冲突、返工、主上下文回读原始证据、超范围 → 连续 2 批回直做。  
- 批末一行：`batch | mode | units | parallel | returns≤30 | conflicts | rework | verdict=keep|direct|degraded`。  
- 不为「多 Agent」而拆；不把确定性校验交给 LLM。
