- **packet**：`rules/packets/defect/submit.md`
- **角色**：`bug-agent`（缺陷平台协作）。查重/提交/回归/回写按专规；备注与状态同轮；读者=开发/产品；本步只做该角色职责；越界交回或升级。

## 4. 本步门

- **HITL `confirm_remark`**：拟关/激/解决/标重复/补充澄清/回归写回 → 先列 id+结论+备注全文；确认后执行。
- **条件判定 `hitl:remark_writeback`**：拟关/激/解决/标重复/补充澄清/回归写回；满足→真，否则跳过该门。
- **HITL `confirm_platform`**：有拟交平台/新建缺陷单 → STOP；回写走备注门；≠ git；无平台动作跳过。
- **条件判定 `hitl:platform_submit`**：拟新建缺陷单/交平台（含：发现即提交预授权｜批末/阶段末/收尾确认｜用户口令提交到平台；见 collaboration §6.1）；满足→真，否则跳过该门。
- **GATE `writeback-receipt`**：按本包门表该门的检查方法核验并留证据；未过不得宣称完成。
- **推进**：默认本步完成后即停（仍输出收尾骨架），不打开下一步。仅当本会话是按链、继续、按计划执行或全链入口时，才进入阶段表的下一未跳过步。

## 5. 本步动作

> **本节 = 本步编排与门槛**（顺序、产出、门、禁做）。
> **方法质量在技能**：§6 列为必开/条件开的 skill 必须按闭环执行，**禁止**把技能正文粘进本包替代实读；**禁止**为省事跳过必开技能。

### 本步动作清单

- remark_writeback＝拟关/激/解决/标重复/补充澄清/回归写回备注。
- 先出 id+备注全文再执行。
- platform_submit＝拟新建单且命中 collaboration §6.1（发现即提交｜批末/阶段末/收尾确认｜用户口令提交到平台）。
- 执行批 ID 与计划对齐。
- 修复批可另立 `B-FIX-xx` 并在计划登记。
- 细则见 `rules/defects/collaboration.md`。
- **交前复判（硬）**：collaboration §5.1 Q13–Q19、Q21–Q22 + §6.0（尤 Q13/Q15/Q19/Q21）。
- 无 `入口指纹` 或（空列表/404/未交付且）`误用已排除≠是` → 禁建单，回 execute。
- 投影禁自拟精简十段、禁现网补证。
- 回执=`{ver}/写回回执.md`（本轮覆盖）。
- 产品缺陷直提产品。
- 建单标题 `[V?][类型]+正文`。
- 列表/仅查重/仅建单（无状态回写）→ 跳过 remark 门。
- 拟新建仍走 platform_submit。
- **缺陷通道**完整交平台即完成（writeback 回执+台账单号）。
- 禁同轮导出包。
- 未回执不得写“已接收”。

### 本步规则卡：投影交单与回执

- **platform_submit**：发现即提交（计划预授权）｜批末/阶段末/收尾确认｜用户口令提交到平台（`collaboration` §6.1）。
- **投影（硬）**：steps=执行失败详情按文案模板投影；**禁自拟精简十段**；禁交单窗现网补截图/主键/文案；缺则回 execute 补采。
- **平台自洽（硬）**：建单/挂靠补证/澄清备注均须可跟做构造+观测自洽；截图/响应**上传并回查**或正文写 `字段=值`；禁测仓 `evidence/…`、本机路径、未上传叶名充证据（`collaboration` 平台自洽 + 文案模板 §5.0.3#16/#17）。
- **附件门（硬）**：UI/含页面复现 → ≥1 钉点截图已挂本单；纯 API → 响应文件已挂**或**正文关键片段齐；回查 `files` 后再写回执（禁「有 json 叶=已交证」）。
- **写入自检（硬 · 新建/正式交平台）**：【提交摘要】含 `问题标题：`+`一句话影响：`+`最小复现：`；末段块名=`【技术附记】`（禁另起【证据】块顶替）；HTML/文本版式按适配「写入前自检」；建单 body 带 `assignedTo`（禁建后再 assign+comment 刷首条备注）。
- **入口门（硬）**：投影前核执行详情含 `入口指纹=`；写接口单须有回查字段=值（Q22）；细则 `collaboration` §5.0.1c / `classification` §0.4。
- **回执**：`{ver}/写回回执.md`（本轮覆盖）；回归写回附范围卡（构建/回归范围/冒烟/影响面/未覆盖；未跑/未覆盖写接受人，槽位见 `collaboration` §7.0）；过 writeback 门。
