## 1. 技法速用手册

- **等价类**：有效/无效各取代表；同类代表不重复测。
- **边界值**：取点口诀 `min-1 / min / min+1 / 典型 / max-1 / max / max+1`——数字、长度、时间、分页、金额都适用。
- **判定表**：条件组合互斥时列规则表，一格一用例（同结果列可合并）。
- **状态迁移**：画状态 × 事件矩阵；每个**非法跃迁**一条负向。
- **场景法**：用户故事串「入口 → 动作 → 观测点」；主路径 + 每条分支变体。
- **组合/配对**：多输入选项用 pairwise 思路裁剪（不做全排列）。
- **算例法**：统计/评分/占量/能力指数等计算类，构造覆盖每个分子/分母桶的最小数据集，写明公式、输入、精度与期望值；分母 0/缺维单列。
- **错误推测**：按历史缺陷谱系补（见 §4）。

## 2. 设计顺序（顺手套七维）

主路径 → 状态与规则 → 负向与非法跃迁 → 边界 → 权限/数据域 → 异常与脏数据 → **视觉/体验**（布局/遮挡/截断/文案/文案减法/空态/加载/错误提示/按钮状态；七维自查见 testcase-agent 完稿自检）。

### 2.1 覆盖全面性（不能只看主流程）

- 每个受影响模块至少覆盖：主路径、状态/规则、负向/边界、权限/数据域、异常/恢复、UI/体验。
- **模块×面矩阵**：按分析表 §2.2 逐格落 `有（点ID）/N/A+依据`；空格=覆盖缺口，不得用“模块简单”跳过。
- **方法×规则矩阵**：P0/高风险规则按分析表 §2.3 至少覆盖适用方法（等价/边界/判定/状态/场景/算例）；只测主路径不算完整。
- 复杂配置/筛选用组合/配对；状态对象画状态 × 事件；写操作必含失败/回查/清理。
- 文档未写死数值 → 仍出行为用例，执行先读现网口径；禁整段不测。
- 用例之外发现（UI/布局/显示/console/network）在执行期记录，不替代用例覆盖。

### 2.2 深度档（不可让 · 完整≠条数）

> **单一出处**：本表。映射无空行只证明「点有人认领」，**不证明深度够**。工作流三闸②引用本表；§4 须落「深度档自检」。  
> **一次到位**：生成时按特征行一次写够可执行厚度与可观测预期；禁靠执行期临时加条补深度。细则判定见工作流 §3.0。  
> **禁止**：场景 1:1 落条无技法展开却称「已全覆盖」；无风险依据的字段穷举/全排列；**为单个事故堆新行**（先扩写本表已有行或 §2.4）。

| 设计点特征 | 最低厚度（可多点共用一条，映射须能指到） |
| --- | --- |
| P0-Smoke / 阻断主链 / GATE | ≥1 主路径成功 + ≥1 关键失败/阻断（可同条可判定分支） |
| 有状态对象/流程 | 合法迁移抽样 + **≥1 非法跃迁**负向 |
| 有数值/长度/时间/金额/分页输入 | ≥1 边界或无效等价 |
| 跨角色 / 租户 / 数据域 | ≥1 **负向拒绝**（明确失败语义，禁弱成功信封）+ 方案点名目标身份 ≥1 **正向可达**（禁高权代测冒充） |
| 写操作 | 失败或写后回查 + 清理；成功须交付方案要求的可观测结果；有权威源则回查对照；纠错/撤回按方案留痕（可并入主条） |
| 方案声明横切或口径类规则 | 幂等/并发/审计/附件/移交/权威复算/固化事实/跨口径对比等：按声明抽样；同键异体拒、冲突不覆盖、不可比须明示、事实不可否定——适用项落入用例；多对象适用时载体≥2 或「不适用+依据」 |
| 受影响 UI 页 | 视觉基础：独立条 **或** 并入相邻预期（执行截图必检，工作流 §2.1.0） |
| 方案含范围/模式变体 | **≥1 组合**或「不适用+依据」；禁只测默认键；**空样本不得写成通过** |
| 有成对日期 | **≥1 倒置或交叉**负向，或「不适用+依据」 |
| 方案点名字段/关键动作/菜单路由 | **≥1 齐套或缺项提示/入口齐套**；步骤写 UI 入口；禁 API 可达冒充页面交付 |
| 有预检与正式提交成对 | **≥1 预检↔提交一致**，或「不适用+依据」 |
| 方案含“不新增/不改变/不自动/禁止”约束 | **≥1 条反向断言**；写清“本该发生的仍发生、本不该出现的未出现”；禁只抄条款 |
| 有配置/样本/权限/时限前提（P0/高风险或前提缺失会误判） | **≥1 条前提缺失断言**：不显示合格/不计分母/不催办/不自动放行；观测点=页面/状态/计数/通知 |
| 有统计/评分/占量/能力指数计算 | **最小分母集 + 独立复算**（公式/输入/精度/期望）+ 分母 0/缺维展示；页面取整不得单独作为通过依据 |
| 有多状态轴/多单据关联 | **≥1 条交叉断言**：A 完成≠B 完成；发货≠到货；关闭≠验证；审核通过≠覆盖 |

- 收尾对照：P0/高风险点标明满足上表哪几行；缺行且无「不适用+依据」→ 覆盖缺口，不得开跑宣称完整。  
- **升版**：优先改写本表已有行/§2.4；确无特征可挂才加行。命中域适应性对照现行表做 diff。  
- 分片超时/直做降级：**同一深度档**，禁用「场景映射齐」替代。
