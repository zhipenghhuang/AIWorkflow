# 细节设计覆盖清单（常青）

> **定位**：功能全量覆盖之外，逐维检查"设计文档/AC 没写死、但用户一定会遇到"的细节。用于测试分析 §2.5、用例生成、评审与探索式选题；不替代功能/接口用例。
> **来源**：HSIM 等真实项目补测缺陷归纳（筛选/显示/状态/交互/文案/异步/批量/规则生效）。示例只作校准，不是穷尽。
> **原则**：设计/AC/原型明确写了 → **功能用例**（全量覆盖）；设计未写但影响可用性/一致性/判断 → **探索式**（P4），发现稳定后回填功能域；影响主路径/数据正确/权限 → 直接升 **P0/P1 功能**。

## 1. 十二维清单

| # | 细节维 | 必查问题 | 判定面/oracle 示例 |
| ---: | --- | --- | --- |
| D01 | 列表/筛选/搜索/排序/分页 | 条件组合、清空、重置、无匹配、超量、默认排序 | 结果集与条件一致；空态文案区分"无数据/无权限/无匹配" |
| D02 | 列/字段显示 | 列显隐、顺序、密度、超长截断、悬停全文、复制 | 列配置持久化；超长不撑破布局；可复制原值 |
| D03 | 空态/错误态/无权限 | 空数据、加载失败、无权限、无匹配是否区分并可下一步 | 文案给原因+动作；不得把无权限写成无数据；空态同屏编号不得误导为「当前有效业务」 |
| D04 | 状态与跨载体一致性 | 列表/详情/运行页/首页徽标、预览/撤回、停止/关闭/作废/重开；同源 KPI/术语 | 同一对象多处状态·用词一致；同源指标名值单位一致；终止后不再显示进行中 |
| D05 | 按钮/入口/位置 | 主次按钮、危险操作相邻、入口位置统一、禁用原因、诱导可点 | 禁用有可见原因或隐藏；不适用/不可比较不得露对比·下钻；危险操作需二次确认 |
| D06 | 交互反馈/连点/异步 | loading、禁用、重复提交、异步任务入口/进度/失败、分步未进阶 | 点击后状态自洽；失败/未进阶有可见原因；异步有任务入口可查；连点只生效一次 |
| D07 | 响应式/窄屏/长文本 | 390px 宽、缩放、长名称、多语言 | 关键动作不被挤出；可换行/折叠/吸底 |
| D08 | 文案/术语一致性 | 同一概念多叫法、错别字、提示是否给下一步 | 术语与方案/PRD 一致；提示含原因+动作 |
| D09 | 跳转/返回/刷新 | 跳转失效、返回丢状态、刷新后保持 | 目标存在且权限一致；刷新不丢筛选/页签 |
| D10 | 批量/部分失败 | 混合合法/非法条目、部分成功、分条结果 | 逐条返回结果；不得整体假成功或静默漏项 |
| D11 | 导出/下载/文件 | 超限转异步、入口、进度、失败、危险文件 | 异步有入口；危险/损坏文件不进正式版本 |
| D12 | 规则/配置生效 | 启用规则后新数据、标准化/发布后刷新、缓存 | 配置对**新产生**数据生效；状态刷新后正确流转 |

## 2. 用法

1. **分析**：§2.5 逐维填 `适用/验证点ID/判定面`；不适用写业务依据。
2. **生成**：适用维至少 1 条功能用例；N/A 需理由；用例 §3 映射到对应验证点。
3. **评审**：逐维核"有没有、能不能判、证据在哪"；缺维=缺口。
4. **探索**：未写进设计的细节风险进 P4 章程；发现稳定后补功能域。
5. **报告**：§6 写"细节维覆盖 x/12、缺口清单"。

## 3. 与功能/探索的划分

| 情形 | 归属 |
| --- | --- |
| 设计/AC/原型明确要求（含筛选条件、列、状态、权限） | 功能用例（全量） |
| 设计未写，但属同一功能面的可用性/一致性/边界体验 | 探索式（P4），发现后回填 |
| 影响数据正确、权限、主路径、资金/合规 | 直接升功能 P0/P1 |
| 纯文案/视觉偏好 | 探索式或产品评审，不单独立 P0 |
