# 实战漏测谱系（发现问题优先）

> **用途**：生成/探索/随机的**错误推测与章程选题**单一速查；来自多产品实战缺陷归类，**非**某项目用例清单。  
> **目的**：测试为发现问题、保证行为正确；通过率是结果，不是目标。  
> **读法**：功能生成对照补条；探索章程按风险选题；随机旅程沿途探针；勿整表抄进每个计划。

## 0. 总则（硬）

| # | 纪律 |
| --- | --- |
| M1 | **发现问题 > 刷绿**：禁为抬高通过率删负向/边界/门禁/入口条；禁弱断言把假成功判过。 |
| M2 | **方案细节全落点**：主读每个可验收单元（GATE/AC/F/R/字段规则/门禁/入口/提示）→ 验证点或「不适用+依据」；禁只测标题级主路径。 |
| M3 | **迭代与完整项目同深度口径**：迭代=范围内细节+邻接宁多勿漏（suite≥module）；完整项目=`full` 库装填；深度不够不得称「已测完」。 |
| M4 | **UI 与 API 双看写操作**：页面成功文案 ≠ 业务已正确落库/状态已变；终态重复调用须断言拒绝或幂等无副作用。 |

## 1. 高频谱系（生成默认对照）

| 码 | 谱系 | 典型探针（通用） | 优先落轨 |
| --- | --- | --- | --- |
| S1 | **假成功 / 终态不校验** | 已确认/已关闭/已作废再调确认·下发·关闭；UI 提示成功但状态未变或脏写 | 功能负向 + 接口 |
| S2 | **前后端校验不一致** | 前端已拦的 0/负/空/倒置/超限，绕 UI 或直打接口仍落库 | 接口 + 功能边界 |
| S3 | **非法值落库** | 空格编码、日期倒置、承诺量&lt;已发生量、数量 0/负/越界 | 功能边界 + 接口 |
| S4 | **状态机 / 业务门禁** | 审批中改关键字段；缺最小字段仍建正式单；预检过但正式失败且明细空；停用后仍可绑 | 功能状态 + 探索 |
| S5 | **并发 / 连点 / 幂等** | 保存并确认连点双单；同键并发后写覆盖；离线确认重复回传 | 功能/接口 + 探索 |
| S6 | **入口 / 投放可见性** | 方案点名菜单无入口；已发布且启用在运行中心/列表仍不可见 | 功能入口 + 探索 |
| S7 | **发布·启用门禁不完整** | 空布局/缺单位/无数据集/缺规则仍可发布升版或启用 | 功能门禁 + 探索 |
| S8 | **权限分权** | 低权改进人姓名/重置密码；关键操作未纳入角色矩阵 | 功能权限 |
| S9 | **列表·筛选·导出** | 勾选导出仍全量；关键词 `%/_` 通配扩大命中；筛选项与行状态不符 | 功能 + 随机沿途 |
| S10 | **配置持久化 / 回显** | 下钻·映射·关联日历保存后丢失或不回显；头状态与明细行不一致 | 功能 + 探索 |
| S11 | **提示不诚实 / 文案误导** | 门禁用错引导；成功提示与落库不一致；默认筛未生效却展示默认值 | UX 探索 + 随机 |
| S12 | **存量与归一** | 历史非标枚举仍展示；迁移后计算版本/快照未递增 | 功能回归 + 探索 |
| S13 | **联动上下文空** | 自动建单缺来源对象/产品等关键头字段；冲销未回写上游数量 | 功能集成 |

## 2. 探索章程选题（建议池 · 每轮 3～6 条取风险高者）

优先从 **S1/S4/S5/S6/S7/S10** 与本期 §0 高影响差量交叉选题；时间盒内以**发现数与可复现证据**衡量，不以「章程步骤跑完」当成功。

## 3. 随机旅程沿途探针（不改选池 · 办结路上顺手）

办结过程中至少留意：**假成功、权限自洽、筛选/导出是否骗人、提示是否诚实、关键配置是否跟着手动路径持久**。发现进分流；不为此改成菜单扫街。

## 4. 反模式

- 用通过率替代验证点结论率或「无阻断」空话。  
- 只测草稿快乐路径，终态/重复调用/权限/入口留白。  
- 探索/随机收尾写「通过」而无发现分类与缺口。  
- 把本谱系写成某产品专属用例库或强制每域全 S1–S13 机械铺条（按风险裁剪）。
