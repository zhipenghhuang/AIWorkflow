# 轨契约 · 探索式测试

> 口令命中「探索式 / 探索测试」生成或执行时默读本文。主链 step 仍用 `testing.yaml`。  
> **定位**：补功能测试测不到/不便测的点 + **细节/体验深挖**（入口下一步、提示/空态诚实、状态误读、门禁假可点等）；**不替代迭代全量**（功能全量为准出主轨）。不另设「补测」轨——深挖即本轨 / 计划 P4。  
> **成败**：以**可复现发现、覆盖缺口、新风险**衡量；禁空「探索通过」或用步骤跑完率当成功。选题速查 `special/defect-findings-spectrum.md` §2。  
> **计划驱动**：按 `{workroot}/test-plan.md` §12；**T1+ 准出强制纳入**（多轨 Q14 / §2.4：条数、必选轴、闭环）。独立口令可即兴（不要求计划，但不顶替 Q14）。  
> **互斥**：本版「该有的本事」主内容随机体检（影响面+常青）→ **计划外** `tracks/random-flows.md`，不塞进本轨。

## 常青边界（硬 · 与功能/接口分流）

| 常青什么 | 不常青什么 |
| --- | --- |
| **轨目录** `{workroot}/exploratory/`、命名纪律、SBTM 节奏、谱系选题方法、发现分流 | **单轮戳夹**（某次 `主题-yyyyMMdd-HHmm` 的探索用例/台账） |
| 历史戳夹作**母题/风险参考**（可读、可对照） | 把上轮 3～6 条章程**原样冻成「探索全量库」**当域常青复跑 |
| 稳定发现沉淀进 **功能/接口 Domain**（或新章程） | 用探索戳文件冒充功能域主档、进 suite 装填计数 |

- **Q11「常青库」只适用于功能/接口 Domain**；探索式成功标准是本轮章程目标闭环 + 可复现发现，**不是**库对齐。  
- 换版本 / 新提测 / 缺陷面明显变化 → **必须重选题**写计划 §12（或即兴新戳），**禁**默认「沿用上版 EXP-01～06 文件名当本轮」。  
- 平铺根目录、文件名缺「探索」、缺戳夹 = **命名违规**（见下）；发现后应迁入戳夹，不把违规形态写成默认可复用资产。

## 章程选题（实际探索 · 不可让）

> 章程必须跟**本期实际风险面**走，不是抄谱系表、也不是复读上轮戳文件。

### 输入（按可得性取用，至少 2 类）

| 源 | 怎么用 |
| --- | --- |
| **分析表 §0** | 高影响差量 / 非目标旁的邻接风险 → 优先入章程或显式跳过 |
| **本项目缺陷平台**（禅道/RDM 等） | 近窗未关/复发/同模块簇标题聚类 → 谱系码对齐后选题；已沉功能负向且稳定的主题**降探索优先级**（改回归，不重复挖洞） |
| **跨项目实战** | 只经 `defect-findings-spectrum.md`（多产品归类速查）；**禁**把他项目用例/戳夹整表搬进本仓当本轮章程 |
| **本轮探索/随机已发现** | debrief 缺口 → 补新章程或补功能/接口条；勿只记观察 |
| **上轮戳夹** | 仅作母题参考；主题可沿用，本场一句按本构建重写；风险已消或已进功能/接口用例 → 换题 |

### 一场一条

- 章程只有一句：**看哪里、用什么、想发现什么**（对齐一个谱系码）。  
- 计划 §12 可留最多 6 条**待办**，按风险排序。**一场只领一条**；其余写下场或不测+理由。禁止把待办铺成逐步用例在同一时间盒跑完。  
- **先领**本产品未关、且本轮功能/接口用例没盖住的最高簇。没有缺陷簇时，才用谱系 §2 的静态优先池。已写成稳定负向用例且近期无复发的，改回归，不在探索里再挖一遍。  
- 页面提示成功之后，要核对记录或状态是否真的变了。同键换内容仍能再建、空请求也返回成功，归**接口轨**；本场不测就在章程里写「不覆盖接口幂等」。  
- 每场：领一条 → 时间盒 → 记下覆盖 / 没碰到 / 发现 / 疑问 / 下一句 → 分流。  
- **发现分流**：缺陷 → 缺陷 + 回归；缺口 → **补功能/接口 Domain**（写下 caseId/主题）或下一句章程；误报 → 记录；交付缺口禁止只进观察。细节类风险按 `rules/special/detail-coverage.md` §3 判定：设计已写 → 功能；未写但影响可用性/一致性 → 探索；影响数据/权限/主路径 → 升 P0/P1 功能。  
- **沉淀清单（硬）**：debrief / 收尾必写「拟补 Domain：…」或「无稳定可沉淀」；禁止只留观察。  
- 独立口令同样一场一条。计划里的探索不替代功能全量，也不降低功能/接口覆盖；**T1+ 跳过本轨不得准出**（Q14）。

## 命名（含时间 · 不可让）

> 探索轮次多、可并列；**一轮一文件夹**，夹名带本轮时间戳。戳取落盘时本机本地时间。

| 产物 | 命名 | 例 |
| --- | --- | --- |
| 轮次夹 | `{workroot}/exploratory/{主题短名}-{yyyyMMdd-HHmm}/` | `…/登录越权-20261015-1430/` |
| 用例 | `{戳夹}/{主题}-{戳}-探索用例.md` | 自描述（禁仅写 `*-用例.md`） |
| 台账 | `{戳夹}/{主题}-{戳}-探索台账.md` | 自描述 |
| 证据 | `{workroot}/exploratory/evidence/{主题短名}-{yyyyMMdd-HHmm}/` | 叶名仍含 caseId |
| 会话记录（可选） | `{workroot}/exploratory/.draft/{章程ID}-{yyyyMMdd-HHmm}-session.md` | 过程 |

- **同戳成对**：同轮用例与台账落同一戳夹；证据子目录同戳。  
- **新开一轮**：新戳夹；旧轮默认保留并列。  
- **续跑**：沿用本轮戳夹，**不另开戳**。  
- **归档**：旧轮整夹移入 `{workroot}/exploratory/_archive/{yyyyMMdd}/`；**禁**进根 `{workroot}/_archive/`。  
- **准出**：报告只引用本计划本轮戳；不与功能/接口台账混计。  

## 红线

- 用例 ID 用 `{前缀}-{NN}`（首字符为字母、连字符分段，如 `EXP-01`；台账合并计数按此识别）；禁纯数字/下划线。  
- **生成对照探索式模板**：章程一句、为何是本场、**3～6 个可判定风险点（逐点结论）**、会话四记（覆盖 / 没碰到 / 疑问 / 下一句）。发现才写可跟做的复现、判定依据与严重度。  
- 生成前至少读分析表 §0（无表须写不适用+依据）。  
- 禁「已登录」「验证功能正常」「探索通过」当记录或收尾。  
- 禁预写整套逐步用例代替会话。  
- **禁**把探索戳夹当 Domain 常青库做 suite 装填/通过率统计；**禁**跨版本默认复用未重选题的 §12。  
- **禁**无缺陷/§0/谱系依据却宣称「本轮探索已覆盖实战高频面」。  
- 探索辅助（可选）：装配 vision-ui（`capabilities/00-contract.md`）时可用自然语言＋截图断言辅助判定；结论仍须可对照主读/现网。  
- 执行与落账细则见 `rules/special/multi-agent-output.md`（jsonl/台账六态与功能轨一致）；计划驱动跨轨见 §4。  
- 证据落本节命名目录，禁抬高通过率。  
- 结果难标准化属预期；收尾须写清章程完成/探索范围与缺口，禁空泛「探索通过」。  
- 探索式不脚本化（`rules/special/script-execution.md` §6）；session 记录/debrief 必做，发现须分流。  
- 章程步骤含菜单/页面时同功能轨：浏览器 MCP 先 UI 再 Network；仅无 UI 断言面（真并发/幂等头等）可 API，台账通道写「混合」。
