# 冲突与优先级（测试轨）

> **定位**：只解决「同一件事在多处出现时以谁为准」；不重复规则正文，不新增门槛。
> **读法**：命中冲突时打开本节；未命中不读。

| 冲突面 | 以谁为准 | 说明 |
| --- | --- | --- |
| 计划 §3.1 批次形态 ↔ 子代理档位 | 阈值 = `collaboration/subagents.md` §2；批次 = 计划 §3.1（须落在阈值内） | 冲突时隔离/写域红线优先，回退并记 `plan_batch_conflict` |
| 计划「全部」↔ 逐条意图范围 | 逐条或区间（`INT-X-01~09`）；「全部」须附覆盖清单 | 闸按展开后集合校验 |

| 报告 ↔ 计划/分析 | 报告引用分析与计划计数 | 不一致 = 报告门 FAIL，不得自造口径 |
