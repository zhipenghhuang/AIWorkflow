# 门面与对外事实同步（测试）

> **定位**：根 `README.md` 与基线/档案中**对外可见句**的事件触发同步。  
> **不替代**：状态「三处同拍」（计划 §0 ↔ 导航 INDEX ↔ `activeContext`）仍只认 `execution-contract.md` §4 规则 7；关账/materials 仍认 `doc-governance.md` §7。  
> **禁每轮全扫**：未命中下表触发 → 不打开、不对账根 README；日常身份短读仍只读档案/基线。  
> **写法**：轻量改已有对应句；结构大动走 `project-readme.md` 偏好确认。实例面禁写工作流包用途/装载/升级（见 `AGENTS.md` 多包·实例面）。  
> **根 CHANGELOG**：本包**不写**。

## 1. 本包表面

| 表面 | 本包职责 |
| --- | --- |
| 身份真源 | `env-baseline.md` / 同仓 product·project-profile（可读）+ `activeContext` 本包分节 |

## 2. 触发矩阵（事件 × 必/可）

| 触发 | 基线/档案/总览 | 根 README | materials README | 根 CHANGELOG | 三处同拍 |
| --- | --- | --- | --- | --- | --- |
| 日常 / 语义未变 | 否* | 否 | 否 | — | 可只改进行中 |
| 阶段·门·焦点·下一步·准出口径语义变 | 否* | 否 | 否 | — | **必** |
| 本轮核实的**对外可见事实**变（测试入口 URL、验收怎么跑等，且 README/基线已有对应句） | **必**（命中行） | **必**（对应句；无则 `na`） | 否 | — | 按需 |
| **被测版本 bump**（提测/部署版本对外字段变） | **必** | **按需**† | 关账时 | — | 阶段变则必 |
| **迭代/版本关闭**（确认后 §7.1） | **必** | **按需**† | **必** | — | **必** |
| **发布 / 上线**（测试准出后；生产记录归开发） | **必**（准出口径） | **按需** | 按发版 | — | **必** |
| 资料不足升级 | **必** | 有缺口则**必**补；无=`na` | 否 | — | 热层 |
| 点名生成·更新·整理 README | 先真源 | 按偏好 | 否 | — | 按需 |

\*纯状态跳变不改基线地图。  
†README 仍写已关闭版本为「当前」或测试入口已断 → 必须改；否则可 `facade=na`。

**对外可见事实（判定）**：会出现在根 README 或对外「怎么验」路径上的现行值；内部用例草稿、缺陷讨论、仅 AI 工作流路径不算。

## 3. 执行顺序与预算

1. 先改基线/档案命中行与总览，再改根 README 对应句；禁只改 README；禁写根 CHANGELOG。  
2. 只改**本轮已变**相关句；禁止为「保险」通读全文。  
3. 无根 README 或无可改测试句 → `facade=na`。  
4. 推迟 → `facade=deferred:<原因>`；必触发未做且未 defer → 不得称同步完成。

## 4. 收尾 `sync=`

`facade=aligned` | `facade=na` | `facade=deferred:<原因>`（与 `triad=` 并列）。未命中触发 → `facade=na`（不必读本文件全文）。
