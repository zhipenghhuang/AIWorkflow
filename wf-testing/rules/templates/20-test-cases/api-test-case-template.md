# {接口域} 执行记录（接口）

> **record_format**：`intent-v1` ｜ **类型**：接口/契约
> **定位**：接口执行时同步生成；契约、请求要点、结果、证据、缺陷同文件。
> **执行口径**：AI 以原文/接口契约 + 分析意图/风险为准直接调用与判定；下表步骤是请求链，供复核，不作为逐条脚本。确定性接口同轮产出脚本。
> **落盘**：`{workroot}/{ver}/api/{NN}-{短名}-执行记录.md`（平铺）；脚本 `{workroot}/scripts/`。
> **判定三要素**：HTTP 状态码 + 业务码/业务信号 + 关键字段；**仅 2xx 不得记通过**；写操作写后回查（回查字段=值）；假成功/200 空壳 = 失败。  
> **path 来源（硬）**：须原文/OpenAPI/本轮 Network/前端契约；禁命名对称猜 path。失败/待实现须 `入口指纹=` +（空列表/404/未交付时）`误用已排除=是`。
