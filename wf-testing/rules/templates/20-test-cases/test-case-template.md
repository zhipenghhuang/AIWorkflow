## 2. 失败 / 阻塞 / 待实现详情（仅这些行需要）

> **成本**：通过行只留 §1 表，不写本节。  
> **成稿（硬）**：失败/待实现/需外力阻塞 → **当场**按下列槽位写满（Markdown）；槽位同构 `defect-writeup-template.md` **§5.0.1a**；厚度门 **§5.0.1b**；缺则当场补采。  
> **交平台**：只投影本节为十段 HTML，**禁**另造叙述、**禁**为交单现网回查补事实/重开页面补拍；截图/响应只上传已有。`surface` 决定复现写法：`ui`/`ui+api` 写**页面/菜单/控件**，`api` 才写请求链；`route`/API 进接口判定或技术附记。

### SC-… {标题}

- **问题标题**：`{页面/模块}：{动作，偏差，后果}`（≤56 字正文）
- **分类 / 两档**：`实现缺陷|产品缺陷|…`；严重程度 `1-致命…4-轻微`；优先级 `1-紧急…4-低`
- **一句话影响** / **最小复现**：（S1/S2 必填；S3/S4 强烈建议）

- **测试数据/业务主键**：`构造：…`（等价构造条件）；`列名=全码`（页面可见全码；evidence 同步）
- **问题** + **业务后果**：
- **复现**：前置；`1…n`（按 surface 写导航/区域/控件 + 数据值，或方法+path+参数值）；复现频率
- **实际**（≥2） / **预期**（≥2）：`ui` 写页面原文/状态/业务后果；`api` 写码/业务信号/字段=值
- **接口判定**：`{方法 path；参数；码/消息；回查字段=值}` 或 `本轮无相关接口`
- **设计对照**：`资料 + 章节/条款`；`原文：…`；`设计应然：…`；`现网/本轮：…`；`差别：…`；`方案理解核对：…`；`本条以…为准`（无文档写 `无设计文档·现网依据：…`）
