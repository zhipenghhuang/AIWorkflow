# 执行与探索（技能 · 随包生效）

> 用于：execute（功能/探索式/计划驱动跨轨）。**计划驱动时，测试计划 §9.2 是阶段编排真值、§3.9 是批次/并行/子代理真值；每阶段按对应轨契约执行。**  
> **执行前核对**：`测试分析表`（覆盖单元/验证点/§2.2/§2.3/oracle/TP）+ 用例追溯；预期来自需求/AC/契约/用户裁决，不按现网改预期；实现≠需求 → fail。无来源先问或标「文档未声明」。  
> **禁换载体**：用例点名动作 UI→同源 Network；难测不改打其它接口。**仅 API 绿 ≠ 点名 UI 条通过**；入口交付缺口禁标观察。弱证据/错题不拟提交。本批未齐禁收尾。  
> **装填优先**：§0/§3.7 展示 suite+命中域；冒烟后只跑装填域。「继续」=续装填，不隐式 generate。  
> **列车门**：P0-Smoke 未绿不进本轮全库；CI 宜 PR 冒烟 / 合入·定时回归 / 发版全量分事件（样例 `extras/github-actions-test-gates.example.yml`；纪律 `release-train-load.md`）。  
> **高效**：能脚本不 AI；数据一次造齐；先侦察后动作；MCP 留给首查/口径/失败复核，回归走脚本档 0 token。

## 0. 现场处置（自主分析 · 对齐市面 healer 分诊）

> 目标：少打断用户、不空转、不刷绿。可自主范围内先分析再行动；不可让项必须停问或按红线定性。

| 现场情况 | AI 自主做什么 | 禁止 |
| --- | --- | --- |
| 缺数据/样本 | 造数/换样（基线配方）；再跑本条 | 直接 blocked |
| 入口 404/空壳（有菜单） | 记 fail+证据；可绕过则跑独立面 | 猜替代 API 换载体；把该条标 pass |
| 无菜单无接口（范围内） | 待实现（实现缺陷）进批次 | 当 blocked；标观察/仅 GAP；用 API 旁路把点名 UI 条刷绿 |
| 点名 UI 仅 API/E0 | 未走 E1 → 不得 pass；旁路另记 | E0/纯 API 冒充 UI 终态 |
| 浏览器不可用（点名 UI） | 拉起失败→blocked | E0 凑 pass |
| 弱通过 / 空扫 / 空成功 / 授权未生效 | 按工作流 §3.0-6 定性 fail 或造数后再判 | 观察后宣称达标；无样本标 pass |
| 同路径旁证问题 | 记 fail/额外发现+证据；不换载体 | 因「非本条断言」静默忽略 |
| 断言面不可达 | blocked+已试路径 | 写成实现缺校验 fail |
| 登录/网关挂 | 互异手段≥2 总≤3；穷尽→blocked 停轮 | 空重试同手段 |
| 冒烟失败 | 按 §1.1.1 分流：环境停轮 / 产品拦断面 / 脚本修脚本 | 冒烟红仍扫全库 |
| 脚本 fail | **有界复核 1 次**：分诊=产品缺陷→fail｜脚本漂移→修脚本重跑｜环境→环境处置 | 脚本红直接交平台；反复深挖凑复现 |
| UI 失败 | 快照+Network+console 分诊；钉断言面；同帧视觉检 | 未复现就改预期 |
| 选择器/文案微调（用例笔误） | 同轮小修用例+同步脚本；摘要注「用例待修」 | 为过用例改业务预期 |
| Flake/偶发 | 同方案无效 2 次换手段；记频率；不一次绿即稳 | 静默跳过 |
| 上游阻断下游 | 能换样/绕过→照跑；不能→下游 blocked 点名上游 | 重复记 fail |
| MCP/浏览器断 | 按基线拉起/重试；仍挂→点名 UI 停并 blocked，禁 E0 代过 | 无差别新开对话空转 |
| 口径待探查 | 先读本载体实现值再断言 | 换功能点「好测的」 |

**自主分析三步（每条异常默认走）**：① 取证 → ② 归因（产品｜脚本/用例｜数据｜环境｜flake）→ ③ 处置后继续装填。产品缺陷不自愈成通过。  
**落账前四问（硬）**：① 断言面本轮重看过（页面/字段/状态/接口）？② 证据可打开且钉断言点？③ 状态语义对（通过/失败/阻塞/待实现/不适用）？④ 写操作本轮 Network 见 METHOD+path 且回查过？四问未过不落账；通过不得只凭“没报错”。  
**路径旁证**：本条步骤中已暴露的其它产品问题同步落台账/额外发现（工作流 §3.0-7），再续跑；不另开无关模块深挖。

## 1. 计划驱动执行（跨轨）

- **按阶段 + 批次推进**：P0 准备 → P1 冒烟 → P2 功能 → P3 接口 → P4 探索式 → P5 非功能 → P6 回归 → P7 UAT → P8 发布前/灰度 → P9 报告；每阶段按计划 §3.9 批次循环派工/合并至本阶段装填全终态或停轮，不跳阶段、不跳批次、不只跑第一批。
- **阶段取轨**：功能/探索式按计划 §3.9 批次 + 多Agent §1.5 决策树取档并声明 `mode=`；接口单 Agent；发布前按轨契约；不跨轨通读。
- **并行**：一次一个 PG（PG 内 ≤3，§1.5.3）；共享 profile/账号/写域串行；同条用例禁并行；未列批次默认串行并记 `deviation=no_batch_plan`；超时降级直做（§1.5.4）。
- **状态**：更新 `{workroot}/test-plan.md` §0（阶段/门/下一动作）与 §16.1 执行日志；正式对照落报告 §2。
- **批末合并 + 门**：先按 §3.9 合并核验（文件/逐条/计数/结果/证据），再 `Invoke-Gate.ps1 -Mode execute -Scope {装填域}`；准出另跑 `-Mode report`。禁无 Scope 全仓 FAIL 充当本批结论；合并未过不开下一批。
- **停止**：P0-Smoke 未过/环境不可用/数据合规/计划实质偏差 → 按计划 §6 暂停或回计划门。

## 2. 执行经济（省时优先）

- **数据先行**：开跑前集中备齐本批前置（缺 → 一次造齐，优先 API/脚本）→ 再进冒烟；别边跑边造。
- **先侦察后动作**：导航 → 等载入 → 快照/截图定位 → 再连续动作；同页多用例=一次侦察多次操作，DOM 变更后再刷新快照；批次结果一次汇总。
- **截图即视觉检**：MCP/直跑凡拍目标页截图 → 按 `workflow.md` §2.1.0 视觉六项同帧检（布局/遮挡/截断/空态加载错误提示/按钮态/文案减法）；阻断→fail；非阻断→额外发现；已截必检，不另开纯视觉轮。
- 冒烟先过再装填域（`多Agent` §1.1.1）；已脚本化走脚本档。
- **工具黑盒调用**：执行器/工具大件不读源码进上下文（先 `--help`/README）；**MCP 全量快照单次数千 token 且逐轮累积**——重复/回归路径沉淀脚本（0 token），MCP 留给首查、口径探查与失败复核。

## 3. 回归闭环（过程中并行）

- **修复即回归**：每个缺陷修复后立即跑 原单 + 冒烟子集 + 影响面组；不等批末。
- **影响面组**：开发回写或测试自建（3～8 条）；**默认纳入**原单+冒烟回归；砍减须留痕；无提测单不免除。
- **升级**：高风险（跨模块/契约/数据/权限/资金/并发）或同模块短窗口 ≥2 单 → 提示模块局部全量/扩大邻接回归。
- **记录**：结果就地覆盖台账与证据，只留最新；报告 §5.2 汇总回归轮次/通过率/遗留。
- 已脚本化优先脚本档；脚本失败按 `rules/special/script-execution.md` §3 有界复核后再定性。

## 4. 探索式测试（SBTM）

- **章程**：Explore [目标] with [资源/约束] to discover [风险]；范围/时间盒/数据/oracle 写清（计划 §12）。
- **用例形态**：对照 `exploratory-case-template.md`——前置三件套、步骤四列（位置/操作/数据或变体/中间观察）、同号判定面、章程目标映射；禁空话步骤。
- **路线轮换**：数据漫游｜操作漫游｜状态漫游｜干扰漫游｜业务漫游。
- **启发式**：FEW HICCUPPS；SFDIPOT。oracle 优先用 **Claims / History / Product**；**禁**「现网一致」当 Claims。选题对照 `defect-findings-spectrum.md` §2（假成功/门禁/并发/入口/发布门禁/持久化等）。
- **成败**：可复现发现 + 缺口 + 新风险；步骤跑完率不是成功标准。
- **记录**：session 笔记（发现/覆盖/疑问/耗时）；发现即记。
- **Debrief**：章程完成/覆盖/缺口/新风险；分流——缺陷→缺陷+回归；缺口→补用例/补章程；误报→记录；**交付缺口不得只进观察**；禁空泛「探索通过」。
- 探索式不脚本化；**勿与随机业务流程混用** → §4.1。

## 4.1 随机业务流程（计划外）

- **定位**：**模仿真实用户操作与体验**，把一类主业务办完；≠ 探索式章程挖洞；≠ 冒烟清单机械跑完。读 `tracks/random-flows.md`；沿途探针见谱系 §3。
- **入口**：仅独立口令「生成/执行随机业务流程｜业务随机」；**不进**测试计划、不被「按计划执行」调度、不参与准出；**不规定主读**（禁选/问主读）；不要求计划/分析表；跳过理解门。
- **选路**：默认全产品**主业务办结链** + 主题（可选，只收窄「办哪类活」）+ **最近 N 轮去重窗**换轴；候选可参考基线菜单地图/冒烟清单作办结候选 + 现网探查；不读计划/分析表差量作补洞或选池边界。
- **口径**：固定 **`口径=现网`**（本构建最新）；方案/旧迭代最多有界背景，不参与判定；文档≠现网不按旧方案开实现缺陷。
- **执行手感**：真实 UI 入口 → 按界面习惯办到办结或明确失败面；变体/异常恢复；禁菜单扫街、禁 API 旁路冒充办结。
- **形态**：对照 `random-flow-case-template.md`——旅程纪要、办结目标、判定面、窗对照、发现分流（含体验/流程优化）、账本写回。
- **产物**：`{workroot}/random-flows/` 同戳纪要/台账 + `{workroot}/random-flows/_覆盖账本.md`；ID=`RND-NN`；不脚本化；缺陷类型=`随机`。
- **收尾**：办结对照/窗对照/新增轴/分流（缺陷｜体验优化｜建议补用例｜文档漂移）；禁空泛「随机通过」；修后回归走计划内或点名复测。

## 5. 现场观察手感

- 看细节与视觉六项 +「疑似不合理有见则记」以工作流 §2.1.0 为准（本节省重复）；边界输入即时试（超长/emoji/空格/大小写/全角）。
- **用例之外发现**：视觉/UX/布局别扭/console/network 等——位置/现象/证据/影响；能复现进defects/观察项，不能复现记频率；不静默忽略，不替代用例结果；不追风格偏好。**范围内入口/能力未交付不得进观察项**（→待实现/fail）。
- 失败当场留证（截图钉断言面并同帧视觉检）、最小复现、环境快照（URL/账号角色/时间）；归因先复现后定性。

## 6. 数据卫生

- 造数遵循基线 §10/§11；用后清理或标注；写操作前查冲突登记（§15）。
- 回归数据用 `REG-`/runStamp 幂等；跨轮复用先核对状态。

## 7. 非确定性 / AI 功能执行

- 同一用例重复 N 次（关键 3～5 次）；记录每次输出/判定/耗时，按阈值判通过，不拿一次结果代表稳定。
- 先固定模型/提示词/检索/工具版本；变更一项就重跑同批，不混版本比较。
- 失败分诊：模型随机性｜提示词/上下文｜检索｜工具/依赖｜数据｜环境｜真实缺陷；不确定先归类“待定”，不直接标产品缺陷。
- 证据：模型/提示词/数据集版本、输入、输出、评分/引用、人工评审；敏感内容脱敏。
- 红队/注入按 `skills/ai-feature-testing/SKILL.md` 执行；不在生产直接做未批准攻击。

## 8. 证据完整性

- 失败/阻塞/待实现必须有证据或已尝试/恢复条件；路径不存在 = FAIL/BLOCKED。
- 截图晚于任务开始，钉住断言面；同帧做视觉六项检；不拿旧截图/他人截图充数。
- 结果就地覆盖台账，只留最新；报告数字与台账逐项一致。
- 不手改结果表、不跳测试、不禁告警凑绿；豁免须用户批准并记录。

## 8.1 Playwright / 脚本稳定性（执行侧速查）

> 细则与资产落点见 `rules/special/script-execution.md` §6；此处只列执行时不可让的稳定纪律（吸收 playwright-best-practices / e2e patterns）。

- **等待**：优先 `expect(...).toBeVisible/toHaveText` 等自动等待；禁固定 `sleep` 当同步。
- **定位**：角色/标签/测试 id 优先；脆弱 CSS/xpath 仅临时，回归前硬化。
- **隔离**：每用例自备数据/账号或可重置夹具；禁依赖执行顺序与共享脏状态。
- **Flake 分诊**：超时/竞态/动画/网络 → 先稳选择器与等待，再考虑重试；**禁**靠无限重试刷绿。
- **失败现场**：留 trace/截图/Network；脚本失败按脚本执行 §3 有界复核 1 次再定性。

## 9. 常见合理化与反驳

| 合理化 | 现实 |
| --- | --- |
| “重跑一次过了就算过” | 非确定性/flake 要看多次与分诊；一次通过可能是偶然。 |
| “这个失败不重要，先跳过” | 跳过要记录缺口/风险接受；不能静默。 |
| “截图差不多就行” | 证据要能定位断言面与时间；旧图/糊图不算。 |
| “AI 输出没法判定” | 用rules/引用/rubric/人工+频率；不是不判。 |
| “先交平台，后面再补证据” | 弱证据/错题不交平台；回写要有回执。 |
| “加长 sleep 就能稳” | sleep 掩盖竞态；用条件等待与隔离。 |

## 10. 执行 DoD

- 用例/计划/环境/数据版本可追溯；前置满足或已记录替代。
- 结果/证据/失败分类/重试有界；未测/阻塞显式列缺口。
- 台账与报告数字一致；P0-Smoke/P0-HighRisk 未过不得判整体通过。
- 清理完成或已隔离；证据路径可打开。
