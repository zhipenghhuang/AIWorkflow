# 指标、埋点与实验（技能 · 随包生效）

> 用于：PRD 的指标/埋点节、发布度量、功能验证、增长实验、复盘归因。  
> 定位：**先有决策问题，再有指标；先有口径，再有数据**。指标不是“上线后看看”，而是验收的一部分。  
> 边界：数据平台/SQL/BI 属开发/数据侧；本技能定义产品口径与验收方法。  
> 不适用：无用户/无数据决策的内部工具；写「不适用 + 原因」，不硬造指标。

## 1. 从决策问题到指标

- 先写：**要做什么决策？**（继续/停止/加投/改方案/放量）——没有决策的指标不采集。
- 指标树：北极星（用户价值）→ 输入指标（可影响）→ 护栏指标（不能被伤害）→ 诊断指标（排障）。
- 一个指标一个定义：名称、口径、公式、分子/分母、时间窗、过滤条件、数据源、owner。
- 分群：新/老、角色、租户、渠道、版本；避免整体平均掩盖局部恶化。
- 反虚荣：注册数/页面浏览量/总时长单独看不算成功；要连到激活、留存、转化、任务完成。

## 2. 事件字典（埋点单一出处）

| 字段 | 要求 |
| --- | --- |
| 事件名 | `{对象}_{动作}`，过去式/稳定语义；禁止 `click1`、`test` |
| 触发时机 | 成功/失败/提交前/响应后，写清唯一时点 |
| 属性 | 名称、类型、必填、枚举、示例、隐私级别 |
| 身份 | 匿名/登录/租户；id 变更与合并规则 |
| 来源 | 客户端/服务端；以哪端为真 |
| 版本 | 事件 schema 版本；废弃/重命名迁移 |
| owner | 产品/数据/开发责任人 |

- 客户端事件易丢/易重复；关键业务以服务端为准，客户端只补交互。
- 命名、属性、枚举一次定清；上线后改名=破坏历史数据，必须走版本/双写/迁移。
- 埋点与功能同批交付；无埋点写「不适用 + 原因」，不事后补。

## 3. 漏斗、留存、 cohort

- 漏斗：步骤、时间窗、是否允许回退/重复、分母是谁；每步流失要能解释。
- 留存：次日/7 日/30 日口径；新用户定义、激活定义、时区；避免幸存者偏差。
- cohort：按首次使用/版本/渠道分组；对比同口径，不拿不同窗口硬比。
- 归因：区分相关与因果；多渠道/自然流量/内部流量要标注。
- 数据质量：空值/重复/时区/机器人/测试账号；上线前做事件校验与对数。

## 4. A/B 与灰度实验

- 假设：`因为…，如果…，则…指标会…`；先写主指标、护栏指标、最小可检测效应。
- 单元：用户/租户/会话；避免同一用户跨组；随机化与分流比例可复现。
- 样本与时长：按基线/方差/效应算样本量；不要“跑两天看看”；避免提前偷看（peeking）。
- 护栏：错误率、延迟、投诉、退款、取消率；护栏恶化立即停。
- 分析：意向治疗（ITT）、SRM 检查、置信区间、多重比较校正；统计显著 ≠ 业务显著。
- 决策规则：上线/回滚/继续/扩大样本，实验前写清；事后不改假设。
- 不能做随机实验时：准实验/前后对比/匹配，明确混杂因素与局限，不冒充因果。

## 5. 隐私与合规

- 最小化：只采决策必需字段；不采敏感个人信息；自由文本慎采。
- 同意/告知：按地区与业务要求；拒绝追踪时仍保证核心功能。
- 保留/删除：期限、聚合、导出/删除路径；跨境与供应商条款。
- 权限：看板/原始数据按角色脱敏；小样本防重识别。
- 参考：PIPL/GDPR（按适用）、公司数据分级；不把“匿名化”当口号，验证可重识别风险。

## 6. 发布与验收

- 发布前：事件字典、埋点实现、数据校验、看板/告警、基线值、决策规则齐。
- 发布后：按窗口核对数据量/漏斗/留存/护栏；异常先查埋点与口径，再下结论。
- 验收：指标能回答预设决策问题；口径可复算；数据延迟/缺口已说明。
- 复盘：目标 vs 实际、分群差异、意外影响、下一步实验；不只看单点涨跌。

## 7. 常见合理化与反驳

| 合理化 | 现实 |
| --- | --- |
| “先上线，数据以后补” | 没有基线/埋点，发布后无法判断成败；补埋点也是变更。 |
| “页面浏览量涨了就是好” | 可能是误点/机器人/重复；要连到任务完成与留存。 |
| “实验显著就全量” | 看效应大小、护栏、分群、时长；显著可能是噪声或 SRM。 |
| “口径差不多就行” | 口径不同结论相反；必须可复算、可追溯。 |
| “用户 id 记一下方便分析” | 高基数/隐私风险；用聚合/脱敏/最小化。 |

## 8. 红旗

- 指标没有公式/分母/窗口/owner。
- 事件名/属性随手上线后改，历史数据断档。
- 只看总数不看分群，局部恶化被平均掩盖。
- 实验中途改假设/看多次就停/无护栏。
- 埋点采集身份证/手机号/自由文本等敏感数据。
- 发布后无人看数据，或看板长期无人维护。

## 9. 输出与 DoD

- PRD/方案：决策问题、指标树、事件字典、埋点位置、看板、实验设计、护栏、隐私、验收。
- 发布：基线、数据校验、观察窗口、决策规则、复盘。
- DoD：每个指标可复算；埋点与功能同批；实验有假设/样本/护栏/决策规则；隐私合规；能用数据回答“继续/停止/加投”。
