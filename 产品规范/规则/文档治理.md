# 文档治理（资料 + 工作文档）

> 单一出处：外部资料的收取/分类/对照/归档，以及工作文档的生命周期/归档/清理。
> 铁律：**先扫描分类 → 输出候选 → 用户确认 → 才改名/移动/标记失效/归档/清理**；未确认前只读。
> 安全：证据、当前 PRD/原型/计划、源文件、用户文件、密钥、`.git` 永不自动删除；拿不准 → 待确认或移 `_归档/_待清理/`。

## 1. 两个区，三种模式

| 区 | 放什么 | 不放什么 |
| --- | --- | --- |
| `产品/资料/` | 外部输入、只读证据（扁平，按类型前缀命名） | 本包 PRD/原型/评审/计划/UAT 等工作文档 |
| `产品/{版本或主题}/` | 本包工作文档，按阶段分组：`01-需求与定义/`、`02-原型与设计/`、`03-变更与缺陷/`、`04-交付与验收/`、`05-展示与材料/`、`06-复盘/` | 外部原件（放 `资料/`）；无内容不建空目录 |

- **单包资料根**：`产品/资料/`；**多包**：共享根 `项目资料/`，本包 `资料/` 只放专属/历史资料。
- **资料模式**：`keep` 原位只读；`mix` 原位只读 + 新文件引用/摘要（默认）；`replace` 可改名/移动，列清单确认后执行。
- **单一主副本**：一份文件只保留一个主副本；跨包只引用，不复制多份。

```text
产品/资料/
├─ 资料索引.md
├─ PRD-{主题}-{版本或yyyyMMdd}.md
├─ 需求-{主题}-{yyyyMMdd}.md
├─ 迭代-{主题}-{版本或yyyyMMdd}.md
├─ 专项-{主题}-{版本或yyyyMMdd}.md
├─ 原型-{主题}-{版本或yyyyMMdd}.html
├─ 设计-{主题}-{yyyyMMdd}.md
├─ 接口-{主题}-{版本或yyyyMMdd}.yaml
├─ 技术-{主题}-{yyyyMMdd}.md
├─ 测试-{主题}-{版本或yyyyMMdd}.md
├─ 验收-{主题}-{版本或yyyyMMdd}.md
├─ 反馈-{主题}-{yyyyMMdd}.md
├─ 调研-{主题}-{yyyyMMdd}.md
├─ 竞品-{主题}-{yyyyMMdd}.md
├─ 会议-{主题}-{yyyyMMdd}.md
├─ 数据-{主题}-{yyyyMMdd}.{ext}
```

- 不再建 `项目文档/`、`原始素材/`、`_收件箱/`、`反馈/调研/竞品/数据/` 子目录；外部资料直接平铺。
- 本包 PRD/原型是工作文档，不是外部资料；只有外部/合作方 PRD 才进 `资料/PRD-*`。
- 无法判断 → 保持原名，状态=`待确认`，问一次；不先移动。

## 3. 资料收取（每次新文件/用户给文档）

1. **识别**：扫描本包资料根 + 既有资料目录（keep/mix）+ 项目根（replace/用户投放）的未登记/变化文件、索引断链、内容哈希变化。
2. **读取**：先读标题/目录/开头与显式变更段，需要时再读关键段，不整篇读；提取标题、版本/日期、范围、显式「替代/废止/全量更新」。
3. **分类**：按 §2 定主类型；不确定 → `待确认`。
4. **对照**：找同类型 + 同主题旧文件，比较覆盖范围；不要只看版本号。
5. **输出【资料收取与归档候选】**：分类、归属、采纳建议（引用/摘要/复制/迁移）、对照关系、建议归档/保留/待确认；**此时不改索引、不改名、不移动、不标记失效**。
6. **确认后**：改名/登记 → 旧文件标 `失效`（仅在确认归档时）→ 移 `_归档/{yyyyMMdd}-{版本或批次}/资料/` → 写 `归档清单` → 更新索引/计划/activeContext。

**覆盖关系**（七类）：

| 关系 | 判定 | 动作 |
| --- | --- | --- |
| 全量替代 | 新文件覆盖旧文件全部范围 | 旧版可归档 |
| 全量覆盖 | 同范围但新版完整重写 | 旧版可归档 |
| 部分覆盖 | 只覆盖部分模块/章节 | 保留旧版，更新索引 |
| 增量补充 | 新增内容，不改旧内容 | 保留旧版 |
| 仅新增 | 同主题新文件，不替代 | 保留，新增登记 |
| 重复 | 内容相同/近似 | 可归档重复项 |
| 冲突 | 口径矛盾 | 停下问一次，不归档 |

**失效依据**（仅用于已确认归档）：S1 全量替代；S2 全量覆盖；S3 重复；S4 需求删除/版本取消；S5 用户明确失效。禁止按时间年龄归档。

## 4. 工作文档四类

| 类型 | 判定 | 动作 |
| --- | --- | --- |
| 长期/固定 | 跨版本稳定的真值/规范/主档 | **就地更新**，不随迭代归档 |
| 版本/迭代绑定 | 只服务某版本/主题 | 关闭时快照/归档；当前版本保留 |
| 失效/替代 | 被新版本全量替代、需求删除、版本关闭 | 旧版归档；部分覆盖保留旧版 |
| 过程/临时 | `.draft/`、草稿、缓存、失败产物、重复文件 | 列清理候选；确认后删除或移 `_待清理/` |

本包清单：

| 文档/目录 | 类型 | 处理 |
| --- | --- | --- |
| `产品档案.md`、`activeContext.md` | 长期 | 就地更新；过期删除 |
| 根 `CHANGELOG.md` | 长期 | 版本/迭代关闭、发布更新；不随版本归档 |
| `产品/产品计划.md` | 长期主档 | 常青；季度结束复制快照到 `_归档/{yyyy-Qn}/`，主档不移动 |
| `产品/需求池.md` | 长期 | 滚动单点；只留现行状态 |
| `产品/用户文档/` | 长期/当前版本 | 当前对外版本保留；旧版按版本归档 |
| `产品/{版本或主题}/` | 版本绑定 | 版本关闭整体归档；当前版本保留 |
| `产品/交接/{HO-ID}/` | 版本绑定/快照 | 生成后不可改；新版本建 `-v2`；关闭/版本结束时随版本归档；`交接台账.md` 常青就地更新 |
| `产品/资料/交接/{HO-ID}/` | 外部输入/只读 | 接收包只读；不修改；随资料归档规则处理 |
| `产品/{版本或主题}/02-原型与设计/` | 版本绑定 | 新原型只替代同页面旧原型；其他保留 |
| `产品/_归档/{yyyy-Qn}/` | 历史 | 只增不改；主档保留索引 |
| `产品/**/.draft/`、失败导出、未引用截图、重复文件 | 过程/临时 | 清理候选；确认后删除或移 `_待清理/` |
| `*.tmp/*.temp/*.bak/*.log/~$*/.DS_Store/Thumbs.db` | 临时/缓存 | 清理候选（确认后删） |

## 5. 更新还是归档

| 情况 | 动作 |
| --- | --- |
| 长期真值/主档变化 | 就地更新；变更前后写变更记录/决策记录，不归档主档 |
| 当前版本文档局部变化 | 就地更新受影响章节；旧结论进变更记录 |
| 新版本 PRD 全量替代旧 PRD | 新版=现行；旧版=失效，确认后归档 |
| 新版本 PRD 只改一个模块 | 旧 PRD 保留并更新未覆盖部分；不归档 |
| 新原型只替代同页面旧原型 | 旧页面原型归档候选；其他页面保留 |
| 版本/迭代关闭，文档只服务该期 | 整个 `产品/{版本或主题}/` 归档；主档/需求池不动 |
| 需求删除/版本取消 | 相关文档标失效；确认后归档 |
| 过期但仍有参考价值 | 保留为参考，不归档 |
| 重复/空文件/无引用 | 清理候选；确认后删除或移 `_待清理/` |

判定原则：版本号新 ≠ 全量替代；以覆盖范围为准；正式文档只写现行有效；发布说明一版一档。

## 6. 版本/迭代关闭

1. 更新 `产品/产品计划.md` §0/§7/§10/§11、需求池、activeContext、根 `CHANGELOG.md`。
2. 季度结束：复制当期执行到 `_归档/{yyyy-Qn}/产品计划-{yyyy-Qn}.md`；主档不移动。
3. 版本/结项：`产品/{版本或主题}/` 整体移入 `_归档/{yyyyMMdd}-{版本}/`；`产品/交接/{HO-ID}/` 已关闭的包同批归档（台账保留）；只归档已确认项；用户文档/主档/长期真值保留。
4. 按 §5 扫描版本绑定文档：全量替代/关闭版本/需求取消 → 归档候选；部分覆盖 → 保留并更新。
5. 写 `归档清单`（原路径/归档路径/类型/依据/替代/校验/日期）。
6. 清理过程/临时文件：按 §7 出候选，确认后执行。
7. 更新资料索引/产品计划/activeContext 及相关链接；跑引用检查。

## 7. 过程/临时文件清理

- 扫描 `产品/` 与项目根顶层；跳过 `.git/`、代码依赖/构建产物/模板目录。
- 候选：`.draft/`（未被计划/报告/评审引用）、`*.tmp/*.temp/*.bak/*.log`、`~$*/ .DS_Store / Thumbs.db / desktop.ini`、`* (1).*/*副本*/0 字节未引用`、未引用导出/下载/截图/临时 JSON。
- 永不自动删除：正式产物、当前版本资料、对外用户文档、证据、源文件、模板、`.git`、`.env`/密钥、拿不准的文件。
- 执行：列【清理候选】（路径/类型/原因/大小/引用/动作）；确认后已知临时文件可删，不确定移 `_归档/_待清理/{yyyyMMdd}/`；写清理清单；更新 activeContext。
- 禁止业务任务中途顺手删除；只在关闭/巡检/点名「清理」时执行。

## 9. 触发

| 时点 | 动作 |
| --- | --- |
| 接入/重新接入 | 扫描资料/工作文档；建索引；旧结构列迁移/归档/清理候选 |
| 新版本/新迭代替换旧文档 | 按 §5 判定更新/归档；不全量替代不归档 |
| 版本/迭代关闭 | 按 §6 快照/归档/清理 |
| 用户点名「资料整理/文档整理/巡检/清理」 | 扫描 → 候选 → 确认 → 执行 |
| 季度/月度（可选） | 只扫描出候选，不移动 |
