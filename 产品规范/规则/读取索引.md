# 读取索引（产品轨）

> **单一读取入口**：开工先读 `AGENTS.md` **§0 硬节**与本索引当前 step 行；只读“必读”，按需再读“可选”。**不要通读整本规则/技能/模板**。
> **读取预算（目标，非硬上限）**：核心必读 ≤3～4（`AGENTS.md` 当前相关节 + 当前 step YAML 块 + 当前 agent/当前关键产物）；方法层按本表「命中才读」；总量 ≤8k；复杂步可至 5 并在收尾 reads= 说明；大文件只读当前 step 对应节，**workflow 只读当前 step 块（当前 `- name:` 到下一个）**；不得为省预算跳过门/证据/红线。
> **读序**：① `AGENTS.md` §0（硬节）→ ② workflow 当前 step 块 → ③ 本索引当前行 → ④ 当前 agent → ⑤ 当前技能/playbook 当前节 → ⑥ 当前产物/证据；到此为止，不扩散。**口令表仅路由未定/首次命中时读**，已路由不每步重读。
> 同一会话文件未变不重读；后续步骤 delta-only。
> **执行契约**：开工判定 execute/analyze/stop 与收尾【遵守自检】读 `规则/核心/执行契约.md` §1～§2/§6；不占每步常规预算。

## 默认行（所有 step）

- **核心必读**：`AGENTS.md` §0 + 命中 `workflows/{workflow}.yaml` 当前 step 块 + 当前 `agents/{role}.yaml` + 当前产物/证据。
- **跨会话快照**：开工/续跑先读项目根 `activeContext.md` 本包 `### 进行中`；无则按模板补建。
- **命中才读**：本索引对应行「可选」列；方法层技能/playbook/模板按 step 命中再读。
- 不读：其它 workflow、全部 agents、全部模板、全本规则。

> 模板引用若用短名（如“产品计划模板”“UAT验收模板”），先按 `规则/模板/模板索引.md` 定位到组；不要猜路径。  
> **技能绑定**：优先认 workflow 当前 step `notes` 首行 `skills_required` / `skills_optional`；与 `技能/README.md` 映射一致时以 YAML 为准。

## 读取纪律

- 先读标题/目录/当前节；不要从第一行读到最后一行。
- 同一文件只读一次；后续步骤用 delta-only。
- 需要跨文件综合时，先列“要回答的问题”，再定向 grep/读节；不要用“通读”代替定位。
- 子代理只读派发路径与节选，不读整本规则/档案/历史。
- 任何澄清/追问 → `规则/核心/澄清.md`；客户需求发现 → `技能/customer-needs-discovery/SKILL.md`；不另造提问格式。
