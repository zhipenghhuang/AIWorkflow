# 读取索引（产品轨）

> **单一读取入口**：开工先读 `AGENTS.md` §0～§3 与本索引当前 step 行；只读“必读”，按需再读“可选”。**不要通读整本规则/技能/模板**。
> **硬上限**：单步读取 ≤8k tokens；大文件只读当前 step 对应节，禁止通读全本；超出先拆读（先读 workflow step + 当前 agent + 技能/playbook 当前节 + 当前产物）。
> **读序**：① `AGENTS.md` §0～§3 → ② workflow 当前 step → ③ 本索引当前行 → ④ 当前 agent → ⑤ 当前技能/playbook 当前节 → ⑥ 当前产物/证据；到此为止，不扩散。
> 同一会话文件未变不重读；后续步骤 delta-only。

## 默认行（所有 step）

- 必读：`AGENTS.md` §0～§2 + 命中 `workflows/{workflow}.yaml` 当前 step + 当前 `agents/{role}.yaml` + 当前产物/证据。
- 可选：本索引对应行。
- 不读：其它 workflow、全部 agents、全部模板、全本规则。

> 模板引用若用短名（如“产品计划模板”“测试报告模板”），先按 `规则/模板/模板索引.md` 定位到组；不要猜路径。

## 读取纪律

- 先读标题/目录/当前节；不要从第一行读到最后一行。
- 同一文件只读一次；后续步骤用 delta-only。
- 需要跨文件综合时，先列“要回答的问题”，再定向 grep/读节；不要用“通读”代替定位。
- 子代理只读派发路径与节选，不读整本规则/档案/历史。
- 任何澄清/追问 → `规则/核心/澄清.md`；客户需求发现 → `技能/customer-needs-discovery/SKILL.md`；不另造提问格式。
