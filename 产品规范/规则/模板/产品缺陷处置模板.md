# 产品缺陷处置单（产品 → 开发 / 测试）

> **用途**：产品对“测试直提的产品缺陷”或“开发提交的产品缺陷评估单”做出判定、处置与交付说明；作为平台附件指派开发或测试。  
> **三包独立**：本单落在产品包自身目录，不假设开发/测试包同目录；开发/测试从平台附件与备注读取，不引用本包内部路径。  
> **落点**：`产品/{版本或主题}/缺陷处置-{BUG-ID}-{主题}-{yyyyMMdd}.md`；模板索引见 `README.md`。  
> **纪律**：先定性，再处置；产品缺陷必须有 PRD/设计原文 + 现网证据 + 相符证明；未确认不改基线；未回写/未验证不关闭。
