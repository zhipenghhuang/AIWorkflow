# 访谈指南 — {主题 / 角色}

> **用途**：准备与用户/客户/业务方的发现访谈；问题遵循 Mom Test（问过去行为与代价，不推销方案）。  
> **纪律**：一次访谈聚焦 1 个问题域；记录原话；会后用 `洞察综合模板.md` 综合。  
> **落点**：`产品/{版本或主题}/01-需求与定义/访谈指南-{主题}-{yyyyMMdd}.md`。  
> **配套**：澄清协议 `规则/核心/澄清.md`；技能 `customer-needs-discovery`。

## 2. 开场（约 2 分钟）

- 说明目的：了解真实工作方式与困难，**不是**推销产品。
- 征得记录/脱敏同意。
- 破冰：`{对方当前职责与一天里和本问题相关的部分}`

## 3. 对方世界（约 10 分钟）

> 每题可追问「上次具体是什么时候 / 然后呢 / 花了多少时间或钱」。

1. 和 `{问题域}` 相关的日常流程是怎样的？
2. 哪里最耗时 / 最容易出错 / 最让人烦？
3. 现在用什么办法解决？试过别的吗？结果如何？
4. 如果不处理，会怎样？（对谁、多大影响）

## 4. 具体过去行为（约 10 分钟）

1. 请讲**最近一次**遇到 `{问题}` 的经过（从触发到结束）。
2. 当时找了谁、用了什么工具、卡在哪？
3. 花了多少时间 / 钱 / 机会？最后结果是什么？
4. 这类事大概多久发生一次？

## 5. 承诺与推进（约 5 分钟）

> “听起来不错”不算承诺；记原话。

1. 若有试点/早期体验，你愿不愿占用时间试用？条件是什么？
2. 是否愿意介绍一位有同样问题的同事？
3. （可选）是否有预算/排期窗口可对上？

## 6. 禁止问法（出现即改写）

| 禁止 | 改写方向 |
| --- | --- |
| 你会不会用做 X 的产品？ | 上次遇到这事你怎么处理的？ |
| 你觉得这主意好不好？ | 你现在最想先解决哪一件？ |
| 你愿意付多少钱？ | 你现在为绕过这问题花了多少？（或试点意愿） |
| 会不会推荐给朋友？ | 你身边还有谁也被这件事折磨？ |
