# {主题} 原型说明

> **用途**：页面原型的单一说明（项目情境 / IA / 线框 / 视觉 / 状态 / 交互 / 工程化 / 交接）。  
> **落点**：`产品/{版本或主题}/02-原型与设计/原型说明-{主题}.md`；高保真同目录 `prototype/index.html`。  
> **用法**：标准多页面项目按 `prototype.yaml` 各步落独立文件（设计情境/IA/线框/评审/工程化/可用性/交接）；小项目可用本文件合并替代，避免重复文件。  
> **纪律**：先项目情境后画；每页有状态；原型≠生产代码；未过评审不交开发。
