# 产品工作日志

> **落点**：`产品/工作日志.md`（产品包维护）。  
> **用途**：岗位**里程碑侧记**，人类可扫、可复查；最新在前。  
> **不是**：项目根 `CHANGELOG.md`（给人看的项目发版史，仅开发维护）、客户「发布说明」、产品计划 §10 执行日志（细粒度过程追加）。  
> **禁止**：创建或修改项目根 `CHANGELOG.md`；把琐碎过程、台账全文、密钥/PII 写入本文件。  
> **只记里程碑级事件**（见下方事件类型）；日常琐碎进计划执行日志。  
> **年归档**：过长（约 >200 行）或跨年 → 列候选并**用户确认**后移入 `产品/_归档/工作日志/工作日志-{year}.md`，本文件留索引；**不随业务版本整文件搬迁**。

## 事件类型（选型）

| 类型 | 何时写一条 |
| --- | --- |
| 计划确认 | 产品计划门通过 / 范围基线确认 |
| 范围变更 | C1+ 变更落地或重基线 |
| PRD 定稿 | PRD APPROVED / 轻量定稿 |
| 设计交接 | 原型/设计包发出或对方签收 |
| UAT 结论 | UAT 通过/有条件/不通过 |
| 发布决策 | 可发布/暂缓/回滚决策 |
| 复盘 | 版本/事故复盘结论 |
