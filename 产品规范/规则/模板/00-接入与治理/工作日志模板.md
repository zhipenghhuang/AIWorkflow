# 产品工作日志

> **落点**：`产品/工作日志.md`（产品包维护）。  
> **用途**：本岗**里程碑侧记**；最新在前。  
> **不是**：根 `CHANGELOG.md`（项目发版史，仅开发维护；本包禁写/禁建）、客户「发布说明」、产品计划 §10 执行日志。  
> **禁止**：创建/修改/补链根 `CHANGELOG.md`；台账全文、密钥/PII。  
> **只记里程碑**（见事件类型）；琐碎进计划执行日志。  
> **年归档**：过长或跨年 → 用户确认后移 `产品/_归档/工作日志/`；不随业务版本整文件搬迁。

## 事件类型（选型）

| 类型 | 何时写一条 |
| --- | --- |
| 接入/治理 | 规范接入、档案/文档树落定 |
| 计划确认 | 产品计划门通过 / 范围基线确认 |
| 范围变更 | C1+ 变更落地或重基线 |
| PRD 定稿 | PRD APPROVED / 轻量定稿 |
| 设计交接 | 原型/设计包发出或对方签收 |
| UAT 结论 | UAT 通过/有条件/不通过 |
| 发布决策 | 可发布/暂缓/回滚；**只写本文件**。结论宜含本版对外变化摘要（产品语言 1～5 条）或链到发布说明，供开发写根 CHANGELOG；本包不写根 |
| 复盘 | 版本/事故复盘结论 |
