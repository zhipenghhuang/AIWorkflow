# 项目根 AGENTS.md（包挂载样例）

> 把下面代码块中的语句补入项目根 `AGENTS.md`（已有内容保留，**追加**即可）。  
> **分层（通用）**：本包 = 通用产品规则；`产品档案.md` = 项目事实；根 `AGENTS.md` 除本挂载外，若有对 AI 的额外要求由**落地项目自写**，母版不规定正文。  
> **单包装载**：用下方「单包」块。  
> **多包同项目**：根 `AGENTS.md` 只做路由——列「已启用包」，**不要**写「本会话只启用本包」；歧义口令先查根 README **意图→包**；一次只执行一个包。三包自动探测并共用原始资料根（推荐 `docs/`）/ `activeContext.md`。

## 单包样例

```markdown
## 产品规范（AI 工作流）

本项目启用 **产品规范** AI 工作流包。

1. 新会话：先读 `产品规范/AGENTS.md` **§0 硬节**（含 `activeContext` 总览/进行中 + 产品档案 §1 身份短读）→ 命中 §3 口令行（路由未定/首次）→ `workflows/*.yaml` **当前 step 块** → `规则/读取索引.md` 当前行；不要通读 §0～§3 全文或整本规则/技能/模板；日常不通读 README。
2. 已路由同会话中段：按 `产品规范/规则/核心/规则重锚.md` 做【规则心跳】，不重读 AGENTS §0 全文。
3. 本会话按产品规范执行（单包装载）。
4. 与本文冲突时以本文为准；细则以 `产品规范/AGENTS.md` 为准。
5. 产品产物统一 `产品/`；项目根只留 `产品档案.md`、`activeContext.md`；文档按 `产品规范/规则/工作流.md` §2 落位。
```

## 多包路由样例（根文件顶部或专节）

```markdown
## 已启用包（多包路由）

- 产品规范：按 `产品规范/AGENTS.md` 执行；口令见其 AGENTS。
- 开发规范：按 `开发规范/AGENTS.md` 执行；口令见其 AGENTS。
- 测试规范：按 `测试规范/AGENTS.md` 执行；口令见其 AGENTS。

歧义口令（缺陷/发布/下一步等）先查项目或母版 README **意图→包**；一次会话只跑一个包。Cursor 建议用各包 `规则/模板/00-接入与治理/cursor-rule样例.mdc` 按目录 globs 启用，避免三包规则同时 alwaysApply。
```
