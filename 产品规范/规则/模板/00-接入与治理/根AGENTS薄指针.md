# 项目根 AGENTS.md 引导样例（追加到既有文件）

> 把下面代码块中的语句补入项目根 `AGENTS.md`（已有内容保留，**追加**即可）。
> **多包同项目**：根 `AGENTS.md` 只做路由，不要逐包追加“本会话只启用本包”。已有多包时保留原文，在“已启用包”列表按实际包目录补齐（本包及同项目其它包各一行）：`- 产品规范：按 产品规范/AGENTS.md 执行；口令见其 AGENTS。` 三包会自动探测并共用原始资料根（推荐 `docs/`） / `activeContext.md`，无需额外协作目录或合同文件。

```markdown
## 产品规范（AI 工作流）

本项目启用 **产品规范** AI 工作流包。

1. 先读 `产品规范/AGENTS.md` **§0 硬节** → 命中 §3 口令行（路由未定/首次）→ `workflows/*.yaml` **当前 step 块** → `规则/读取索引.md` 当前行；不要通读 §0～§3 全文或整本规则/技能/模板。
2. 本会话只启用产品规范（落地通常只装本包）；多包时按根 AGENTS 的已启用包列表路由，一次只执行一个包。
3. 与本文冲突时以本文为准；细则以 `产品规范/AGENTS.md` 为准。
4. 产品产物统一 `产品/`；项目根只留 `产品档案.md`、`activeContext.md`；文档按 `产品规范/规则/工作流.md` §2 落位。
```
