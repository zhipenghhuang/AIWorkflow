# 项目 README 素材（可选，非强制大纲）

> 细则与档位见 `规则/核心/项目README.md`。  
> **用法**：先按用户偏好选档（A/B/C/D），再从下表**择需拼接**；已有 README **禁止整文件覆盖**。  
> `{…}` 换成本项目事实；跨会话真源仍是档案/`activeContext`，本文只给人看。

## 选用指引

| 档 | 建议选用块 |
| --- | --- |
| A 极简 | 标题 + 一句话 + 快速开始 + 文档入口 |
| B 标准协作（默认可推荐） | A + 这是什么 + 仓库怎么看 + 常用命令 |
| C 对外开源/产品 | B + 可选徽章/截图、协作说明、许可；语气对外 |
| D 保持现状 | 不套本文；只补缺口句 |

---
