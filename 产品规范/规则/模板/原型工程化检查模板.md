# {主题} 原型工程化检查

> **用途**：高保真原型的路由/数据/状态/响应式/打印/无障碍/版本检查。  
> **落点**：`产品/{版本或主题}/原型/工程化检查-{主题}.md`。  
> **结论**：通过 / 有条件通过（列条件）/ 不通过；阻断项不修不得评审交接。

## 1. 导航与路由

- [ ] 页面/路由表完整；入口可达
- [ ] 历史/返回/深链可用；无死路
- [ ] 未保存提醒/重置可用
- [ ] 演示/原型数据可重置

## 2. 数据与状态

- [ ] 数据模型/关系与 PRD 一致
- [ ] seed 数据覆盖主路径 + 异常/边界
- [ ] 每页状态矩阵齐全（空/加载/失败/成功/禁用/无权限/边界）
- [ ] 模拟能力（OCR/AI/支付）已标注

## 3. 响应式

- [ ] 断点覆盖手机/平板/桌面
- [ ] 手机能完成主任务；表格转卡片/横向滚动
- [ ] 触控目标 ≥44px；无遮挡/截断

## 4. 打印/导出（如适用）

- [ ] A4 版式正确；分页/页眉页脚
- [ ] 打印门槛生效（未通过核对不得正式打印）
- [ ] 导出格式/文件名/权限

## 5. 无障碍（WCAG 2.2 AA 基础）

- [ ] 语义 HTML / label / alt
- [ ] 键盘可达；焦点可见；无焦点陷阱
- [ ] 对比度 ≥4.5:1（正文）
- [ ] 不只用颜色传达状态；`prefers-reduced-motion`
- [ ] 证据：截图/检查结果/工具输出

## 6. 版本与交接

- [ ] 原型版本 / PRD 版本 / 日期
- [ ] 变更记录
- [ ] 组件/状态/交互/tokens 交接清单
- [ ] 标注「原型≠生产代码」

## 7. 结论

- `{通过 / 有条件通过 / 不通过}`
- 阻断项：`{…}` + 责任人 + 截止
