# 后端实现（技能 · 随包生效）

> 用于：S4 编码自测中涉及 API/服务/数据访问/任务/消息/外部集成的任务。  
> 产出：可运行服务 + 单测/集成/契约测试 + 日志/指标证据 + 配置/迁移说明。  
> 原则：**输入必校验、权限必自校、写操作想事务、重复调用想幂等、外部调用想超时。**

## 1. 分层与边界

- Controller/接口层：参数校验、鉴权入口、错误映射。
- Service：业务规则、事务边界、幂等、并发控制。
- Repository/DAO：查询、索引、批量、分页；不把业务塞进 SQL。
- 外部集成：超时、重试、熔断、限流、降级。
- 与项目现有结构/命名一致；最小改动。

## 2. 输入、权限与错误

- 必填/类型/范围/枚举/长度/格式；服务端为准。
- 认证/授权/资源级权限/数据域；不假设调用方已鉴权。
- 错误码稳定、可区分；消息可给用户看；不泄露堆栈/密钥/内部地址。
- 幂等：幂等键/业务键；终态重入拒绝；重复提交可识别。

## 3. 数据与事务

- 事务边界：一个业务动作一个事务；避免长事务/大事务。
- 隔离级别/锁/死锁重试；并发更新用版本号/乐观锁/悲观锁。
- 缓存一致性：失效/双写；先写库还是先写缓存。
- 迁移/回填：幂等、分批、可回滚/前滚；大表看锁与时长。
- 消息/任务：重复消费、顺序、死信、补偿；Outbox/Saga（如适用）。

## 4. 可靠性

- 外部调用超时/重试/退避/熔断；重试只对幂等操作。
- 限流/降级/队列背压；失败可恢复。
- 日志：结构化、含 traceId、无敏感信息。
- 指标：RED/关键业务；告警阈值；健康检查。
- 配置/密钥：环境变量/密钥库；默认值安全；零入库。

## 5. 测试与证据

- 单测：业务规则/边界/异常/幂等。
- 集成：真实数据库/缓存/消息（可用容器）；契约测试。
- 负面验证：鉴权/越权、参数边界、终态重复、不存在对象、错误码。
- 证据：测试命令+结果、关键日志/指标、迁移/配置变更说明。
- 未验证项明示；不把“编译通过”当“功能通过”。

## 6. 常见坑

- 只做 happy path；鉴权/越权漏测。
- 长事务、锁等待、N+1、无界查询。
- 重试风暴、无超时、异常吞噬。
- 日志打印 token/PII；错误回显内部信息。
- 迁移不可回滚、配置默认值不安全。
