# 工程质量（技能 · 随包生效）

> 用于：`change.design` / `change.implement` / `change.review`（iterate 同名步骤同样适用）。  
> 定位：**质量条与证据的单一出处**；不替代 `solution-design`（方案结构）、`implementation-and-selftest`（实现方法）、`code-review`（评审方法）。  
> 原则：**先约束与质量属性，再结构；先最小可行，再演进；每条质量主张都要有证据。**  
> 冲突：`AGENTS.md`/`规则/` 的红线与门优先；项目档案 §7/§8 的项目约束优先于本技能默认值。

## 1. 质量基线（提交前逐条过）

| # | 维度 | 最低要求 | 证据 |
| ---: | --- | --- | --- |
| 1 | 正确性/需求覆盖 | 每个 RP/AC 有实现与验证；无范围外夹带 | 任务清单对账 + 测试/走查 |
| 2 | 边界/契约 | 输入/输出/错误码/空值/上限明确；契约变更先确认 | 契约/OpenAPI + 边界用例 |
| 3 | 数据/事务/一致性 | 数据所有权、事务边界、一致性模型清楚；迁移幂等/可回滚 | 迁移脚本 + 回滚演练 |
| 4 | 失败/幂等/并发 | 超时、重试、降级、补偿；写操作幂等；并发有锁/版本策略 | 失败注入/重复提交/并发测试 |
| 5 | 安全/隐私 | 认证/授权/资源级权限/输入校验/密钥/PII/越权面 | 负面用例 + 扫描/人工清单 |
| 6 | 性能/容量 | 有量级假设与预算；无 N+1/无界查询/大事务 | 基准/压测/查询计划 |
| 7 | 可观测 | 结构化日志（无敏感信息）、RED/USE 指标、追踪、告警点 | 日志/仪表盘/告警截图 |
| 8 | 可测试 | 业务规则可测；单测/集成/契约/负面路径；不靠手测兜底 | 测试命令 + 结果 |
| 9 | 可运维/回滚 | 配置外置、开关/灰度、回滚/前滚路径、运行手册 | 开关/回滚步骤 + 演练 |
| 10 | 兼容/依赖/供应链 | 版本/许可证/维护状态；老数据/老客户端兼容 | 依赖清单/SBOM/兼容用例 |
| 11 | 可维护/最小复杂度 | 边界清晰、命名一致、无投机抽象、最小改动 | diff + 评审结论 |
| 12 | 文档/变更记录 | 行为/接口/配置变化与实现同变更；ADR/CHANGELOG 更新 | 文档链接/版本记录 |

> 阻断：1～5、9 未满足不得声称完成；6～8、10～12 可列遗留但必须有负责人/截止/风险接受人。

## 2. 设计与实施启发式

1. **从质量属性倒推结构**：先写“刺激→响应→度量”（性能/可用性/安全/可修改性/成本），再选架构；不拿框架反推需求。
2. **最小可行架构**：能单体不拆微服务；能同步不引入消息；能库不引入平台。复杂度必须由约束/规模/团队证明。
3. **边界与依赖方向**：领域/应用/基础设施分层；依赖指向稳定侧；跨边界只走契约（API/事件/schema）。
4. **契约先行**：接口先写输入/输出/错误码/幂等/版本；改约先文档 + 确认；前后端按契约并行。
5. **数据先想清楚**：谁拥有、写在哪、事务边界、一致性、保留/删除、迁移/回填；避免共享数据库当集成。
6. **失败是主路径**：超时、重试（仅幂等）、退避、熔断、限流、降级、补偿、死信；禁止无限重试与空 catch。
7. **安全默认**：最小权限、服务端校验、资源级授权、密钥外置、日志脱敏、依赖扫描；前端隐藏不等于授权。
8. **可观测默认**：关键路径有日志/指标/追踪；错误可定位到请求/用户/资源；告警有阈值与升级路径。
9. **小步可逆**：一类改动一提交；重构与功能分开；高风险用开关/灰度/回滚；大改先拆。
10. **文档是交付物**：架构决策进 ADR；接口契约进 OpenAPI；运行/回滚进 runbook；版本变化进 CHANGELOG。
11. **避免投机抽象**：不为“以后可能”造框架；重复三次再抽象；抽象必须有稳定边界与测试。
12. **测试有效性**：测试断言行为而非实现；关键模块可用变异测试/覆盖率缺口做加强信号，但不替代门禁。

## 3. 实施检查（before / during / after）

**Before**

- 读任务卡/AC、设计说明、契约、代码地图、质量门禁命令。
- 明确“怎么证明它对”：失败用例/探针/压测/扫描；无测点写理由。
- 列出改动文件与影响面；超出清单先停下说明。

**During**

- 最小 diff；不顺手重排/升级无关依赖；不夹带重构。
- 每个可验证单元：红→绿→重构（或等价的探针/契约测试）。
- 边界/错误/权限/并发至少各想一条；外部调用设超时。
- 日志/指标/配置/迁移与代码同变更。

**After**

- 跑项目最小充分门禁；失败不声称完成；存量失败只对账新增。
- 对账 RP/AC/文件/证据；未验证项明示。
- 更新任务清单/接口文档/ADR/CHANGELOG/运行手册（按变更面）。

## 4. 质量属性 → 证据

| 质量属性 | 可接受证据 | 不接受 |
| --- | --- | --- |
| 正确性 | 单测/契约/验收用例通过 | “代码看起来对” |
| 性能 | 基准/压测/查询计划/真实指标 | 只看编译通过 |
| 可靠性 | 失败注入/重试/幂等/回滚演练 | 只跑 happy path |
| 安全 | 越权/注入/密钥/PII 负面用例 + 扫描 | “用了框架就安全” |
| 可观测 | 日志/指标/追踪/告警截图 | 只打 console.log |
| 可维护 | diff 小、边界清、命名一致、评审通过 | “以后再重构” |
| 兼容 | 老数据/老客户端/版本矩阵用例 | 只测新环境 |
| 可运维 | 开关/灰度/回滚步骤 + 演练 | 只写“可回滚” |

## 5. 评审 rubric（12 项，0～2 分）

| # | 维度 | 阻断 | 说明 |
| ---: | --- | --- | --- |
| 1 | 需求/AC 覆盖与范围 | 是 | 无漏项、无夹带 |
| 2 | 正确性与边界 | 是 | 空值/上限/精度/时区/并发 |
| 3 | 契约与兼容 | 是 | 输入输出/错误码/版本/老客户端 |
| 4 | 数据/事务/迁移 | 是 | 所有权/一致性/幂等/回滚 |
| 5 | 失败/幂等/并发 | 是 | 超时/重试/降级/重复提交 |
| 6 | 安全/隐私 | 是 | 鉴权/越权/注入/密钥/PII |
| 7 | 性能/容量 | 重要 | 量级/预算/N+1/无界 |
| 8 | 可观测/告警 | 重要 | 日志/指标/追踪/告警 |
| 9 | 测试有效性 | 是 | 断言行为、负面路径、可复跑 |
| 10 | 可运维/回滚 | 是 | 开关/灰度/回滚/runbook |
| 11 | 依赖/供应链 | 重要 | 版本/许可证/维护状态 |
| 12 | 可维护/文档 | 重要 | 最小复杂度/命名/ADR/CHANGELOG |

> 阻断项必须 2 分；总分 ≥20/24 且无阻断才可通过评审。  
> 高风险/大改/破坏性变更：核验者 ≠ 实施者；核验不替代机器门禁。

## 7. 反模式

- 为未来造抽象/平台；单体没跑通先拆微服务。
- 分布式单体：服务拆分但共享库/共享库表/同步调用链。
- 隐藏耦合：跨模块直接读表、绕过契约、共享可变状态。
- 无界查询/N+1/长事务/大事务；循环内 IO。
- 重试风暴/无超时/空 catch/吞异常；失败只打日志不回滚。
- 日志打印 token/PII；错误回显堆栈/内部地址。
- 迁移不可回滚、不可重跑；配置默认值不安全。
- 只测 happy path；改断言/跳测试/禁告警凑绿。
- 大 diff 夹带重构；无 ADR/CHANGELOG；文档与实现脱节。

## 8. 输出与 DoD

- 设计：质量属性场景、边界/契约、失败路径、数据/迁移、观测、测试策略、回滚；重大取舍进 ADR。
- 实施：代码 + 测试 + 迁移/配置 + 观测 + 文档 + 证据。
- 评审：需修项（文件:行｜问题｜证据｜严重度｜修法）+ 结论；不重写代码。
- DoD：AC 满足、门禁通过、评审通过（如触发）、文档/CHANGELOG 同步、证据可复核、可回滚。
