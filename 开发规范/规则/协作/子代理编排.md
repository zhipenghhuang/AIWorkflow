# 子代理编排（执行四档 · 扇出读 · 汇聚写）

> **定位**：本包唯一子代理编排口径；`workflows/` 与 `agents/` 只写「按本文取档/派工/回收」，不重复阈值。  
> **原则**：**先工具、再单上下文分节、再只读扇出、最后写分片**；能直做不拆。  
> **净收益**＝上下文卸载＋墙钟加速＋质量增益−（重复读取＋合并核验＋漂移风险）。  
> **契约文件**：实施/侦察子代理 → `../agents/worker-agent.yaml`；独立核验 → `../agents/reviewer-agent.yaml`（派工时附带，禁只靠口头角色名）。

**派工前 3 问（任一否 → 直做）**：① 能否脚本/校验器/单上下文分节完成？② 单元是否独立且写入不相交（或只读）？③ 合并/核验是否机械、返回能否 ≤30 行？

## 1. 执行四档

| 档 | 适用 | 形态 | 落盘 |
| --- | --- | --- | --- |
| **工具档** | 门禁、校验器、grep/统计、脚本、日志过滤 | 确定性执行，0 token；不派子代理 | 日志/摘要 |
| **直做档** | 默认；单文件、小批、单文档、需全局判断 | 本会话直接做 | 正式产物 |
| **分片档** | 读任务：≥20k token 原始证据/≥5 文件；写任务：≥3 个可独立任务且文件集不相交 | 一任务/一模块/一 bug 一子代理；读可并行、写按文件集隔离；批末门禁→核验→下一批 | `.draft/{任务}/`＋正式产物 |
| **拆分档** | 高风险/大改/破坏性/需独立核验 | Writer → 同回合 fresh verifier → 编排合并 | 草稿＋正式产物 |

## 2. 取档阈值（不达不拆）

| 场景 | 阈值 | 取档 |
| --- | --- | --- |
| 实施/迭代 | **≥3 个可独立任务且文件集不相交** | 分片；一组一子代理 |
| L0 微改/单文件 | — | 直做 |
| 缺陷批量 triage | **≥5 单且读单成本高**（多备注/附件/评估单）或合计 ≥20k token | 逐单只读侦察；分类与处置集中 |
| 缺陷修复分片 | ≥3 单且文件不重叠 | 分片（默认串行） |
| 代码评审 | >400 行有效 diff 或 L3 | 拆分/维度扇出 |
| 设计 | L3/架构级且 ≥3 领域 | 只读领域侦察；方案正文单写手 |
| 发布就绪 | L3/多系统 | 按检查域只读扇出；GO/NO-GO 集中 |
| 文档吸收 | ≥3 份新文档 | 只读抽取扇出 |
| 代码地图/影响面 | 大仓或改动 ≥5 文件 | 只读 scout |
| 门禁日志 | 先脚本过滤；多文件语义归因才子代理 | **工具优先** |
| 同一文件/同一清单/同一单据/同一缺陷 | — | **禁并行**，直做 |

## 3. 扇出读 · 汇聚写（硬约束）

- 读可扇出：代码地图、影响面、日志、文档抽取、逐单分析、领域侦察、证据核对。  
- 写必须单写手或文件集不相交；同一文件/任务清单/方案/报告/发布文档禁并行写。  
- 判断、优先级、终态、门禁、git、平台回写、GO/NO-GO 留在编排；子代理不得过 `hitl`/`gate`。  
- 子代理不改任务清单/开发计划/需求基线/方案正文；完成状态由编排核验后回写。  
- 同文件集多个子代理必须合并成一组串行；禁止并行覆盖。

## 4. 派工包（7 项，缺一不派）

1. 任务与验收（任务号/RP/AC/DoD）。  
2. 边界（允许路径/文件集；禁改清单外）。  
3. 输入（路径＋节；**不附整本**；不读其它包）。  
4. 规则摘录（只带 3～5 条相关红线＋契约文件路径；禁只靠口头角色名）。  
5. 输出契约（草稿路径/代码范围/返回字段）。  
6. 返回格式（≤30 行固定字段；禁日志全文/推理过程）。  
7. 禁止事项（git/平台/门/超范围/同命令重跑）。  

## 5. 回收与合并（编排必做）

- 文件在、字段齐、计数一致、证据可打开、规则回执；失败同回合补跑。  
- 去重与冲突：同一结论只留一条；冲突以代码/命令输出/证据为准；不采信口头完成。  
- 写分片合并后跑一次定向/全量门禁；单文件不重复写。  
- 规则回执：`rules=ok|violation:<条款>`、`scope=ok|over`、`evidence=…`；违规即回退重派或降级直做。  
- 失败：同回合重测 ≤1；同方案无效 2 次换路径；连续失败停止上报。

## 6. 上下文卫生（防稀释）

- 主上下文只留派工摘要、返回摘要、核验结论；原始日志/大 diff/长文档落盘。  
- 子代理只读派发摘录与本批相关节；不通读整本规则/档案/历史；同一文件不重读。  
- 后续步骤 delta-only；批末只重读当前步 must＋当前门，不重读整本。  
- **独立核验**：只给产物＋验收＋diff，不给作者解释/自评（防锚定）。  
- 并发 ≤3；共享写域/同一文件/同一账号/同一发布窗口一律串行。  
- 草稿落 `.draft/{任务}/`，不入库；已完结 draft 按 `规则/文档治理.md` §8（点名/关版本可清；日常收尾不向用户追问）。

## 7. 成本守卫

- **负收益信号**：返回 >30 行、合并/口径冲突、返工、主上下文回读原始证据、超范围。  
- 连续 2 批出现负收益信号 → 回直做。  
- 批末一行：`batch | units | returns≤30 | conflicts | rework | verdict=keep|direct`；不写长报告。  
- 质量投资型拆分（独立核验、维度评审）只在 L3/高风险/大改启用。  
- 不为「多 Agent」而拆；不把确定性工作交给 LLM。
