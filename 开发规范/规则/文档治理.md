# 文档治理（资料 + 工作文档）

> 单一出处：入站意图分析、资料/工作区分流、覆盖对照、受影响同步、归档与清理；含根 `CHANGELOG.md` 与 `开发/工作日志.md`。
> 铁律：**先分析分类 → 输出候选 → 用户确认 → 才改名/移动/标记失效/归档/清理**；未确认前只读。
> **单包优先**：仅本包即可闭环；缺产品/测试包 → 一句缺口，不阻塞、不强制安装、不自动跑他包。多包时可用 `项目资料/` 与交接直读，放入≠分发。
> **反堆积**：确认采纳且 S1/S2/S3 → **同批**失效归档；正式档就地覆盖；禁止「只落位、等关版本再清」。
> 安全：证据、当前计划/方案/任务清单、源文件、用户文件、密钥、`.git` 永不自动删除；拿不准 → 待确认或移 `开发/_归档/_待清理/`。

## 1. 两个区

| 区 | 放什么 | 不放什么 |
| --- | --- | --- |
| `开发/资料/` | 外部/上游原件、只读证据 | 本包需求基线/方案/任务/提测/发布/UAT/复盘 |
| `开发/00～08` 与主档 | 本包工作文档 | 外部原件（放 `资料/`） |

- **单包资料根**：`开发/资料/`。多包 `项目资料/`：确认后只吸收进本包。
- **资料模式**：`keep` / `mix`（默认）/ `replace`。工作文档根默认 `开发/`；旧 `docs/` 等记档案 §9 映射。
- **单一主副本**：跨包只引用。
- **版本记录**：根 `CHANGELOG.md`＝开发维护的发版史；`开发/工作日志.md`＝岗位里程碑（禁写入/补链根 CHANGELOG）。他包各自维护本包工作日志。

## 2. 资料目录（版本/主题子目录）

```text
开发/资料/
├─ 资料索引.md
├─ _通用/
├─ {版本或主题}/
├─ 交接/{HO-ID}/
└─ _归档/{yyyyMMdd}-{版本或批次}/
```

- **禁止**：新建 `项目文档/`/`原始素材/`/`_收件箱/`；禁止新资料长期平铺 `资料/` 根（收取批次内可临时落根并标「待分类」，确认后同批归位）；禁止强制类型前缀改名（类型写索引）。
- **兼容**：旧扁平前缀文件、旧 `资料/项目文档/`、旧 `开发/_归档/**/资料/` → 重新接入列迁移候选。
- 仅外部/上游原件进资料；本包基线/方案/清单是工作文档。

## 3. 入站意图分析

输出：`类型 | 落点 | 同步 | 归档/覆盖`。

| 类型 | 线索 | 落点 | 本包同步 | 归档/覆盖 |
| --- | --- | --- | --- | --- |
| T1 全量基线替代 | 整份新 PRD/需求废止旧版 | 外件→`资料/{ver}/`；吸收→`01-需求基线/` | 台账、计划、文档索引 | 旧基线正文若不再实施入口 → 归档 |
| T2 方案/设计变更 | 方案 diff、技术结论 | 外件→资料；正文→`02`/`03` | 变更记录、任务清单、计划、索引 | 旧方案失去**实施入口** → 期中归档；局部就地覆盖 |
| T3 未决确认 | 拍板、澄清答复 | 结论→`00-待决项` + 基线/方案对应条 | 关闭待决、冻结范围 | 过程件不堆现行区 |
| T4 迭代专项/局部 | 修改方案、单模块补丁 | 外件→资料；增量→方案/任务增量 | 影响面任务、计划 | 被替代的旧增量归档；禁两份「最终方案」并排现行 |
| T5 范围/优先级 | 砍需求、重排期 | 计划/台账 | 状态与范围节 | 旧通知被替代 → 归档 |
| T6 缺陷/回流 | 产品回复、修复说明 | 外件→资料；结论→`00` 评估/变更 | 对齐受影响 01～06 | 旧评估被替代 → 归档 |
| T7 仅参考 | 无强制采纳 | 资料=`参考` | 一般不改 SSOT | 不进现行工作区 |
| T8 冲突 | 未裁决矛盾 | `待确认` | 停下问 | 不覆盖现行 |
| T9 交接包 | HO-ID | 多包直读；仓外按接收 | 计划/台账回写 | 发出包不可改 |

C0～C3 同协作规则。双落点时 **SSOT=工作区**；吸收=写内容，不是把外件挪进 `01/` 当基线原件。

## 4. 资料收取步骤

1. 识别变化文件 → 判 T1～T9 + 覆盖关系。
2. 输出候选；确认前不改文件。
3. **确认采纳后同批**：落位 → 同步工作区 → S1/S2/S3 失效 → 资料进 `开发/资料/_归档/{批次}/`；工作文档进 `开发/_归档/{批次}/`（或同类下 `归档/`）→ 清单 → 更新索引/开发计划 §13/activeContext。
4. 部分/增量/参考保留且状态准确；冲突→T8。

覆盖关系与 S1～S5 同产品包。禁按年龄归档。

## 5. 工作文档四类

| 文档/目录 | 类型 | 处理 |
| --- | --- | --- |
| `项目档案.md`、`activeContext.md`、`开发/文档索引.md` | 长期 | 就地更新；本包只改 `## 开发` |
| 根 `CHANGELOG.md` | 长期 | 只增不改；过长确认后移块到 `开发/_归档/changelog/`，禁版本关闭整文件搬迁 |
| `开发/工作日志.md` | 长期 | 过长确认后移块到 `开发/_归档/工作日志/` |
| `开发/开发计划.md` | 长期主档 | 关闭时快照到 `_归档/{yyyyMMdd}-{版本}/`，主档不移动 |
| `00-项目治理/` | 长期 | 变更/待决/决策/缺陷评估；就地更新 |
| `01-需求基线/` | 绑定 | 正文按实施入口归档；`需求台账.md` 常青 |
| `02-方案设计/` | 绑定 | 关闭或非实施入口 → 归档 |
| `03-技术设计/` | 长期 | SSOT 就地更新；不随迭代整夹归档 |
| `04-计划与任务/` | 绑定 | 同实施入口规则 |
| `05-测试与验收/` | 绑定 | 工程侧 UAT 等；关闭归档。多包时业务 UAT SSOT 在产品，此处可引用 |
| `06-发布与交付/` | 绑定 | 一版一档；关闭归档 |
| `07-运维与协作/` | 长期 | 就地更新 |
| `08-复盘与改进/` | 绑定 | 关闭归档 |
| `开发/交接/{HO-ID}/` | 快照 | 不可改；`-v2`；台账常青 |
| `**/.draft/` 等 | 临时 | 清理候选 |

**实施入口**（方案/任务清单）：

| 留现行 | 进归档 |
| --- | --- |
| 仍有未完成功能要改代码；草案/评审中/已确认/实施中 | 主体已落地，不再作下一期入口；已实施/已执行/已归档 |

尾巴写在状态括号，不占现行入口。

## 6. 更新还是归档

主档/局部 → 就地更新。T1/失去实施入口 → 确认后归档。T4 → 增量就地或专项件，禁并排双最终方案。版本关闭 → 绑定文档归档；`00`/`03`/`07`/台账/计划主档保留。正式文档只写现行有效。

## 7. 版本/迭代关闭（换迭代 = 关当前版进入下一版）

> **迭代即版本主题**：换下一期方案/新版本目录 = 结束当前迭代并开下一迭代。与「正式发布上线」**不是两套清理标准**——分类、绑定归档、失效资料、临时清理、索引/链接同一套完整分析；差别只在是否做**发版对外项**。

### 7.1 关账清单（按实际裁剪，不是少做）

| 动作 | 换迭代（可不发版） | 正式发版/结项 |
| --- | --- | --- |
| 分析分类：长期/版本绑定/失效替代/过程临时 | 必做 | 必做 |
| 更新计划/台账/索引/activeContext | 必做（指向下一迭代） | 必做 |
| 当前迭代绑定方案/清单/提测/UAT/复盘等 → `_归档/{yyyyMMdd}-{版本或迭代}/` | 必做（已确认结束的） | 必做 |
| 失效资料 → `资料/_归档/` + 清单 | 必做 | 必做 |
| 临时/过程/失败/重复清理 | 必做 | 必做 |
| 修断链 | 必做 | 必做 |
| 根 CHANGELOG 发版史 / 发布说明对外 | **跳过**（除非用户点名发版） | 必做 |
| 部署/上线检查/对外公告 | 跳过 | 按 release 门 |

### 7.2 确认结束当前迭代（不确定必问）

出现下一期方案/换主题/版本号升级，但当前迭代是否算结束不明确（例如仍在缺陷回归、提测未结）→ **STOP** `confirm_iteration_close`：出示「当前迭代标识、未完成项、拟归档摘要、下一迭代标识」→ 用户确认「结束当前并进入下一」后才执行 §7.1；用户说「并行不关」→ 只落新资料、不归档现行绑定主档，收尾记假设。

用户已明确「下一期 / 换版本 / 关这期」→ 按已确认执行，不重复空问。

### 7.3 触发（自动探测 · 同会话）

1. 新迭代/版本文档确认采纳（intake / materials / change）且判定换代，或用户确认结束当前
2. 换主题目录 / 版本号升级 / 计划范围换代
3. 正式发版/结项口令
4. 点名整理/巡检/清理（可只做清理子集，仍先分析分类）

未确认零移动；证据/现行主档/密钥永不自动删。

## 8. 过程/临时清理

同产品包规则，范围 `开发/` + 项目根顶层；不确定 → `开发/_归档/_待清理/`。永不自动删正式产物与根 CHANGELOG/工作日志。**换迭代/关版本时的清理并入 §7.1**，不另立「轻量卫生」标准。

## 9. 输出骨架

```text
【入站分析】意图=Tx | 级别=Cx
```

## 10. 触发

| 时点 | 动作 |
| --- | --- |
| 接入/重新接入 | 建资料结构+索引+标准树；旧结构迁移候选 |
| 新文档/intake/方案变更/未决/专项 | §3～§4；确认后同步+归档同批；若换代→§7（不确定则先 `confirm_iteration_close`） |
| 换代/换主题/版本升级（可不发版） | **§7 关账（与发版同级分类归档）**；跳过仅发版项 |
| 版本关闭/正式发布 | §7 全表（含发版项） |
| 点名整理/巡检/清理 | §7.1 清理子集或 lifecycle；仍先分析分类 |
| 季度可选 | 只出候选 |
